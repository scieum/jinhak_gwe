개정 요청 ①(2026-11-24 채팅 원문): "우리반 일정표에서 분류에 따라 색을 다르게 해주자. 다 똑같이 묶지 말고" → 사용자가 고른 것: 담임 · 학생 일정 둘 다 적용, "새 일정 색 5개"(판정 · 파랑과 안 겹치는 차분한 색을 일정 전용으로 만들고, 점 · 옆 막대 · 태그에만 쓰고 글자는 흑백 유지).
개정 요청 ②(2026-11-24 채팅 원문, 모바일 그날 목록 캡처 — 묶음 머리마다 밑줄 글자 "일정 고치기" 반복): "여기 겹치는 부분이 많아서 그냥 연필 모양으로 수정을 암시하는 느낌으로 가야할듯". 승인 기록은 prev로 옮겨져 다시 S3 → 승인 → S4.
한 줄: 담임이 반 학생들의 수시 일정을 날짜별로 보고, 서류 · 면접/실기는 완료로 표시하고, 발표 일정에서 결과를 고르면 결과 집계와 같은 기록(outcomes)에 바로 저장되는 화면이에요. 일정 종류 5개는 일정 전용 색 표식 + 이름으로 나눠 보여요. 판정(안정 · 적정 · 소신 · 위험) · 환산 숫자 · 앞으로의 결과를 점치는 말이 없어요.

## 4. 데이터 규칙 · 앱 메모

- 일정 행 = (학생 카드 지원 칸) × (그 대학 · 전형의 일정). 연결 키 = 번호 + 대학 + 전형(outcomes와 같음). 학과는 카드 slot에서 읽어 행에 보여요.
- 면접/실기 날짜는 카드 slot의 고사 종류 · 고사 날짜를 읽어요(복사 안 함). 학생이 카드를 다시 보내 날짜가 바뀌면 화면도 바뀌어요. 교사가 넣은 면접/실기 날짜는 카드 날짜가 없는 학생에게만 쓰여요.
- 1단계 발표 행은 교사가 그 전형에 1단계 발표 일정을 넣었을 때만 생겨요. 1단계 불합격(stage1 = 불합격)인 학생은 그 뒤 면접 · 최종 발표 행에서 빠지고, 최종 결과 칸은 "1단계 불합격"으로 이미 채워져 있어요.
- 결과 칸은 결과 집계와 같은 outcomes를 바로 고쳐요(D13). 학생이 카드를 다시 보내도 직접 넣은 결과는 지우지 않아요(결과 집계와 같음).
- 완료 표시는 서류 제출 · 면접/실기 행에만, 발표 행은 결과 값이 곧 완료(미입력이 아니면 완료).
- 종류 색은 저장된 종류 값(서류 제출 · 면접·실기 · 1단계 발표 · 최종 발표 · 충원 기간)으로만 정해요. 카드 slot의 고사 종류(면접 · 실기 · 논술 등)는 모두 면접·실기 색이에요. 메모 · 이름 글자로 종류를 추정하지 않아요.
- **새 저장(앱 반영 사항)**: ① 대학 일정 { 대학, 전형, 종류(서류 제출 · 면접·실기 · 1단계 발표 · 최종 발표 · 충원 기간), 날짜, 마감일(충원 기간만), 시각?, 메모? } ② 학생별 완료 표시 { 번호, 대학, 전형, 종류, 완료 } — 교사 저장소 버전을 올려 테이블 2개 추가. 학급 지우기 · 백업 형식에 함께 넣어요.
- 앱 반영 사항(2026-11-24): 일정 종류 색 토큰 10개를 앱 색 정의에 추가하고, 달력 칸 표식 줄 · 범례 · 종류 태그 · 칩 표식을 그려요. 묶음 머리 고치기는 연필 아이콘 버튼(aria-label "… 일정 고치기"). 저장 파일(xlsx · hwpx · pdf)에는 색 없이 종류 이름만.
- 후속: outcomes 키에 학과 추가(같은 대학 · 같은 전형 학과 둘), 전형계획 데이터에 검수된 일정 날짜가 생기면 대학 일정 기본값으로 채우기(그때도 교사가 고칠 수 있게), 6회 제한 제외 기관 칸 포함 여부.
- 서버로 보내지 않아요. 저장 파일은 기기에서 만들어요(D21). 나이스 등 외부 연동은 없어요.
- 학생은 번호 · 별칭만. 대학 일정 입력 칸에 학생 이름 · 연락처 칸이 없어요.
- NEVER-1 대상 계산(환산 · 판정)이 없어요. 날짜를 추정해 채우지 않아요.

## 7. 접근성

- 달력 = 표(caption "2026-11 반 일정 달력 · 날짜를 누르면 그날 일정을 보여요"), 칸 = 버튼(aria "11월 20일, 일정 25건, 서류 제출 11건, 1단계 발표 14건"), 오늘 aria-current=date, 선택 aria-pressed. 방향키로 칸 이동, Enter/Space 선택. 달이 바뀌면 조용한 알림.
- 종류 표식 · 옆 막대는 aria-hidden이고, 종류는 칸 aria · 태그 글자 · 칩 이름 · 범례 글자로 읽혀요. 범례는 목록(ul)으로 읽혀요. 색을 구분하기 어려워도 칸 표식은 고정 자리(1~5번째)로, 나머지는 이름 글자로 구분돼요.
- 표식 대비: 진한 색 5개는 흰 바탕 · {colors.accent-soft}(선택 칸) · tint 위에서 모두 3:1 이상(그래픽 기준), 실제로는 5.1:1 이상이에요.
- 연필 아이콘 버튼 = button(aria-label "연세대학교 미래캠퍼스 학교생활우수자 1단계 발표 일정 고치기", 대학 · 전형 · 종류를 넣어 묶음끼리 이름이 겹치지 않게), 아이콘은 aria-hidden. 아이콘 {colors.ink} 흰 바탕 대비 18:1. 모바일 누르는 영역 44×44, PC 32×32 + 툴팁 "일정 고치기"(포커스에도 보임). 포커스 2px 잉크 링.
