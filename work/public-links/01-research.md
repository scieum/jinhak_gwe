## 반영 포인트

- P1: 목적별 묶음 3개. "상담 받기"(대교협 대입상담교사단 · 강원진학지원센터 상담 · 모의면접 신청) / "원서 접수"(진학어플라이 · 유웨이어플라이) / "경쟁률 보기"(진학어플라이 스마트경쟁률 · 유웨이어플라이 파워경쟁률). 섹션 제목 + 카드 그리드로 나누고, 기관 이름보다 "무엇을 하러 가는지"를 섹션 이름으로 써요 [근거: L2, L3, L11]
- P2: 카드 모양은 2열 직사각형. 카드 안: 서비스 이름 {heading-4} + 한 줄 설명(예: "현직 교사에게 무료로 대입 상담을 받아요") + 운영 기관 캡션 + 오른쪽 위 ↗ 외부 표시. 흰 바탕 + 1px hairline-soft, 모서리 0, 그림자 없음. 모바일 2열, PC 3열 [근거: L4, L5]
- P3: 외부 링크 표시는 세 겹. (1) 카드마다 ↗ 아이콘 + 대체 텍스트 "외부 사이트, 새 창", (2) 묶음 위 캡션 text-muted "누르면 외부 사이트로 이동해요 · 진학 내비가 운영하지 않아요", (3) 처음 누를 때만 확인 시트 "○○ 사이트로 이동해요" + 주소 도메인 + "이동하기"/"취소". 색으로 경고하지 않고 ⓘ + 문장으로 알려요 [근거: L6, L7]
- P4: 책임 범위 고지. 묶음 맨 아래 `disclaimer-note`: "외부 사이트의 내용과 경쟁률 숫자는 각 기관이 제공해요 · 진학 내비는 링크만 연결해요 · 주소는 2026-11-18 기준이에요". 경쟁률 숫자를 진학 내비 화면에 옮겨 적지 않아요 [근거: L8, L7]
- P5: 홈에는 고른 링크만 작게. 홈 카드 하나 안에 즐겨찾기한 바로가기 4개(아이콘 + 두 줄 이름) + 오른쪽 위 "전체 보기"/"편집". 전체 목록은 더보기의 바로가기 화면에 둬요 [근거: L1, L3]
- P6: 즐겨찾기는 기기 저장 + 개수 제한. 카드 오른쪽 아래 별(☆/★) 토글로 담고, 편집 화면에서 "4/4"처럼 고정폭 개수를 보여줘요. 선택된 칸은 accent-soft + 1px Route Blue 테두리(선택 표시 규칙). 즐겨찾기는 이 기기에만 저장해요 [근거: L9, L10]
- P7: 시기 표시는 글자로. 원서 접수·경쟁률 카드에는 캡션 "수시 원서 접수 기간에 열려요"처럼 언제 쓰는지 적어요. 기간 밖이라고 카드를 숨기거나 회색으로 막지 않아요(외부 사이트 상태를 진학 내비가 알 수 없음) [근거: L5, L7]

## 지키는 것

- NEVER-2: 경쟁률 카드 설명에 "유리/불리", "붙을" 같은 해석을 붙이지 않아요. "실시간 경쟁률을 각 원서접수 사이트에서 봐요"까지만 써요.
- 데이터 수집·연동 없음: 경쟁률을 긁어 오거나 원서 상태를 불러오지 않아요(갭 5·22 "링크만").
- 학생 데이터 서버 저장 없음: 즐겨찾기·"다시 묻지 않기"는 기기 저장.
- 모서리 0, 카드 그림자 없음(확인 시트만 떠 있는 레이어 그림자 허용). Route Blue는 링크 글자·선택 표시에만.

## 확인 필요 (S2 전에)

- 각 기관 링크 주소(대교협 어디가 상담, 강원진학지원센터 상담·모의면접 신청 페이지, 진학어플라이 스마트경쟁률, 유웨이어플라이 파워경쟁률)는 이번 조사에서 직접 열어 확인하지 않았어요. 주소와 전화번호(1600-1615)는 S2에서 공식 페이지로 다시 확인해야 해요.
- 외부 링크 카드·↗ 아이콘·이동 확인 시트가 design.md 컴포넌트에 있는지 S2에서 확인해요. 없으면 "design.md 수정 제안"으로 남겨요.
