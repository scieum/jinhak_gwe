## 1. 화면 목적과 데이터

- 목적: 같은 성적이 관심 대학마다 교과·출결·합계 몇 점이 되는지 보고, 계산 근거를 단계별로 확인하게 한다(PRD 6-4).
- 계산은 검수 완료(verified) 규칙만 쓴다. 검수 전 규칙인 대학은 목록에 남기되 계산하지 않는다(R-CALC-002, NEVER-1).
- 순위 정의(화면 문구로도 보여준다)
  - 환산 기준 순위: 대학 만점 대비 내 합계 비율로 줄 세운 순서
  - 단순 평균 기준 순위: 대학별 반영 교과의 단순 평균 등급으로 줄 세운 순서
  - 순위 차이 = 단순 평균 기준 순위 − 환산 기준 순위 (+면 이 대학 환산이 나에게 유리한 쪽)
  - 순위는 계산된 대학끼리만 다시 센다. 대학이 빠지거나(관심 빼기) 계산이 안 되는 대학이 생기면(입력 부족) 남은 대학끼리 다시 줄 세운다(5장 C · F의 순위 문장은 이 규칙으로 1장 값에서 다시 센 것이다. 새 점수는 만들지 않는다).

- 다온대학교 = 검수 전 규칙. 점수 칸은 비우고 숫자·추정값·임시값을 넣지 않는다. 그 자리에 `data-status-badge` "환산 규칙 준비 중" + "검수가 끝나면 계산해요"만 둔다.
- 정렬 기본값은 환산 기준 순위. 준비 중인 대학은 어떤 정렬에서도 맨 아래, 입력 부족 대학은 계산된 대학 아래 · 준비 중 위.

### 산출 근거 예시 (솔빛대학교, 모든 프레임 공통)

| 단계 이름 | 수식 / 값 |
|---|---|

| 반영 학기 | 1-1 ~ 3-1, 5개 학기 · 학년 가중 없음 |
| 반영 과목 | 국어·수학·영어·사회·과학 22과목, 학점 합 92 |
| 제외한 과목 | 융합선택 2과목(석차등급 미산출 → 규칙상 제외) |
| 과목별 적용 점수 (예) | 공통국어1 1등급 → 100점 × 4학점 / 공통수학1 2등급 → 96점 × 4학점 / 통합과학1 1등급 → 100점 × 3학점 |
