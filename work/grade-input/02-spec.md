# 02-spec — 성적 입력 (grade-input)

## 1. 개요

- 근거: PRD 6-2(내 성적 입력), 9장 R-IN-001~004, design.md Responsive Strategy "성적 입력" 행, 01-research.md P1~P7
- 프레임: 모바일 390×844, PC 1440×900
- 하는 일: 학기별 과목 성적을 성적표 열 순서대로 입력해요. 과목 유형에 따라 입력 칸이 바뀌고, 검증(R-IN)에 걸린 칸은 그 자리에서 고치게 해요.
- 필수 컴포넌트 점검: grade-input은 rules의 requires_trace_accordion, requires_disclaimer_note 어느 목록에도 없어요. 환산·판정 결과를 보여주지 않는 화면이라 산출 근거 펼치기와 고지 문구를 넣지 않아요.
- 색: 흑백 + 입력 오류용 위험 색 쌍(judge-risk / judge-risk-bg)만 써요. Route Blue는 이 화면에 없어요. 등급 숫자에 색을 넣지 않아요.

7. 하단: `tab-bar-pill` (성적 탭 선택), safe-area 지킴

## 4. 모바일 바텀시트 편집기 (위에서 아래로) [P2, P3, P4, P7]

`bottom-sheet` 위쪽 모서리 16, 그림자 overlay, 뒤 scrim. 머리와 하단 버튼은 고정이고 가운데만 스크롤돼요.

1. 손잡이 막대
2. 머리: "여행지리"(heading-4) + 오른쪽 닫기 아이콘
3. 유형 줄: `subject-type-chip` "융합" + caption text-muted "사회 · 2학년 1학기"
4. 학점 | 수강자수: `text-input` 2열, 라벨은 칸 위, 칸 안 오른쪽에 단위 접미사 "학점", "명". 숫자 키패드
5. 원점수 | 과목평균: `text-input` 2열, 접미사 "점"
6. 성취도: `segmented-control` "A · B · C · D · E", 선택 "A"는 `segmented-control-active`
7. 성취도별 분포비율: 라벨 "분포비율(%)", A~E 칸 5개를 한 줄로. 각 칸은 `text-input-error` (2px judge-risk 링). 그 아래
   - 요약 줄: 왼쪽 "합계", 오른쪽 "98.5%" (고정폭, judge-risk 글자 + ■ 아이콘)
   - 안내 caption(judge-risk) 한 번만: "분포비율 합이 98.5%예요. 100%가 되도록 확인해 주세요."
8. 석차등급: 칸을 숨기지 않고 비활성으로 둬요. canvas-soft 빗금 채움 + 칸 안 "미산출"(text-faint), 아래 caption text-muted "융합선택 과목은 석차등급이 없어요". 누를 수 없어요(R-IN-001)
9. (스크롤 아래) 공동교육과정 표시: 체크박스 + "공동교육과정·온라인학교 과목이에요"
10. 하단 고정: `button-primary` "저장". 오류가 남아 있으면 비활성(canvas-soft 채움 + text-faint 글자)

- 포커스된 칸은 `text-input-focused` (2px 잉크 링).
- 오류가 남은 채로 닫으면 입력값은 이 기기에 그대로 두고, 카드에 "확인 필요"를 붙이고, 그 과목은 계산에 넣지 않아요. 입력한 값이 사라지지 않게 하려는 거예요.
- 유형에 따라 칸이 달라져요(PRD 6-2 표):
  - 공통·일반·진로: 위 칸 전부 + 표준편차(선택) + 석차등급 1~5 입력 가능
  - 융합: 석차등급만 미산출 처리(위 예시)
  - 체육예술·과탐실험: 학점 + 성취도 `segmented-control` "A · B · C" + 석차등급 미산출. 시트 높이가 줄어들어요
  - 교양: 학점 + `segmented-control` "이수 · 미이수" + 석차등급 미산출
- 수강자수가 기준값 이하면 수강자수 칸 아래 caption text-muted "소수 수강 과목이에요"를 붙여요(R-IN-004).

   - 미산출 칸(여행지리·기후변화와 환경생태·운동과 건강·진로와 직업의 석차등급): canvas-soft 빗금 + caption "미산출", 입력 불가 [P7]

## 6. 상태·흐름

- 빈 학기: `empty-state` "아직 입력한 성적이 없어요" + body-sm "성적표를 보면서 과목을 하나씩 더하거나, 엑셀 파일을 불러올 수 있어요" + `button-primary` "과목 추가하기", 그 아래 `button-outline` "엑셀 불러오기"
- 불러오기 [P6]: PC `modal`, 모바일 `bottom-sheet`. 제목 "성적 불러오기". 같은 크기의 선택지 3개를 나란히(모바일은 세로로):
  - "템플릿 내려받기" — caption "성적표와 같은 열 순서의 엑셀 양식이에요" + `button-outline` "내려받기"
  - "엑셀·CSV 올리기" — caption "템플릿에 채운 파일을 올려 주세요" + `button-outline` "파일 고르기"
  - "선생님이 보낸 파일 열기" — caption ".jnavi 파일을 열어요" + `button-outline` "파일 고르기"
  - 올리는 동안 선택지 자리에 진행 문구 "파일을 읽고 있어요". 끝나면 창이 닫히고 `toast` "과목 9개를 불러왔어요 · 확인 필요 1개"
- 내보내기: PC `modal`, 모바일 `bottom-sheet`. 선택지 2개: "백업 파일(.jnavi)" — 암호 `text-input` + caption "이 암호가 있어야 다시 열 수 있어요", "CSV" — caption "다른 프로그램에서 열 수 있어요". 하단 `button-primary` "내보내기"
- 저장 알림: 모바일 시트 저장 후 `toast` "저장했어요" (탭바 위)

## 9. design.md 수정 제안 (있음, 반영은 사람 판단)

### v4-9. design.md 수정 제안 (v4, 반영은 사람 판단)

1. 대분류 첫 화면 머리(`brand-logo` 92 줄)에 보조 동작 1개를 둘 수 있는지 규칙이 없어요. 성적 입력은 오른쪽 더보기(성적 파일)가 필요해서 v4는 `app-bar`의 "오른쪽 보조 동작 1개" 규칙을 빌려 썼어요.
2. 과목명처럼 직접 치면서 목록에서도 고르는 칸(추천 목록 입력)이 없어요. v4는 `text-input` 변형 select의 떠 있는 목록 모양으로 대신했어요. `text-input` 변형 combobox(입력 + 추천 목록)를 적어 두면 좋겠어요.
3. 거르기 결과 0건 모양이 없어요(`empty-state`는 주요 버튼 하나가 필수라 맞지 않아요). v4는 body-sm 한 줄 + `button-pill-soft` "거르기 풀기"로 썼어요.
4. 시트 위에 시트를 한 겹 더 올리는 규칙(scrim 겹, 최대 겹 수)이 없어요.
5. 앞 설계서 제안 중 아직 남은 것: subject-card 오류 상태(이제 icon/triangle-alert로), toast 안 동작 글자("되돌리기"), 메뉴 선택 줄(모달·시트 안 동작 목록), 단계 표시, 아이콘 목록(icon/more · icon/triangle-alert · icon/loader 등).
