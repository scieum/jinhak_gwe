## 4. 규칙 · 데이터

- 승인 규칙(앱 fieldReview.ts 그대로, 화면 문구로 드러냄): 표 전체 단위 승인, 서로 다른 검수자 2명 = 검수 완료. 칸 · 행이 바뀌면 승인 전부 지움. 빈 칸 · 같은 학과 두 번이 하나라도 있으면 승인 못 함. 검수 완료일 때만 공개 파일(univ-wiki.json의 fields) 내보내기.
- 검수자 이름은 이 기기에만 기억(브라우저 저장). 2인 검수 기록은 field-review.json 파일로 주고받아 합쳐요. 서버 저장 · 로그인 계정 이름 연동은 이번 범위 밖(PRD 미결 10 "관리자 데이터 저장소 방식").

- 이 표가 쓰이는 곳: univ-detail-wiki "입결이 비슷한 대학"(같은 계열 · 관련 계열), dept-tier 학과 묶음. 이 화면 자체는 입결 숫자를 읽거나 보여 주지 않아요(빠진 학과 찾기는 공개 입결의 대학 · 모집단위 이름만 씀).
