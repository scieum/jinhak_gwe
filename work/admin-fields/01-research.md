# 01-research — 학과 계열표 검수 (admin-fields, 관리자)

작성일 2026-11-23 · 담당 researcher (S1)
근거: PRD 6-11(관리자 데이터 파이프라인 · 2인 검수, 작성자 ≠ 검수자), 3-5(센터 데이터 관리자: 검수한 뒤에만 공개), 7-4(관리자 화면). 앱 구현 app/src/screens/AdminFields.tsx + app/src/domain/fieldReview.ts.
이 표는 'univ-detail-wiki · 입결이 비슷한 대학'과 'dept-tier 계열 고르기'가 쓰는 소계열·중계열 표예요. 숫자를 계산하거나 공개 입결을 바꾸지 않아요(NEVER-1 대상 계산 없음). 화면 안 문구에 지원 결과를 내다보는 말은 쓰지 않아요(NEVER-2).
