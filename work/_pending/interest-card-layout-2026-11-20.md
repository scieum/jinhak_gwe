# 관심 전형 화면 구분 개선

- 제목·검색을 흰색 패널로 분리하고, 저장 목록에는 별도 헤더와 구분선을 적용했다.
- 관심 항목은 대학 로고·대학명·전형, 학과 정보, 실행 버튼을 구분한 흰색 카드로 표시한다. 넓은 화면은 2열, 좁은 화면은 1열이다.
- 학과를 지정하지 않은 기존 항목은 강조 안내와 검정색 ‘학과 선택하기’ 버튼으로 표시한다. 학과가 저장된 항목은 모집단위 이름을 크게 표시한다. 저장·삭제·지원 준비의 데이터 처리 방식은 유지한다.
- 대학명으로 기존 로컬 로고를 찾을 수 있도록 대응표를 추가했다. ‘가천대’ 같은 약칭을 처리하며, 로고 스타일은 공통 컴포넌트로 옮겼다. 수집 도구에서 두 대응표를 함께 재생성한다.
- 관련 테스트 3개 파일 36개 및 프로덕션 빌드 통과. 기존 번들 크기 경고는 남아 있다. diff 공백 검사 통과.
- 격리한 Edge 브라우저에서 1920/1440/768/390/320px 화면의 로고 표시, 카드·문서 넘침 없음, 검색·관심 삭제·학과를 포함한 지원 준비를 확인했다. 기존 학과 미지정 카드와 모바일 화면도 직접 확인했다.
