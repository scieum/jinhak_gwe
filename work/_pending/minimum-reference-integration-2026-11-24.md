# 실제 수능 최저 참고자료 연결

사용자 요청: 화면 개발을 계속하면서 실제 데이터도 함께 넣어 완성도를 높인다.

## 반영

- 기존 검수 준비 자료에서 원본 규칙 참조 4,801건과 전형·모집단위 조합 40,823건을 218개 대학·캠퍼스 패키지로 생성했다. 총 12,646,484바이트이며 화면에서 전체를 내려받지 않는다.
- 위치: `app/public/data/minimum-references/`. 재생성: `python app/tools/build_minimum_references.py`.
- 생성 전 입력 해시와 원본 패키지 해시를 확인한다. 앱 로더도 파일 크기·SHA-256·스키마·규칙 참조를 확인한다. 실패한 요청은 재시도할 수 있고 같은 파일 요청은 공유한다.
- 실제 목표 대학의 “수능 최저 원문·근거”에서 학년도·캠퍼스·전형·모집단위, 원문 문장(있는 경우), 수집일, PDF 쪽수 링크를 표시한다. 모의고사 성적이 없어도 확인할 수 있다.
- 동일 대학명에 여러 캠퍼스가 있거나 같은 전형·학과가 여러 모집시기에 걸쳐 있으면 하나를 임의로 선택하지 않는다. 학과 누락·연결 없음·명시적 보류·미적용 원문이 구분된다.
- 모든 자료는 `review_status: draft`, `executable: false`. 실행용 Criterion을 내보내지 않으며 실제 충족 판정 경로에 연결하지 않았다. 기존 샘플 판정은 그대로다.
- 기존 공통 기준일과 혼동하지 않도록 실제 참고자료의 수집일은 각 근거에 표시한다.

## 검증 결과

- 전체: 72개 파일, 591개 테스트 통과 (`minimum-reference-full-tests.log`, exit 0).
- 변경 대상 최종 확인: 4개 파일, 23개 테스트 통과.
- 프로덕션 빌드 통과 (`minimum-reference-build.log`, exit 0). 기존 번들 크기 경고는 남는다.
- 218개 생성 파일 모두 해시·크기·참조·건수·draft 상태 검사 통과.
- 실제 브라우저에서 한림대 원문 근거를 연결했다. 펼치기 전 요청 0회, 펼친 후 목록+해당 패키지 2회. 원문 페이지 링크와 판정 없음, 320/390/1440px 레이아웃 확인.
- 브라우저 재현: `work/_pending/minimum_reference_smoke.py`. 화면: `minimum-reference-mobile.png`.
- `git diff --check` 통과.
- G5는 기존 시각 차이 4곳 그대로 실패. 모바일 새 버튼 배치 1곳, 시안 로고 겹침 2곳, PC 큰 글자 1곳. SSIM 390=0.9545 / 1440=0.9817, same_fail_streak=2. 데이터 연결로 새 시각 차이는 생기지 않았다. 완료 판정 또는 예외를 만들지 않았다.

외부 배포·커밋·원문 최신 공지 재검증은 수행하지 않았다. 계산용 자료 공개에는 실제 검수와 별도 배포 절차가 필요하다.
