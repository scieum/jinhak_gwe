# 전형 자료 선택 → 지원 준비 → 원문 연결

사용자의 계속 개발 요청에 따라, 앞서 연결한 218개 대학·캠퍼스 참고자료를 지원 전형 입력에도 사용하도록 확장했다.

## 동작

- 지원 전형 추가/수정창에서 “전형 자료에서 찾아 입력”을 펼친다. 해당 학년도의 대학·캠퍼스 검색 → 전형·모집시기 → 모집단위 선택 후 적용한다.
- 펼치기 전 네트워크 요청은 없다. 선택한 대학 패키지만 불러오며, 오류 재시도와 대학/학년도 변경 중 늦게 도착한 응답 처리를 지원한다.
- 표시명과 원문 링크를 채우고, 패키지·전형·모집단위 식별자·모집시기·원본 해시를 `source_selection`에 저장한다. 기존 직접 입력과 기존 백업 형식은 계속 지원한다.
- 출처 식별자가 로컬 DB와 암호화 백업·복원에 보존된다. 정확한 식별자가 있는 경우 동명 전형의 모집시기를 구분한다.
- 대학·전형·학과·학년도를 직접 수정하면 이전 출처 연결 및 자동 입력된 원문 링크를 해제한다. 출처 변경은 기존 확인 상태·기한·근거를 초기화하는 변경으로 처리한다.
- 원문 해시가 달라지면 이전 선택을 자동으로 최신 자료에 연결하지 않고 재선택을 안내한다.
- 자격·일정·최저 판정은 자동으로 확인 처리하지 않는다. 참고자료는 계속 draft/executable=false다.
