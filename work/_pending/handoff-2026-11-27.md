## 6. 알아 둘 함정

- **Figma 업로드**: Windows curl(schannel)·Python requests 모두 이 네트워크에서 인증서 검증 실패. `upload_assets` 받은 URL에는 **PowerShell `Invoke-WebRequest`**(Windows 인증서 저장소)로 PNG를 POST하면 됨. designer 에이전트는 업로드 도구가 없으니 imageHash를 넘겨준다.
- **Figma 모서리 0 전역 규칙**: 앱 CSS에 border-radius 0 강제가 있어 둥근 표시는 svg로 그린다(`.ic-ring` 참고).
- **G5 도구**: 2만 px 넘는 프레임에서 메모리 부족 → 비교 배열 float32, SSIM은 float64 가로 띠(`ssim(..., band=2048)`). float32로 SSIM 누적합을 하면 점수가 망가진다(오늘 한 번 겪음).
- **Chrome 확장**: 가끔 응답 없음. 화면 확인은 `app/tools/impl_gate.App`으로 같은 빌드·샘플 시드에서 Playwright 캡처가 안정적.
- **localhost:5173 브라우저 자료**: 사용자 실제 관심 전형·성적이 들어 있을 수 있음. 확인용으로 넣은 자료는 반드시 지운다.
- `knue` 같은 입학처 약칭 학과명, 캠퍼스 섞인 어디가 화면(경동대·교통대·한경대·안양대)은 캠퍼스 배정을 기존 입학처 모집단위로 했음 — 검수 때 확인.
