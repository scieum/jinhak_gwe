# 관심 전형 비교 구현 · 2026-11-20

사용자 요청: 추천 작업 1번인 관심 전형 비교부터 구현.

## 구현

- `대학 찾기 → 전형 비교`(`/compare`) 및 수시 입결 관심 목록의 ‘관심 전형 비교’, 학과 카드의 ‘이 학과 비교하기’에서 진입.
- 저장된 대학·전형·학과 중 2~4개를 선택. 학과 미지정 기록은 선택하지 못하며 기존 학과 선택 경로를 제공. 비교에서 빼더라도 하트 기록은 유지.
- 같은 입결 학년도·모집시기·등급 지표·컷/평균 기준을 공통 적용. 선택 학년도와 직전 2개 학년도를 표시. 선택과 조건은 URL에 유지하며 새로고침 시 복구.
- 모집단위, 해당 연도 전형 유형·모집인원·경쟁률, 최근 3개 학년도 컷, 산출 기준·대상, 등급제, 원문 상세 및 학과별 수집 자료 링크.
- ‘다른 점만’은 확인된 동일 값만 숨김. 학과 식별·산출 기준·출처와 미확인 항목은 유지. 숫자의 표시 자릿수만 다른 경우 동일 값으로 취급.
- 대학/캠퍼스·전형·학과·연도·시기·지표가 정확히 일치하는 원문만 연결. 여러 원문은 자동 합산/첫 행 선택 없이 연도별 직접 선택. 모집인원 등도 선택한 동일 원문을 사용.
- 50/70% 컷은 수집 원문에서 표시. 추가 컷·평균은 같은 수집본 해시의 전국 배치표 통계에서 근거·대상을 함께 표시. 9등급제와 1~9 수치를 확인하며 없는 통계를 다른 컷으로 대체하지 않음.
- 실패·미수집·미기재를 구분하고 자료 재시도 제공. 이전 요청의 늦은 응답은 효과 정리 시 무시.
- 모바일은 비교표만 가로 스크롤, 항목 열 고정. 선택 모달은 기존 키보드 초점 관리·Escape 닫기 사용.

- Figma 예시 숫자를 제품 데이터로 사용하지 않음. 새 Figma 시안이나 하네스 승인 문서를 작성하지 않음.

## 남은 범위

- 반영 교과·수능최저·면접·고사 일정은 **해당 비교 학년도**의 구조화 자료 연결 전까지 ‘해당 연도 모집요강 확인 필요’. 현재 2028 전형계획을 2026 등 과거 입결에 붙이지 않음.
- 수집본은 검수 전 참고자료. 원문 전수 검수·이용 조건 확인 완료로 바꾸지 않으며 성적 판정·합격 가능성 계산에 사용하지 않음.
- 지원 준비 기록/수시로 기능 확장은 이번 범위가 아님. 기존 버튼 동작 유지.

## 검증

- 비교 및 기존 수집 브라우저 테스트 18개 통과: 정확한 학과 연결, 중복 원문 선택, 2~4개 제한, 검색·취소, 하트 기록 보존, 오류 재시도, 추가 통계 실패 시 다른 통계로 대체하지 않음.
- 실제 로컬 자료로 강원대(춘천)·한림대·한라대·가천대 확인. 독립 브라우저 저장소에 테스트 관심만 생성하여 사용자의 관심 기록은 변경하지 않음.
- 실제 브라우저에서 2/4개 선택, 새로고침, 원문 상세/Escape, 50/70/75% 컷, 학년도 변경, 다른 점만, 관심 목록/학과 카드 진입 확인.
- 1440/1024/768/390/320px 비교표 10개, 선택 모달 3개, 관심 목록 3개 등 16개 화면에서 페이지 전체 가로 넘침 없음. 브라우저 런타임 오류 없음.
- 스크린샷·브라우저 점검 코드/결과: `outputs/interest-comparison/`(git 제외).
- TypeScript·프로덕션 빌드 성공. 기존 큰 번들 경고 유지.
- 전체 회귀 검사: 테스트 파일 43개, 테스트 387개 통과(`npm test -- --maxWorkers=2 --reporter=dot`).
