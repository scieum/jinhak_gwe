# 전국 대학 좌표 배치표 구현

요청: 기존 수집 입결을 연결해 전국 대학 배치표를 추가한다. 학생 화면에서 검수 전 참고자료로 조회하며 성적 판정에는 사용하지 않는다.

## 화면

- 경로: `/national-placement`. 대학 찾기 메뉴, 수시 입결 페이지, 기존 배치표 모달에서 진입한다.
- 가로축은 실제 발표 등급 1~9, 대학은 가나다순이다. 점이 겹치면 세로 위치만 조정한다. 세로 위치는 수치나 순위를 의미하지 않는다.
- 같은 대학·같은 수치는 한 점으로 묶고 모든 원문 행을 보존한다. 점 안 숫자는 연결된 원문 행 수이다. 클릭하면 전형·모집단위 선택과 원문 20개 필드, 출처 링크를 확인한다.
- 대학·학과·전형 검색, 학년도·모집시기·전형 유형·지표·컷·등급 범위를 제공한다. 교과등급과 수능등급을 섞지 않는다.
- 좌표는 10개 대학씩, 목록은 50행씩 보여 준다. 목록의 데이터 열 8개는 모두 헤더 정렬이 가능하다. 상세 동작 열은 정렬 대상이 아니다.
- 모바일 상세 조건은 접어서 시작한다. 그래프 내부에서 가로·세로로 이동하며 축과 대학명은 고정한다.

## 데이터와 재생성

기존 수집본 132,261행/226개 대학·캠퍼스 중 9등급제로 명시되고 교과등급 또는 수능등급이며 50%/70% 컷 중 하나 이상이 1~9의 유효 수치인 행만 색인한다. 원본 문자열과 원본 행 번호를 보존한다.

| 학년도 | 대학·캠퍼스 | 색인 행 | 전송 크기 |
|---|---:|---:|---:|
| 2026 | 157 | 16,565 | 784,112 bytes |
| 2025 | 156 | 16,436 | 781,558 bytes |
| 2024 | 149 | 15,834 | 744,288 bytes |

합계 48,835행. 화면 조건에 따라 실제 표시 수는 줄어든다. 예를 들어 2026 수시 교과등급 70% 컷은 152개 대학·캠퍼스/15,143행이다. 강원대(춘천)는 2026 수시 50% 컷 자료가 있으나 70% 컷이 없으므로 컷을 전환해야 나온다.

`app` 디렉터리에서 다음을 실행한다.

```powershell
npm.cmd run data:build-placement
npm.cmd run dev -- --host 127.0.0.1
```

수집본을 다시 가져온 후에는 `data:build-placement`를 다시 실행한다. 도구는 `app/tools/build_national_placement.py`, 배포 파일은 `app/public/data/national-placement`이다. 기존 수집 파일과 색인 파일의 바이트 크기·SHA-256 및 출처 연결을 검증한다. 수집본과 색인이 어긋나면 표시하지 않고 오류를 안내한다. 데이터는 정적 파일로 로컬에서 동작하며 이 화면은 외부 DB를 요구하지 않는다.

## 검증

- 전체 색인 행이 원문과 일치하고 조건에 맞는 원문 행이 빠지지 않는지 검사한다. 파일 해시·변조 거부·지표 분리·좌표 정확성·동일 좌표 원문 보존을 검사한다.
- 원문 선택·목록 정렬·검색·잘못된 범위·학년도 전환 중 늦게 도착한 응답·실패 후 재시도를 테스트한다.
- 실제 브라우저에서 페이지 이동, 원문 링크, 대학 검색, 컷 변경, 빈 결과, 헤더 정렬, 연도 변경을 확인했다. 320/390/768/1024px에서 문서 가로 넘침과 실행 오류가 없었다.
- 브라우저 임시 기록: `outputs/layout-review/national-placement.json`과 PNG, 재현 스크립트 `national-placement.cjs` (Git 제외).
- `npm.cmd test -- --maxWorkers=2`: 39개 파일, 358개 테스트 통과. 최초 동시 실행에서 기존 XLSX 테스트 1건이 5초 시간 제한을 초과했으나, 다른 무거운 작업 없이 전체 재실행 시 모두 통과했다.
- `npm.cmd run build`: 통과. 기존 500kB 이상 번들 경고는 남아 있다. `git diff --check`도 통과했다.

검수 전 자료 상태를 유지한다. 개인 성적과 겹쳐 지원 가능성을 판정하지 않으며, 대학별 반영 교과·산출 기준 차이를 안내한다. 좌표가 없는 대학이나 값은 추정해서 추가하지 않는다.

## 원문 선택 창 겹침 수정

- 공통 `.button-outline`의 고정 높이(PC 44px/모바일 52px)가 여러 줄 원문 선택 항목에 적용되어 설명이 다음 항목과 겹쳤다.
- 해당 목록 버튼만 `height: auto`와 최소 높이 52px를 적용했다. 제목·설명은 별도 줄로 배치하고 긴 문자열은 줄바꿈한다. 모달은 콘텐츠 행 높이를 유지하며 화면 높이가 부족하면 스크롤한다.
- 가천대 2026 학생부우수자 70% 컷 2.8의 경제학과·법과대학·인공지능학과 실제 3행으로 재현/검증했다. 1440×900, 900×600, 390×844, 320×568, 900×320에서 항목 내부 설명 수용, 항목 간격 8px, 가로 넘침 없음, 좁은 높이의 스크롤, 마지막 항목 상세 선택·목록 복귀·Escape 닫기를 확인했다.
- 관련 흐름 테스트 2개와 빌드 통과. 임시 기록: `outputs/layout-review/national-source-layout.json`, 같은 이름의 크기별 PNG.

## 그래프 전체 너비 확장

- 고정 900px 너비를 결과 패널 너비 100%로 변경했다. 대학명 열을 제외한 나머지 공간을 등급 축이 채운다. 작은 화면에서는 기존 최소 너비와 내부 가로 스크롤을 유지한다.
- ResizeObserver로 실제 축 너비를 측정해 축 눈금·격자·점 위치와 겹침 배치를 함께 계산한다. 가로 위치가 발표 등급과 일치하는 원칙을 유지하며 창 크기 변경에도 갱신한다.
- 실제 브라우저를 새로고침 없이 1920→1440→2560→1024→390→320→1920px로 변경해 검사했다. 넓은 화면에서 그래프와 내부 가용 폭이 일치(1920px 화면에서 1564px), 점 위치 오차 0.016px 미만, 점 겹침 0, 문서 넘침 및 실행 오류 없음. 점 상세 열기/닫기도 확인했다.
- 관련 테스트 7개와 빌드 통과. 임시 기록: `outputs/layout-review/national-full-width.json`, `national-full-width-1920.png` 등.
