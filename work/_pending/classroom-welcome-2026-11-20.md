# 우리 반 홈 빈 상태 개선

- Figma PC `103:191035`, 모바일 `103:190920`를 직접 수정. PC 본문 `103:191048`, 모바일 본문 `103:190923`.
- 작은 빈 상태 안내를 시작 안내·검정 주요 버튼·준비 정보·후속 3단계로 재구성했다. PC 좌우, 모바일 세로 구조이며 입력 명단은 예시로 표시한다.
- `ClassWelcome`을 우리 반 홈의 학급 미생성 상태에 연결했다. 기존 학급 만들기 폼과 서버 저장본 불러오기, 다른 교사 메뉴의 빈 상태는 유지한다.
- 학생 자료는 자동 수신이 아니라 학생이 전달한 .jnavi 파일 또는 QR을 불러오는 것으로 안내한다.
- 기존 users/plus SVG, 색상·여백 토큰, 주요 버튼 재사용. 고정 높이로 내용을 자르지 않고 모바일 단계 카드에는 최소 높이를 사용한다.
- 교사 흐름 테스트 14개 통과. 별도 브라우저에서 320/390/646/1024/1440px 가로 넘침 없음, 학급 생성 모달 열기·닫기, 명단 2명 저장 후 새로고침 유지 확인.
- Figma 컨텍스트 및 화면 캡처: `outputs/classroom-onboarding/`. 기존 실제 사용자 학급 데이터는 변경하지 않았다.
