이 문서는 2026-11-18 design-plan.md와 resume-notes.md의 Figma 미반영 목록에 대한 최신 실행 기록이다. 과거 메모의 “미완료”를 그대로 다시 작업하지 말고 아래 인덱스를 먼저 확인한다.

- 총 87개 프레임에 반영: 신규 편집 가능한 시안 71개, 로컬 앱 원본 캡처 1개, 기존 시안 15개 보완.
- 전체 페이지 33개 화면 섹션을 학생 / 교사 / 로그인·관리자 행으로 재배치. 공통 부품은 별도 참고 섹션에 보관.
- 배치표: PC 6계열·50개 학과, 모바일 계열 선택; 표·배치표·대학별 점 보기. 최신 2.0~2.3 추정 범위·대표 2.13·A-3 준비 중·교육청 실측표 설명 반영.
- 성적 입력: PDF 선택·읽기·확인·덮어쓰기·오류·반영 완료·학년별 보기, 확인 오류 2칸과 비활성 고정 CTA.
- 수시 입결: PC/모바일 점 그래프와 13행 상세 표, 10행 내 비교, 빈 상태·점 상세. 연도는 2024/2025/2026.
- 결과 집계: 모바일과 모의고사 수합 탭, 기존 상태의 메뉴·드롭다운 보완.
- 회원가입: PC/모바일, 메일 발송·약관·오류 상태.
- 신규 기능: 입시 일정(학생/교사, 한 달/목록, 겹침·상세·내보내기), 최저로 찾기(what-if), 전형 비교(빈 상태), 면접 준비(타이머·답 메모), 바로가기(외부 이동 확인).
- 로컬 앱 신규 기능: 원서·서류 체크리스트, 지원 자격 확인표, 상담 질문·할 일(각 입력/근거 상태), 전형 성향 탐색(소개·문항·결과·혼합·답변 부족).
- 전형 성향 탐색은 길콩 원본 에셋과 앱의 파스텔 팔레트를 사용. 원본 네이티브 캡처는 `130:87995`.
- 새 화면 PC 메뉴 선택과 모바일 가로 하위 메뉴를 적용. 긴 화면 35개에 세로 스크롤, 모바일 표 2개에 가로 스크롤을 설정.

검증: 대표 화면 렌더 확인, 섹션 겹침 0, 화면 내부 프레임 겹침 0, 잘못된 입력 예시 잔여 0, 스크림 40%, 6개 점 그래프의 좌표 래퍼 오프셋 0 확인. 주 시안 폰트는 IBM Plex Sans KR이며, 원본 캡처만 원래 Pretendard를 유지했다.
