# U:NAVI 서비스 소개 상세페이지

2026-11-24 사용자가 “맨처음에 서비스 소개하는” 상세페이지임을 다시 명확히 했다. 서비스에 들어가기 전에 읽는 긴 홍보·소개 페이지를 PC와 모바일로 제작했다.

## 최신 Figma 시안

- 페이지: `서비스 소개 상세페이지 · 밝은 분위기` (`840:52`)
- [PC — 1440 × 9321](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=844-12)
- [모바일 — 390 × 11743](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=844-271)

## 방향과 구성

사용자가 제공한 [Huddling](https://www.huddling.club/)의 큰 중앙 소개 문구, 캐릭터 중심 비주얼, 대상별 설명 흐름을 참고했다. 이후 사용자가 밝은 분위기를 요청하여 PC·모바일의 어두운 섹션을 흰색과 연파랑으로 바꾸고, 본문 색과 로고를 밝은 배경에 맞게 수정했다. 전체 화면 스크린샷으로 확인했다. 이전 UI Bowl 랜딩 조사와 출처는 [기존 조사 기록](home-promo-landing-2026-11-24.md)에 있다.

무료 앱이라는 사용자 지시에 따라 가격표·요금제·유료 업그레이드 안내는 포함하지 않는다. 현재 두 시안의 텍스트에도 해당 항목이 없음을 확인했다.

1. 내비게이션과 시작 버튼.
2. “2028 대입, 나의 방향을 찾는 시작.” 소개 문구와 길콩. 상단에 “2028학년도 대입을 위한 진학 길잡이”, 설명에 내신 5등급 세대·수시 6장·선생님 상담을 명시했다.
3. U:NAVI가 제공하는 진학 탐색과 준비 소개.
4. 핵심 기능 6가지: 전형계획 탐색, 내 성적 이해, 대학별 환산, 수시 6장 설계, 모의고사·최저, 선생님과 상담.
5. 학생·선생님에게 각각 필요한 도움.
6. 성적의 추정 범위를 이해하는 사용 예시.
7. 관심 대학 비교와 계획 준비 예시.
8. 수시 6장 보드와 조건·일정·고민을 함께 정리하는 사용 예시.
9. 학생 3명의 상담 준비 예시와 학생·교사의 활용 흐름.
10. 추정 정보의 해석 안내.
11. 시작하는 세 단계.
12. 자주 묻는 질문 8문항: 이용 대상, 시작 순서, 추정 등급, 대학별 환산과의 차이, 수시 6장, 교사 상담, 학생 데이터 저장·백업, 계산 가능한 전형.
13. “2028 대입 준비, U:NAVI와 함께.” 시작 안내.

## 제작 및 확인

- 기존 로고·길콩 포즈·버튼·성적 미리보기 컴포넌트 재사용.
- 반복되는 대상 소개, FAQ, 단계, 대학 예시 행, 기능 카드, 수시 카드, 상담 학생 행은 컴포넌트 인스턴스.
- 색·간격 변수와 IBM Plex Sans KR 텍스트 스타일 사용. 소개 전용 큰 제목 스타일을 추가했다.
- PC·모바일 모두 편집 가능한 텍스트·벡터·인스턴스로 제작했다. 이미지 채움은 길콩 에셋 7개씩이며 완성 화면을 이미지로 붙인 부분은 없다. PC 텍스트 174개·인스턴스 49개, 모바일 텍스트 171개·인스턴스 49개를 확인했다.
- 전체 스크린샷으로 검토 후 시작 버튼의 파란 배경, 모바일 예시 프레임과 여백, FAQ 빈 문구를 보정하고 두 화면을 다시 확인했다.
- 콘텐츠 확장 후 섹션 여백을 줄이고 본문 대비를 높였다. PC·모바일 전체 스크린샷을 확인했으며 모바일 FAQ 4번 질문을 짧게 수정하고 다시 확인했다. 기능과 FAQ의 내용은 프로젝트 PRD를 참조했고, 대학·학생 예시는 가상 구성임을 화면에 표시했다.
- 디자인 시안으로 제작했으며 사이트 구현·배포·버튼 동작 연결은 포함하지 않았다.
- 기존 시안은 보존했다. 사용자 승인 기록은 변경하지 않았다.

## 모션 추가

사용자가 길콩 바운스와 스크롤 중 컴포넌트 등장을 요청하여 Figma 네이티브 키프레임을 추가했다.

- 기존 PC·모바일 상세페이지의 히어로 길콩에도 바운스를 적용했다. PC 18px·모바일 12px로 두 번 점프하고 멈추며, 착지에 2–3% 압축을 사용한다.
- [PC 첫 화면 미리보기](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=862-442): 3.2초, 소개 문구·설명·버튼의 100ms 간격 등장과 길콩.
- [모바일 첫 화면 미리보기](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=862-457): 3.2초, 모바일 강도로 동일 흐름.
- [PC 기능 카드 미리보기](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=862-469): 2초, 90ms 간격으로 20px 상승·페이드 인.
- [모바일 스크롤 진입 미리보기](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=862-484): 390×844 화면에서 콘텐츠를 861px 이동시키는 7초 타임라인 시뮬레이션. 실제 사용자 스크롤 이벤트 연결은 구현하지 않았다.
- [모션 가이드](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=866-522): 웹 구현 시 화면 하단 10% 안쪽 진입 시 1회 재생, 되돌아갈 때 다시 숨기지 않음, 동작 줄이기 설정에서 이동·점프 비활성화. 이 조건들은 구현 지침이며 현재 웹에 적용된 상태는 아니다.
- `service-intro-motion/hero.mp4`, `cards.mp4`, `scroll.mp4`로 렌더링했다. ffmpeg로 각 영상의 4개 시점을 추출해 바운스의 정점·착지, 카드 등장 순서, 스크롤 진행과 마지막 카드 표시를 시각 확인했다.
- FAQ와 본문은 가독성을 위해 제자리에 유지한다. 모션은 기존 화면 편집성과 색·레이아웃을 유지한다.

## 2028 대입 타깃 강조

사용자 요청에 따라 PC·모바일 첫 화면의 큰 제목에 2028 대입을 명시했다. 서비스 정의, 전형계획 기능 카드, 마지막 시작 안내에도 2028학년도 타깃을 반영했다. Figma 모션 미리보기 4개에도 같은 문구를 적용했고 기존 키프레임은 보존했다. PC·모바일 첫 화면 스크린샷으로 줄바꿈을 확인했다. 로컬 MP4 파일은 문구 변경 전 모션 검수본이며 최신 문구는 Figma가 기준이다.

## FAQ 번호 강조

사용자가 제공한 FAQ 화면을 기준으로 번호를 질문 문자열에서 분리했다. 40×40 연파랑 배경에 파란색 숫자를 표시하고, 질문·답변은 오른쪽 열에 정렬했다. PC 간격은 24px, 모바일은 16px이며 기존 구분선을 유지했다. 새 컴포넌트 `872:522`의 Number·Question·Answer 속성으로 PC·모바일 16개 항목을 구성했다. 두 FAQ 섹션의 스크린샷을 확인했다.
