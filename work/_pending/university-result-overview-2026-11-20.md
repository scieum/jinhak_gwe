# 대학별 수시 입결 시안 누락 보완

## 문제와 반영

기본 화면은 수집 자료 표였고 기존 좌표 그래프는 검수 완료 자료 탭에만 있었다. 검수 완료 자료가 없으면 그래프가 나타나지 않았으며, 시안의 비교 기준 패널도 기본 조회 화면에 없었다.

- `/admission-results` 기본 탭을 ‘대학별’로 변경했다. 수집 자료·검수 완료 입결·관심 전형은 별도 탭으로 유지하고 기존 `cu/cp/cd`, `u` 링크도 유지한다.
- 대학 로고·대학 변경 검색, 교과/종합/논술/기타/전체 유형, 전형 선택, 학과 검색, 최근 3년 70% 컷 그래프, 학과별 관심 저장, 비교 기준 패널을 연결했다.
- 기존 해시·바이트 검증 로더로 로컬 수집 자료를 읽는다. 수시 자료의 최신 학년부터 3개 학년 범위에서 9등급제·교과등급·유효한 70% 컷(1~9)만 좌표로 표시한다. 없는 연도를 예전 연도로 대체하지 않는다.
- 원문이 여러 개인 같은 학과·연도의 행도 덮어쓰지 않는다. 각 점에서 원문 상세의 모든 열과 정밀도, 출처·쪽수·산출 기준을 확인한다. 전형·학과 이름이 변경된 기록은 임의로 연결하지 않는다.
- 10학과 단위 페이지, 연도별 점 위치 분리, 자료가 없는 학과 안내와 전체 표 링크를 제공한다. 그래프 대상이 아닌 값도 기존 표에서 조회할 수 있다.
- 내 성적은 기존 5 to 9 계산을 사용하며 입력이 없으면 입력 안내를 표시한다. 예시 숫자를 실제 성적으로 넣지 않는다. 검수 전 입결은 성적 차이·판정에 쓰지 않는다.
- 선택 대학·전형·유형은 URL에 보존한다. 로딩·실패·재시도 및 대학 변경 중 늦게 도착한 응답 처리를 포함한다.

## 검증

- 관련 5개 테스트 파일, 45개 테스트 통과. 신규 검증은 최근 3년 범위·지표 제한·같은 연도의 복수 원문, 기본 진입·원문·학과별 관심·표 이동, 대학 변경 응답 경합·빈 상태·재시도를 다룬다.
- `npm.cmd run build` 및 diff 공백 검사 통과. 기존 번들 크기 경고는 유지된다.
- 격리한 Edge에서 실제 경희대(서울) 지역균형전형 자료를 확인했다. 기본 경로, 대학 검색·변경, 점 원문, 관심 저장, 비교 기준 모달, 탭 복귀·새로고침, 전체 표 이동 확인.
- 1920/1440/1024/768/390/320px에서 문서 가로 넘침 및 JavaScript 오류 없음. 넓은 화면은 그래프와 비교 패널을 나란히, 좁은 화면은 세로로 표시하고 그래프만 가로 스크롤한다.
- QA 기록: `outputs/layout-review/university-overview.json`, `university-overview-*.png`.
