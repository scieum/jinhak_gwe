## 검증

- 전체 테스트 41개 파일, 374개 통과 (`npm test -- --maxWorkers=2`). 초기 전체 병렬 실행의 시간 초과는 작업자 2개로 재검증했고, 문구 규칙 위반과 링크 이름이 중복된 테스트 질의는 수정했다.
- TypeScript 검사 및 프로덕션 빌드 성공. 기존 대형 번들 경고는 남아 있다.
- 37개 경로·탭 × PC 1440 / 모바일 390 = 74개 렌더링: 페이지 가로 넘침·콘솔 실행 오류 0건.
- 주요 7개 화면 × 320 / 390 / 768 / 1024 / 1440 / 1920 = 42개 레이아웃: 가로 넘침·깨진 로고 0건. PC 3×2 / 모바일 단일 열을 좌표로 확인.
- 학과별 하트 해제, 내 성적 분석 링크, 수시로 순위 이동·메모 저장, 대학별 환산 행 선택, 원점수 저장 후 새로고침, 백업 직접 링크, 입결 점 12개 각각의 상세 열기를 확인.
- 검수 브라우저는 별도 프로필이다. 실제 사용자 저장 데이터는 변경하지 않았다. 대학별 환산 표는 브라우저 안에서만 주입한 합성 검수 규칙으로 확인했고, 운영 배포 데이터에는 추가하지 않았다.
- 자료: `outputs/figma-alignment/after/`, `outputs/figma-alignment/flows/`, `outputs/figma-alignment/tests-final.json`. 검수 스크립트와 Figma 원본 컨텍스트도 같은 폴더에 있다.

## 시안과 의도적으로 다른 부분 / 미완료 범위

1. 시안의 D-day 예시 대신 실제 저장한 지원 준비·관심 항목 수를 표시한다. 확정 일정 공급원이 아직 없다.
2. 시안의 대학별 점수·판정·최저 충족 숫자는 검수된 실제 데이터가 있을 때만 표시한다. 현재 공개 규칙이 없는 화면의 빈 상태는 정상이다.
3. 실제 수집 자료를 선택할 전형·학과 검색과 검수 상태 안내는 유지했다. 수시 입결의 ●는 개별 학생이 아니라 대학 발표 70% 컷이다. 불합격 ×는 사용자 결정대로 추후 업데이트 사항이다.
4. 모바일 수시로의 시안은 드래그 손잡이를 사용하지만 현재 순위 변경은 위·아래 버튼으로 작동한다. 키보드 조작과 저장 동작을 유지했다.
5. Figma에만 있는 별도 화면은 현재 앱 경로에 없다: 일정(129:85931), 최저로 찾기(129:86483), 전형 비교(129:86966), 면접 준비(129:87430), 공식 링크(129:87683). 이는 색상·간격 수정이 아닌 신규 기능·데이터 연결 범위로 PLAN.md에 분리했다. 전체 Figma 화면의 100% 구현 완료로 표시하지 않는다.
