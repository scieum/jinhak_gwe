# 실제 대학 지도 연결 인수인계

사용자 결정: 실제 앱 데이터와 지도까지 연결(2026-11-25). Figma 수정은 이번 작업 범위가 아니다.

- 기존 디렉터리 196개 대학 모두 연결. DGIST 추가: 197개 대학, 244개 캠퍼스, 17개 시도.
- `app/public/data/univ-map.json`은 교육부 원본 + 출처 명시 보완 자료로 생성. 공개 소스 데이터 v2와 기존 2인 검수 데이터 v1을 구분한다. 임의 검수자나 가짜 승인 기록 없음.
- 샘플 성적 모드에서도 실제 위치를 사용한다. Figma 고정 시안 대조 시에만 `VITE_MAP_DESIGN_FIXTURE=true`를 빌드 환경에 설정한다. 일반 배포 환경에는 설정하지 않는다.
- 화면의 시도별 집계, 대학 검색, 캠퍼스 선택, 위치 핀, 주소, 원문 링크 연결 완료. 대학 수 표시는 기존 시안 규칙에 따라 캠퍼스를 따로 센다.
- 기존 코드만 공개 방침에 따라 수집 원본과 생성 지도 JSON은 로컬에서 유지하고 gitignore에 추가했다. 실제 배포 자료 번들에는 지도 JSON을 포함하고 필수 파일로 검사한다.
- 지도 테스트 30개와 배포 자료 테스트 6개, 타입 검사, G5 통과. 실제 빌드 Chromium 모바일·PC 검증 통과. 원격 배포·커밋·푸시는 하지 않았다.

원본 기준일은 2025-11-26이다. 전체 물리적 캠퍼스 전수 조사는 아니며, 현재 앱에 있는 대학별 위치 연결을 완료한 상태다. 출처·제외 항목·갱신 절차는 `work/_data/university-map/README.md`에 있다.
