# 순차 개발·데이터 반영 기록

2026-11-24. 사용자가 지정한 순서(목표 대학 백업 → 지원 준비 화면 → 우선 대학 데이터)로 진행했다. 커밋·외부 배포는 수행하지 않았다.

## 1. 목표 대학 순위 저장과 백업

- StudentDatabase v6의 preferences 테이블에 최대 3개 지원 전형 ID와 순서를 저장한다. StudentBackup.targetPriorities에 포함되므로 기존 암호화 백업에서 함께 복원된다.
- 기존 localStorage 순위는 기본 학생 DB에서 한 번 이전한다. 중복·삭제된 ID는 제거하고, 이미 DB 설정이 있으면 기존 브라우저 값을 다시 덮어쓰지 않는다.
- 성적만 있는 구버전 백업은 순위를 유지한다. 전형 목록을 포함한 구버전 백업은 복원된 전형에 연결되는 순위만 유지한다. 명시적 빈 배열은 그대로 보존한다.
- 전형 삭제·전체 데이터 삭제·샘플 백업 제외 시 순위 연결도 정리한다. 잘못된 참조·중복·4개 이상 순위가 있는 백업은 원본 데이터를 변경하기 전에 거절한다.
- 저장 실패 시 선택창을 유지하고 재시도를 제공한다. DB 저장이 끝나기 전 성공 알림을 표시하지 않는다.
- 검증: 암호화 왕복, v5→v6 업그레이드, 저장 후 DB 재연결, 구버전 복원, 손상 백업 거부, 샘플 제외, 브라우저 새로고침·삭제 흐름.

## 2. 지원 준비 화면

- Figma 원본: application-checklist 668:210274 / 670:210435, eligibility-check 682:218325 / 683:218459.
- 원서·서류 체크리스트: 모바일은 전형 선택 → 전형 정보·집계 → 항목 카드 → 바로가기, PC는 항목·진행 상태·마감·확인 기록·자료·동작 표로 표시한다.
- 지원 자격 확인표: 전형 정보, 집계 타일, 상태 배지·근거·확인 기록 카드의 모바일/PC 구성을 반영했다.
- 페이지 설명과 추가 버튼은 실제 PC 헤더에 연결한다. 모바일·PC 전환 및 언마운트 시 React portal로 정리된다.
- 수정·삭제 접근성 이름을 유지하고, 화살표 장식은 접근성 이름에서 제외했다. 320·390·1440px에서 페이지 가로 넘침 없음.
- **G5는 미통과다. 화면 구현을 완료로 판정하지 않는다.**

최종 오류는 위치·아이콘·픽셀 비교 등에 남아 있다. 시안의 전형명과 현재 공통 샘플 전형명이 다르고, 시안의 2026-11-20 마감 상태는 현재 날짜와 다르다. 긴 실제 전형명을 잘라내거나 마감 상태를 과거로 고정하지 않았다. 공용 로고·탭 구성 차이도 남아 있다. 체크리스트 PC data-table은 시안의 셀 인스턴스를 실제 전체 표와 짝짓는 C/Z 오류가 남는다. 모바일 안내 문구는 전체 내용이 보이도록 줄바꿈하며 시안의 한 줄 높이와 다르다. 임의 예외나 게이트 로직 변경은 하지 않았다.

## 3. 우선 대학 검수 자료

`python app/tools/build_priority_review.py`로 강원대 4개 캠퍼스·한림대·가톨릭관동대·한국교원대 자료를 생성한다.

- 7개 패키지, 수능 최저 원본 규칙 942건, 전형·모집단위 조합 2,400개.
- 연결 1,768 / 명시적 보류 45 / 미분류 587. 보류·미분류를 최저 없음으로 바꾸지 않는다.
- 원본 JSON과 정규화 입력 해시, 원문·HWP 추출본 9개 파일 해시, 규칙 JSON 포인터와 원본 객체 일치를 검사한다. 모든 패키지를 검사한 뒤 산출물을 쓴다.
- 각 패키지에 원문 URL·해시·페이지/HWP 표 번호·원래 환산 조건·조건 해석 보류 이유·적용 조합을 함께 묶었다. CSV 검수 목록도 제공한다.
- 공식 원문 파일 7개를 다시 내려받았으며 모두 보관본과 SHA-256이 일치했다. 한림대·강원대 기존 공지도 다시 열었다. 한국교원대 공지 웹 열람은 403, 가톨릭관동대 다운로드 웹 도구는 502였으나 직접 파일 다운로드 검사는 성공했다. 사이트 전체의 최신 문서임을 확인한 것은 아니다.
- 한림대 공지는 세부내용을 추후 수시·정시 모집요강에서 확인하도록 안내한다. 전형계획을 최종 모집요강으로 표시하지 않는다.
- 환산 엔진 확장 필요 조건, 한국교원대의 동점자 처리 전용 자료를 별도로 표시한다. 검수자·승인일·독립 기대값 테스트는 비워 두었다.
- **계산용 검수 완료 자료는 추가하지 않았다.** 모든 산출물은 draft / executable=false이며 앱의 scoring-rules.json은 변경하지 않았다. 조건 확인·독립 기대값 테스트·기존 관리자 검수 절차가 필요하다.
