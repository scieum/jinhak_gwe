# 대학별 데이터 수집 실행 계획

시작일: 2026-11-22 (Asia/Seoul). 사용자 요청: 필요한 순서대로 계획하고 자동으로 계속 진행.

## 범위와 완료 기준

2028학년도 전국 4년제·교육대와 별도 관리하는 특수학교를 대상으로 한다. 전문대는 기존 제외 범위를 유지한다. 2024~2026 입결은 과거 자료로 연결하며 2028 전형·학과와의 동일성을 자동 추정하지 않는다.

대학 → 캠퍼스 → 학년도 → 전형 → 모집단위 단위로 관리한다. 원문 확보, 추출, 기계 검증, 사람의 독립 검수, 서비스 배포는 별도 상태다. 기계 검증 통과를 사람 검수 완료로 바꾸지 않는다. 자료가 없는 필드는 0/없음으로 만들지 않고 미확인·해당없음·원문 미기재·추후 공지·접근 실패를 구분한다.

학교의 현재 단계가 완료돼도 다음 대학으로 계속 진행한다. 공식 자료 미공개·접근 제한·원문 모순은 근거와 재시도 조건을 남기고 독립적으로 진행 가능한 다음 항목으로 이동한다. 같은 실패를 무한 재시도하지 않는다. 원격 공개 배포·커밋·푸시는 수집 절차에 포함하지 않는다.

## 실행 순서

1. **기준 대장**: 현재 218개 계획 항목, 입결 표기명 226개를 재집계. 출처·로컬 원문 해시와 추출 상태를 기록. 대학명 매핑은 제안과 확인을 분리.
2. **한림대 시범 완성**: 공식 첨부 재확인 → 전형 목록 → 모집단위 표 → 지원자격 → 최저 조건 → 교과·출결·수능 환산 → 학종·면접·실기·학폭 반영 → 미공개 일정 → 과거 입결 연결 후보. 원문 모순/엔진 미지원은 별도 문제 목록.
3. **기확보 우선 대학**: 강원대 춘천, 강원대 삼척·도계, 가톨릭관동대, 춘천교대, 가천대, 한국교원대, 포항공대. 다음으로 강원권 나머지(강릉·원주 자료 범위 확인, 상지대·한라대·경동대·연세대 미래).
4. **전국 확대**: 수도권 → 충청 → 인천·제주 잔여 → 대구·경북 → 부산·울산·경남 → 광주·전북·전남 → 특수학교 잔여. 자료가 이미 있는 항목부터 처리하되 원문 PDF/HWP 확보만으로 완료 처리하지 않는다.
5. **입결 공백·연결**: 기존 지역 공백 보고서를 현재 통합본과 재대조. 공식 입학처 우선, 대학 제공 어디가로 보충. 동일 지표/모집단위/전형의 연도별 연속성을 확인하고 개편·신설·통합은 별도 관계로 기록.
6. **검수 준비**: 형식·참조 무결성, 모집인원 합계, 범위, 출처, 예외, 표의 병합셀 점검. 독립 검수자가 볼 체크리스트와 공식 계산 대조 사례를 준비. 사람 검수 및 이용 조건 확인 전 운영 계산에 연결하지 않는다.
