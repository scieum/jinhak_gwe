# 승인 시안 적용 및 전체 화면 검수

사용자 승인: “시안 좋아 이렇게 다른 쪽도 전체 검수하고 적용하자.” (2026-11-20)

기준: [입결 PC 시안](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=236-103727), [모바일 시안](https://www.figma.com/design/AqkVdYZ4hvPYuAlewoBs4W?node-id=236-104184).

## 적용

- 공통 셸: PC 상단바는 경로와 모드, 본문은 페이지 제목을 맡는다. 회색 작업 배경 위에 흰 조건·결과 패널과 24px 간격을 적용했다. 기존 색·간격·글꼴·직각 모서리 토큰을 사용한다.
- 수집 입결: 자료 탭과 대학·학년도·모집시기·전형 유형을 조건 패널에, 대학·검수 상태·결과 수·전형 검색·표를 결과 패널에 배치했다. 대학 검색 창을 추가했다.
- 모바일 입결: 조건 시트의 변경은 적용할 때만 반영한다. 닫기/Escape는 초안을 취소한다. 표는 모집단위·50%·70% 컷을 보여 주고 각 행에 학년도·전형·지표를 함께 표기한다. 상세는 기존 원문 20개 필드를 모두 유지한다.
- 검수 완료 입결, 전형계획, 모의고사, 성적 입력·추이·환산, 될각, 지원 준비, 수시로, 생기부 입력, 교사 성적 불러오기, 관리자 검수에 동일한 영역 구분을 적용했다. 기존 카드·목록과 상담·누가기록·최저 보드의 표면도 정리했다.
- 교사 `ClassGate`가 학급 로드 이후 공통 `student-screen teacher-screen` 래퍼를 반환하지 않던 문제를 수정했다. 학급 생성 전후 모두 제목·간격·입력 스타일이 유지된다.
- 모바일 탭의 글자 중간 줄바꿈, 성적 입력의 PC 전용 툴바 노출, 짧은 페이지에서 배경이 끊기는 문제를 수정했다. 넓은 데이터 표는 표 내부에서 가로 스크롤한다.

## 검수 범위와 재현

로컬 Vite http://127.0.0.1:5173 에서 설치된 Edge를 Playwright로 실행했다. 별도 브라우저 컨텍스트에 가상 학급 3명, 내신 1과목, 가상 지원 전형 1건, 교사 모의고사·학기 평균을 넣었다. 사용자 브라우저와 기존 데이터는 사용하지 않았다. 입결과 전형계획은 앱에 포함된 실제 수집 자료를 조회했다.

33개 경로를 1440×1000 및 390×844에서 확인했다(66개 화면). 경로별 화면 캡처·실행 오류·문서 너비·스크롤 영역 밖 넘침을 점검했다. 추가로 주요 8개 경로를 320/768/1024px에서 확인했다(24개).

- `app`에서 `npm.cmd run build`: 통과. 기존 500kB 이상 번들 경고는 남아 있다.

## 범위의 한계

검수 전 입결·전형계획의 출처, 정밀도, 검수 상태와 성적 판정 제외 정책을 유지한다. 전국 대학 좌표 배치표에 수집본을 연결하는 작업은 이번 UI 적용에 포함하지 않았다. 공개 데이터가 없는 상세·계산 화면은 빈 상태를 확인했으며, 33개 경로의 모든 업무 분기나 실제 서버 전송까지 검증했다는 의미는 아니다. 로그인·회원가입은 화면 진입만 확인했다.

작업 중 존재한 인증·계정·Supabase·NEIS 변경과 다른 테스트 변경은 별도 작업으로 보존했다. 이번 기록은 로컬 코드 적용 결과이며 추가 커밋·푸시는 수행하지 않았다.


## 후속 요청: 입결 헤더 정렬

- 수집 자료의 학년도·시기·전형·모집단위·모집·경쟁률·50% 컷·70% 컷·지표를 헤더 클릭으로 정렬한다. 상세 버튼 열은 데이터 값이 아닌 동작 열로 유지한다.
- 검수 완료 입결 표의 모집단위·전형·연도별 컷·전년 대비·경쟁률·모집·기준·원문 주소도 정렬한다. 좌표 그래프의 배치에는 영향을 주지 않는다.
- 클릭마다 오름차순/내림차순 전환, 방향 화살표와 `aria-sort`, 키보드 버튼 조작을 제공한다. 수집본은 필터 적용 후 전체 행을 정렬하고 50행으로 나눈다. 정렬 변경 시 첫 페이지로 돌아가며 원문 순서 복귀를 제공한다.
- 숫자는 소수·음수·천 단위 구분을 처리하며 원래 표시 문자열을 보존한다. 빈 값과 숫자로 해석할 수 없는 값은 양방향 모두 마지막이다. 같은 값은 기존 순서를 유지한다. 문자 열은 한국어 및 이름 속 숫자 순서로 정렬한다.
- 회귀 검사: `table-sort`, `collected-browser`, `result-browser`의 15개 테스트. 실제 수집 자료로 PC 1440px의 9개 데이터 열, 모바일 320/390px의 표시 열 3개를 클릭·Enter로 정렬하고 숫자 순서·빈 값·원문 순서 복귀를 확인했다. 자료 원본 및 성적 판정 정책은 유지한다.
- 브라우저 기록: `outputs/layout-review/sorting.json`, `sorting-320.png`, `sorting-390.png`, `sorting-1440.png`.

## 후속 요청: 전형계획 대학 목록 밀도와 헤더 구분

- 전형계획 목록은 1600px 이상에서 4열, 1200~1599px에서 3열, 768~1199px에서 2열, 모바일에서 1열로 표시한다. 한 페이지는 3열·4열에 모두 맞는 24개이다.
- 대학 목록 헤더는 회색 배경과 2px 하단 구분선으로 카드 영역과 분리한다. 대학 수는 제목 옆 보조 정보로 표시한다.
- 카드 여백을 16px로 줄이고 대학명·캠퍼스 정보와 원문 형식·보기 동작 사이에 구분선을 넣었다. 원문 보기 버튼은 카드 하단 오른쪽에 배치했다.
- 실제 브라우저 1920/1600/1440/1200/1024/768/390/320px에서 열 수·24개 카드·헤더 구분선·문서 및 카드 넘침 없음·상세 열기/닫기·실행 오류 없음을 확인했다.
- 관련 기존 테스트 8개 및 빌드 통과. 기존 큰 번들 경고는 유지된다. 브라우저 기록은 `outputs/layout-review/plan-grid.json` 및 `plan-grid-*.png`이다.

## 후속 요청: 수집 입결 목록에서 바로 하트 저장

- PC에서는 전형명 옆, 모바일에서는 모집단위 제목 옆에 44px 하트 버튼을 제공한다. 상세 열기와 별도 버튼이며, 눌러도 상세 창은 열리지 않는다.
- 기존 `InterestButton`/학생 IndexedDB 저장소를 재사용한다. 저장 단위는 대학+전형이므로 같은 대학·전형의 다른 학과·연도도 함께 표시되며 중복 저장하지 않는다. 이름이 없는 전형에는 버튼을 표시하지 않는다.
- 새로고침·재진입·정렬 후에도 저장 상태를 유지한다. 하트 상태와 접근성 이름을 갱신하고 저장 실패를 표시한다. 검수 전 자료의 판정 제외 정책과 원문은 유지한다.
- 관심 전형 목록의 ‘수집 입결에서 찾기’로 대학과 전형 검색 조건을 복원한다. 정시도 검색할 수 있도록 직접 링크는 모집시기 전체로 시작하며, 수집 목록에 없는 대학은 안내한다.
- 관련 테스트 22개 통과: PC/모바일 저장·전형 단위 중복 방지·관심 탭·복귀 링크·재진입·해제, 기존 백업/복원·저장 실패·저장 한도 포함. 빌드와 변경 파일 공백 검사 통과.
- 실제 브라우저 1440/390/320px에서 같은 전형 4행의 하트 동기화, 새로고침 유지, 정렬, 관심 탭, 수집 입결 복귀, Enter로 해제, 빈 관심 목록 복귀를 확인했다. 문서 가로 넘침과 실행 오류 없음. 임시 기록: `outputs/layout-review/collection-hearts.json`, `collection-hearts-*.png`.

## 정정: 관심 저장은 선택한 학과만

사용자가 전형 전체가 아닌 원하는 학과만 저장되어야 한다고 정정했다. 위 전형 단위 동작은 아래 구현으로 대체한다.

- 관심 식별자는 대학+전형+학과이다. 같은 조합의 다른 연도만 함께 표시하며, 같은 전형의 다른 학과 및 같은 학과의 다른 전형은 독립적이다. 하트는 학과명 옆에 배치했다.
- 기존 2개 이름 ID와 백업은 호환성을 유지한다. 학과 정보가 없는 기존 항목은 ‘학과 미지정’으로 표시하고 학과 선택 링크를 제공한다. 원하는 학과를 저장하면 같은 대학·전형의 미지정 항목만 한 트랜잭션에서 대체한다. 사용자 선택 없이 학과를 추측하거나 전부 등록하지 않는다.
- 500개 한도에서도 기존 항목을 학과 항목으로 대체할 수 있고, 쓰기 실패 시 기존 항목을 보존한다. 다른 학과의 관심 기록은 삭제하지 않는다.
- 관심 목록은 학과명을 표시하고 학과 검색을 지원한다. 입결 복귀 링크는 전형·학과를 정확히 일치시켜 표시하며 ‘학과 선택 해제’로 전체 조회에 복귀한다. 지원 준비에도 선택한 모집단위를 전달한다.
- 대학 상세에서는 관심 학과 선택으로 이동하며, 전형 상세도 모집단위별 하트로 저장한다. 전형 전체를 새로 저장하는 UI를 제거했다.
- 회귀 검증: 전체 39개 파일 365개 테스트 통과 후, 대학·전형 상세의 후속 변경은 관련 19개 테스트 재검사 통과. 최종 빌드와 변경 파일 공백 검사 통과. 기존 큰 번들 경고는 유지된다.
- 실제 가천대 가천의약학 자료로 1440/390/320px 검증: 의예과 3개 연도만 선택, 약학과·한의예과 미선택, 새로고침 유지, 약학과 별도 저장 후 의예과만 해제, 미지정 항목 대체, 약학과 정확한 복귀(3행), 지원 준비 모집단위 전달을 확인했다. 오류·문서 가로 넘침 없음. 임시 산출물: `outputs/layout-review/department-hearts.json`, `department-hearts-*.png`.
