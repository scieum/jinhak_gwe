# 수시 입결 실제 데이터 연결

사용자 요청: 정리한 수시 데이터를 실제 화면에 구현(2026-11-25).

## 동작

- `/admission-results` 대학별 그래프·표에서 101,406행/227개 대학·캠퍼스 원문 묶음을 사용한다. 개인 성적 샘플 모드에서도 실제 수시를 읽는다.
- `/admission-results?view=collected&scope=susi`는 수시 전용 원문 표다. 대학별 화면 하단 링크로 이동한다. 기존 scope 없는 수집 경로는 수시·정시 링크 호환을 유지한다.
- 정리 당시 확인 필요 3,027행은 그래프에서 제외하고 표·상세에 사유와 원문값을 표시한다. 검수 완료나 정확성 검증을 자동 부여하지 않는다.
- 같은 학년 여러 출처·지표 값을 첫 행으로 축약하지 않는다. 표에서는 각 값을 보존하고 지표·산출 기준이 다르면 표시한다. 상세에서 출처별 모든 원문을 연다. 선택한 그래프 점의 출처가 상세 버튼에 연결된다.
- 학년도 선택은 그래프와 표 양쪽에 적용한다.
- 조회 전용 경로이며 기존 공개 승인 파일·성적 판정 엔진은 변경하지 않았다.

## 데이터 갱신

앱 폴더에서 `npm.cmd run data:build-susi`: 정리 → 원본·정리본 해시 검증 → 행별 확인 항목 포함 배포 묶음 생성. `data/susi-results/index.json`은 마지막에 쓰고 각 대학 파일은 내용 해시 파일명으로 쓴다. 로더가 해시·바이트 수·시기·확인 항목 인덱스를 검증한다. 배포 검사에서는 전체 입결 수집본과 수시 원본 해시 일치를 요구한다.

## 검증

- 주요 수시·원문 조회·검수 회귀 테스트 4개 파일 28개 통과. 다른 입결 관련 테스트도 작업 중 통과.
- 배포 자료 Python 테스트 7개 통과. 타입 검사 포함 `build:deploy` 통과.
- `admission-results` G5 통과(390px SSIM 0.9653 / 1440px 0.9859). 기존 글꼴 허용 기록 유지, 새 예외 없음.
- G5 고정 예시만 `VITE_SUSI_DESIGN_FIXTURE=true`로 실행. 일반 배포는 설정하지 않는다.
- 실제 자료 브라우저 확인 도구와 캡처는 `work/_cache/susi-runtime-smoke.py`, `work/_cache/susi-runtime-smoke/`에 둔다.
- 최종 배포 빌드 Chromium 390px·1440px에서 경희대 국제 실제 자료의 점 선택 → 학과 상세 → 원문 → 수시 전용 표 이동 통과. 페이지 오류·가로 넘침 0건. 새 수시 경로만 요청하며 전체 132,605행 패키지를 중복 요청하지 않음을 확인했다.
- 실제 화면의 날짜는 파일 생성 시각을 한국 시간으로 표시한 ‘자료 정리일’이다. 원문 재검수일이나 최신 발표일로 표현하지 않는다.

로컬 구현·배포 빌드까지 수행. 원격 서버 배포·커밋·푸시 없음. 다른 세션의 그래프 확대·축소 변경과 화면 변경을 보존했다.
