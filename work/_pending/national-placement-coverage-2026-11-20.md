# 전국 배치표 연결 전수 대조 및 확장

## 범위

로컬 수집 패키지 226개 대학·캠퍼스, 2024~2026학년도 132,261행을 전국 배치표와 전수 대조했다. 대학 공식 PDF를 전부 재열람한 내용 검수나 이용 조건 승인이 아니다. 자료의 `draft` 상태 및 성적 판정 제외 정책을 유지한다.

기존 `national-placement-2026-11-20.md` 및 `gangwon-placement-audit-2026-11-20.md` 이후 변경 사항이다.

## 결과

- 수집 226곳 모두 목록·원문 연결. 선택 학년도 자료가 없는 캠퍼스도 숨기지 않는다.
- 2024~2026 중 하나 이상의 등급 좌표가 있는 대학·캠퍼스: 170 → **211곳** (+41).
- 기존 50%·70% 컷으로 좌표가 있던 원문 48,835행 유지. 추가 통계로 원문 **26,702행**을 더 연결해 총 **75,537행**이 하나 이상의 좌표를 제공한다.
- 지표가 다르거나 비어 있는 38,415행, 9등급제 미확인 168행, 지원하는 기준의 단일 수치가 없거나 모호한 18,141행도 색인과 원문 연결을 유지한다. 숫자를 추정하지 않는다.
- 기본 조건(2026·수시·교과등급·70% 컷)은 기존과 동일하게 152곳/15,143행이다. 211곳은 모든 학년도·지원 통계를 합친 범위이며 한 화면에 동일 기준으로 211곳을 비교한다는 뜻이 아니다.

전 대학·연도별 행 수, 컷·평균별 수, 사유별 집계:

- `national-placement-audit-2026-11-20.csv` (226곳 × 3개 학년도)
- `national-placement-audit-2026-11-20.json` (원본 해시, 집계, 대학 목록)

## 구현

- 색인 v2는 좌표 가능 여부와 관계없이 원본 행을 모두 보존한다. 원본 대학 패키지의 SHA-256, 행 번호, 필드 값으로 연결하며 조회 시 무결성을 검사한다.
- 컷 50/70/75/80/85/90/100%와 평균을 분리한다. 대학 반영/환산·전과목·상위 9과목·국영수사과 평균도 각각 다른 선택지다.
- `cut_other`에 명시된 지표만 해석하며 추출 근거 문자열·원문 대상(최종등록자/합격자/1단계 등)을 상세와 좌표 목록에 표시한다.
- 명시된 최종등록자 통계가 있으면 그 값을 우선한다. 동일 기준에 상충하는 값, 숨김 표시, 범위, 총점/백분위, 통합 전형의 평균을 개별 전형에 적용하는 경우는 좌표로 만들지 않는다.
- ‘수집 대학 226’에서 해당 연도 행 수, 현재 좌표 행 수, 미표시 사유, 통계별 이동 버튼, 원문 링크, 수집 학년도를 제공한다. 전체 열 정렬·미표시 대학 필터·페이지 이동을 지원한다.
- 대학명 검색은 ‘강원대학교’와 ‘강원대’처럼 대학교/대 표기를 함께 찾는다. 과거 대학명·캠퍼스의 임의 병합은 하지 않는다.
- 75%를 70%로 바꾸지 않는다. 검수 완료 입결·성적 판정·불합격 × 기능을 변경하지 않는다.

## 현재 원문 연결만 제공하는 15곳

경찰대학, 공주교육대학교, 광주과학기술원(GIST), 국립한국교통대학교(통합), 대구예술대학교, 서울장신대학교, 아신대학교, 영산선학대학교, 예원예술대학교(전북희망), 용인대학교, 울산과학기술원(UNIST), 포항공과대학교, 한국과학기술원(KAIST), 한국에너지공과대학교, 한국예술종합학교.

이 목록은 현재 로컬 수집본에 표시 가능한 등급 통계가 없다는 뜻이다. 대학이 입결을 공식적으로 미공개했다는 판정이 아니다. 원본에 새 수치가 추가되면 같은 빌드·감사 명령으로 재생성한다.

## 재현 명령

`app/`에서:

```text
npm run test:placement-statistics
npm run data:build-placement
npm run data:audit-placement
npm test -- tests/national-placement.test.ts tests/national-placement-flow.test.tsx --maxWorkers=2
npm run build
```

브라우저 검증 스크립트: `outputs/national-coverage/check.cjs`. 수집 대학 226개 페이지 순회, 추가 컷 선택, 원문 상세, 좌표 없는 대학의 수집 자료 이동, 1440/1024/390/320px의 좌표·대학 목록 화면을 검사한다.

검증 결과: 전체 앱 42개 파일/380개 테스트 통과, 통계 추출 Python 8개 테스트 통과, 최종 배치표 회귀 10개 테스트 통과, TypeScript·프로덕션 빌드 성공. 실제 브라우저에서 226곳 연결과 8개 화면 크기/보기 조합 검사 통과(가로 넘침·런타임 오류 없음). 기존 대용량 번들 경고는 유지된다.
