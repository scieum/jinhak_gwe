# U:NAVI 서비스 홍보용 메인 페이지

> 후속 정정: 최종 작업 범위는 서비스 진입 전에 처음 보는 **서비스 소개 상세페이지**다. 사용자 제공 Huddling 레퍼런스를 반영한 최신 PC·모바일 시안은 [service-intro-detail-2026-11-24.md](service-intro-detail-2026-11-24.md)에 기록했다. 아래 시안은 이전 방향으로 보존한다.

2026-11-24 사용자가 “우리 서비스 홍보용이라 생각하면 될 것 같아”라고 용도를 명확히 했다. 이번 요청의 최종 산출물은 서비스 소개 랜딩이며, 앞서 제작한 로그인 후 홈 상세 시안은 최종 방향이 아니다.

## 구성

1. 공개 페이지 내비게이션: U:NAVI 로고·소개·기능·교사 안내·시작하기.
2. 히어로: “복잡한 입시 준비, 내 성적에서 길을 찾아요.”와 시작 버튼, 전형계획 둘러보기.
3. 실제 기존 컴포넌트로 만든 편집 가능한 내 위치 미리보기. 숫자는 예시로 명시.
4. 핵심 기능: 내 성적 이해 → 전형 탐색 → 지원 준비.
5. 신뢰: 계산 과정, 추정 범위, 자료 출처와 기준일.
6. 교사 소개: 학급 자료·수시 카드·상담 기록.
7. 시작하는 세 단계.
8. FAQ와 잉크색 푸터의 시작 안내.

## UI Bowl 조사

`search_ui_patterns(query="랜딩", platform="PC", limit=3)` 결과 이미지를 직접 확인했다.

- [레드프린팅](https://uibowl.io/website/레드프린팅?patterns=랜딩페이지&patternName=디자인%20서비스) — 소개 문구와 시각 자료의 분할 배치.
- [피처링](https://uibowl.io/website/피처링?patterns=랜딩페이지) — 핵심 가치, 시작 버튼, 제품 화면을 연결하는 흐름.
- [아치캘린더](https://uibowl.io/website/아치캘린더?patterns=랜딩페이지) — 짧은 가치 제안과 명확한 시작 행동.

U:NAVI의 기존 직각·흑백 중심 디자인, 의미 있는 파란색, IBM Plex Sans KR, 실제 로고·버튼·범위 막대·성적 칩을 재사용했다. 제품 설명의 근거는 `docs/prd.md`이며 확인되지 않은 실적 수치·사용자 후기·성과 보장 문구는 넣지 않았다.

## 검수

- PC·모바일 전체 스크린샷을 확인하고 내비게이션 및 본문 줄바꿈을 수정 후 재확인했다.
- PC 194개 하위 노드(텍스트 86, 인스턴스 28), 모바일 191개(텍스트 83, 인스턴스 28).
- 두 화면 모두 IBM Plex Sans KR 사용 확인. 변수 연결 노드는 PC 167개, 모바일 164개.
- 이미지로 합쳐 붙인 화면 없음. 텍스트·벡터·인스턴스를 편집할 수 있다.
- 화면 디자인 시안이며 버튼 동작·사이트 배포는 작업 범위에 포함하지 않았다.
- 기존 승인 기록 및 공용 디자인 시스템을 변경하지 않았다. 사용자의 새 승인으로 기록하지 않았다.
