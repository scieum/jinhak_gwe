# 01-research — 상담 질문·할 일 (counsel-tasks, 학생)

작성일 2026-11-23 · 담당 researcher (S1)
근거: 사용자 요청(채팅 원문) "그리고 시안에서 추가적으로 지금 안그린 기능들이나 추가적으로 그 안에서 팝업창 같은 것들도 더 그려봐"
PRD에는 이 화면 절이 따로 없어요. 가장 가까운 근거는 6-x 수시로 "상담카드로 제출: 6장 + 희망 순위 + 고민 메모"(PRD 228), 6-10 교사 상담 화면의 상담 메모(264), 7장 학생 기능(로그인 없음, 이 기기 저장 · 암호화 백업)이에요.
앱 구현: `app/src/screens/Preparation.tsx` `CounselTasks`(경로 `/counsel-tasks`, nav.ts 학생 메뉴 "상담 질문·할 일" icon message-square), 도메인 `app/src/domain/planner.ts`(`CounselTask`, `newCounselTask`, `taskDeadline`).
겹침 정리: 교사 쪽 `counsel`(학생 상담, `counsel-timeline`)과는 다른 화면이에요. 이 화면은 학생이 이 기기에 적는 목록이고 교사에게 자동으로 가지 않아요(서버 없음).

### 0-2. 본문 블록 (위에서 아래)

1. 머리: 제목 "상담 질문·할 일" + 설명 "상담 전에 궁금한 점을 모으고, 상담 뒤 해야 할 일을 챙겨요." + 오른쪽 `button-primary` "+ 질문·할 일 추가"
2. 숫자 4칸(stats): 진행할 항목 · 오늘까지 · 기한 지남 · 완료
3. 거르기 3개(select): 전형별 보기(모든 전형·공통 상담 / 전형 목록, URL `?plan=`) · 상담 구분(질문·할 일 전체 / 상담 전 질문 / 상담 후 할 일) · 완료 상태(진행할 항목 기본 / 완료한 항목 / 전체)

5. 카드 버튼 3개: "완료로 표시" ↔ "다시 진행"(outline) · "수정"(outline) · "삭제"(text-button)
6. 하단 캡션: "기한은 한국 날짜 기준이에요." + 링크 "지원 전형 관리"(application-checklist) · "암호화 백업·복원"(grade-input)

## 2. 반영 포인트

- P1: 모바일 거르기는 select 3개 대신 `filter-chip` 한 줄로 바꿔요: "전체 n · 상담 전 질문 n · 상담 후 할 일 n · 완료 n"(칩에 개수). 전형별 보기는 칩 줄 끝 "전형 ⌄" 칩 → `bottom-sheet` 텍스트 행 목록(선택 행 ✓). PC는 page-header 아래 같은 칩 줄 + 전형 select [근거: L4, L1, L9, L6]
