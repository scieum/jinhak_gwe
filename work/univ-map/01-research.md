# 01-research — 대학 지도 (univ-map, 공개)

작성일 2026-11-23 · 담당 researcher (S1)
근거: 사용자 요청(채팅 원문) "지도 하나 그리고 전국에 있는 4년제 대학을 모두 지도에 표현해주는 기능도 추가해줘. 유아이볼에서 시안 조사하고 전국으로 하고 하나 시도 광역단체 선택하면 거기만 따로 또 보여주는 형태로"
PRD에는 이 화면 절이 따로 없어요. 가장 가까운 근거는 6-1(전형계획 탐색, 누구나 · 로그인 없음 · "대학 검색: 이름, 지역(강원/수도권/권역), 설립 유형, 캠퍼스"), 4장("강원 지역 학생은 지역 대학과 수도권 대학을 함께 고려"), 13장(데이터 기준일 · 출처 · 사용 허락 확인된 자료만)이에요. 즉 6-1 대학 검색의 "지역" 조건을 지도로 보여 주는 화면이에요.

## 0. 이 화면이 하는 일

| 블록 | 내용 | 데이터 조건 |
|---|---|---|
| 전국 보기(첫 화면) | 대한민국 시·도 경계 지도 위에 4년제 대학 전부. 전국 축척에서는 핀이 겹치므로 시·도마다 "대학 n곳" 개수 표시 1개 | 대학 위치 데이터(아래 0-1) + 시·도 경계(0-2) |
| 시·도 보기 | 17개 시·도 중 하나를 고르면 그 시·도만 확대해 그 안의 대학 핀을 따로 보여 줌. "전국으로" 돌아가기 | 같음 |
| 대학 카드 | 핀을 누르면 아래에 대학 카드(로고 · 대학명 · 캠퍼스 · 설립 구분 · 주소) → 대학 상세로 이동 | 같음 |
| 목록 보기 | 지금 보고 있는 범위(전국 / 시·도)의 대학을 목록으로 | 같음 |
| 기준 · 출처 | 데이터 기준일, 위치 자료 출처, 지도 경계 출처 | 같음 |

- 이 화면은 판정하지 않아요. 판정 색(안정·적정·소신·위험)과 판정 아이콘을 쓰지 않아요.
- Route Blue는 "선택됨 · 여기예요"에만: 선택된 시·도 / 선택된 핀 / 선택된 필터 칩, (켜면) 내 학교 위치. 개수 표시 · 핀 기본 상태 · 시·도 채움에는 쓰지 않아요.
- 입결 · 환산 숫자를 이 화면에 올리지 않아요(NEVER-1 범위 밖으로 두기). 대학 카드에도 컷 · 경쟁률은 넣지 않고 상세로 넘겨요.
- 시·도를 개수에 따라 색으로 칠하는 단계 구분도(choropleth)는 design.md에 없어요. 쓰려면 S2에서 "design.md 수정 제안"으로 멈춰야 해요(1차 권장: 칠하지 않고 숫자 표시만).

### 0-1. 대학 위치 데이터 (지금 앱에 없음)

현재 상태: app/public/data에 대학 좌표 · 주소가 없어요. 시·도 목록은 app/src/domain/auth.ts `SIDO`(17개: 서울특별시 … 제주특별자치도, 강원특별자치도 · 전북특별자치도 새 명칭 반영)만 있어요. 이 목록을 지도 시·도 키로 그대로 쓰면 돼요.

필요한 필드(대학 · 캠퍼스 1행)

| 필드 | 예 | 쓰임 |
|---|---|---|
| univ_id | 기존 대학 데이터의 id와 같은 키 | 대학 상세 · 로고 연결 |
| name / campus | 강원대학교 / 삼척캠퍼스 | 핀 · 카드 이름 |
| campus_type | 본교 · 분교 · 캠퍼스(제2캠퍼스) | 필터, 같은 대학 핀 여러 개 |
| sido | `SIDO` 값 중 하나 | 시·도 보기, 개수 |
| sigungu | 춘천시 | 카드 주소 줄 |
| address | 도로명 주소 | 카드, 좌표 검수 |
| lat / lng | 37.86, 127.74 | 핀 위치 |
| founding | 국립 · 공립 · 사립 (+ 국립대법인 · 특별법) | 필터, 카드 |
| school_kind | 일반대학 · 교육대학 · 산업대학 등 | "4년제" 범위 결정 |
| source / as_of / review_status | 대학알리미 2026 공시 / 2026-04-01 / verified | 고지, 관리자 검수 |

공개 출처 후보(사용 허락 · 필드 실제 여부는 S2 전에 사람 확인 필요)
1. 대학알리미(academyinfo.go.kr, 한국대학교육협의회 운영) 학교 기본 정보 공시: 학교명 · 본분교 · 설립 구분 · 소재지 주소. 좌표는 없을 가능성이 커요 → 주소 지오코딩 필요.
2. 교육부 · 한국교육개발원(KEDI) 교육통계서비스(kess.kedi.re.kr) "고등교육기관 현황 / 학교 주소록"(매년 4월 1일 기준 엑셀): 학교 종류(일반대 · 교대 · 산업대 등) · 설립 · 시·도 · 주소. "4년제"를 학교 종류로 거를 기준 자료로 적합.
3. 공공데이터포털(data.go.kr) "전국대학및전문대학정보표준데이터"(표준데이터, 위도 · 경도 필드가 있는 것으로 알고 있음 — 확인 필요). 좌표가 있으면 지오코딩을 건너뛸 수 있어요. 공공누리 유형(출처표시 여부) 확인.
4. 좌표가 없을 때 지오코딩: 행정안전부 도로명주소 좌표제공 API(juso.go.kr, 승인키 필요) 또는 브이월드 지오코더(vworld.kr, 키 필요). 결과 좌표는 관리자가 캠퍼스 단위로 검수(정문 vs 본부 위치 차이).
- 규모: 4년제(일반대 + 교육대 + 산업대 등) 약 190~200개교, 분교 · 캠퍼스를 따로 찍으면 그보다 많아요(정확한 수는 출처 2로 확정 필요).
- 기존 대학 데이터(전형계획 · 입결)의 대학 id와 이름 · 캠퍼스 매칭 표가 필요해요(예: "연세대 미래캠퍼스" 표기 차이).

### 0-2. 지도 바탕(행정구역 경계) 그리는 방법

| 안 | 장점 | 주의 |
|---|---|---|
| A. 정적 SVG 시·도 경계(권장) | 키 · 쿼터 없음, 오프라인 동작(PWA), 흑백 팔레트 그대로(design.md 색 규칙 지키기 쉬움), 17개 시·도를 누르는 영역으로 바로 씀, Figma에 벡터로 그대로 올림 | 경계 원자료 라이선스 확인, 섬(울릉 · 제주 등) 단순화 정도, 세종처럼 작은 시·도의 터치 영역(44px 미만) → 칩 · 시트로 보완. 확대는 시·도 단위 고정 축척(자유 줌 없음) |
| B. 지도 타일(카카오 · 네이버 지도 API, OSM, 브이월드 배경지도) | 자유 줌 · 도로 · 지명, 익숙함 | API 키 · 일일 쿼터 · 약관(비상업 배포 전제 확인), 타일 색이 팔레트 밖(J1 판정과 흑백 원칙에 어긋남), 지도 로고 · 저작권 표기 의무, OSM 공용 타일 서버는 대량 사용 금지 정책, 오프라인 불가 |

- 경계 원자료 후보: 통계청 SGIS 통계지역경계(시·도, 무료 · 출처 표시), 국토정보플랫폼 · 브이월드 행정구역 경계(공공누리 유형 확인). 공개 저장소의 가공본(예: 통계청 경계를 GeoJSON으로 변환한 것)도 원자료 라이선스를 따라요.
- 만들기: GeoJSON → 단순화(mapshaper 등) → 시·도별 path가 든 SVG 1장(+ 시·도별 확대용 viewBox). 출처 문구를 지도 아래 캡션으로.
- 1차 권장 = A. 시·도 보기에서도 정적 경계(그 시·도 path만 확대 + 시·군 경계는 선택 사항).

### 0-3. 기존 화면과의 연결

| 화면 | 연결 |
|---|---|
| 대학 상세 (univ-detail) | 대학 카드 · 목록 항목을 누르면 그 대학(캠퍼스) 상세로. 반대로 상세의 주소 줄에서 "지도에서 보기" → 이 화면 시·도 보기 + 그 핀 선택 상태로 열기(S2 결정) |
| 전국 배치표 (national-placement) | 같은 "전국 → 지역" 축. 배치표에서 지역 필터를 고른 상태를 지도로 넘기거나 그 반대(같은 시·도 키 `SIDO` 공유). 지도에는 입결 숫자를 올리지 않음 |
| 특수 계열 모아보기 (special-tracks) | 묶음(예: 교육대학 · 특수목적 대학)에 속한 대학을 지도에 표시하는 "지도로 보기" 진입 후보. 1차 범위 여부는 S2 결정 |
| 내비게이션 | design.md 대분류 "대학 찾기" 아래 소분류 후보(전형계획 · 수시 입결 · 학과별 구간 · 계열 모아보기 · 될각 · 최저로 찾기 옆). 소분류 아이콘(icon/map 등)이 다른 메뉴와 겹치지 않는지 확인 필요 → design.md 수정 제안 대상 |

### 0-4. 상태 · 팝업 후보

1. 전국 보기(기본): 시·도마다 개수 표시, 선택 없음
2. 시·도 보기: 선택 시·도 확대 + 핀, 머리에 "강원특별자치도 · 대학 n곳" + "전국으로"
3. 핀 선택: 하단 대학 카드(모바일) / 오른쪽 패널 카드(PC). 같은 위치에 핀이 여러 개면 묶음 핀 → 누르면 그 묶음 목록 시트
4. 시·도 선택 시트: 17개 시·도 격자 + "전국" (모바일 bottom-sheet / PC 드롭다운 또는 왼쪽 목록)
5. 목록 보기: 지금 범위의 대학 univ-card 목록 + 개수 + 정렬(가나다 · 설립 구분)
6. 검색: 대학 이름 입력 → 결과 목록 → 고르면 그 시·도 보기 + 핀 선택
7. 검색 결과 없음 empty-state: "찾는 대학이 없어요" + 다른 이름 안내
8. 필터 결과 0곳: 지도는 두고 "조건에 맞는 대학이 없어요" 한 줄 + 필터 초기화
9. 위치 데이터 준비 중: 좌표 검수 전 대학은 핀을 찍지 않고 "위치 확인 중인 대학 n곳" data-status-badge 한 줄
10. 지도 불러오기 실패(B안일 때만): 목록 보기로 대체

## 1. 레퍼런스 (uibowl)

검색 9회, 모두 1페이지: 패턴 `지도 × 바텀시트`, 패턴 `지도 × 부동산`, 컴포넌트 `지도 × 여행`, OCR `지역 선택 전국`, OCR `목록보기 × 지도`, 패턴 `지역 필터 × 모빌리티`(0건 — 패턴 이름이 아님), 컴포넌트 `지도 핀, 카드 × 지도뷰·내주변`, OCR `서울 경기 강원 충북 × 바텀시트`, 패턴 `지도뷰·내주변 × 칩 × 부동산`(L3 중복).
제외: 데일리호텔 예약내역 속 작은 지도, 렌트카 카모아 메인, 더벤티 선물하기(OCR 우연 일치). 교육 · 입시 앱의 대학 지도 사례는 0건이에요. 시·도를 색으로 칠한 단계 구분도 화면도 찾지 못했어요.

## 2. 반영 포인트

- P1: 첫 화면은 전국 지도 한 장(정적 시·도 경계, 흑백)이고, 전국 축척에서는 대학 핀을 다 찍지 않고 시·도마다 "n" 개수 표시 1개만 둬요(잉크 채움 + 흰 숫자, 고정폭 숫자). 지도 아래 한 줄 "전국 4년제 대학 n곳 · 시·도를 누르면 그 지역만 볼 수 있어요" [근거: L1, L3, L2]
- P2: 시·도 고르기 경로는 둘: ① 지도에서 시·도 영역을 누름 ② 상단 filter-chip "전국 ⌄" → bottom-sheet(PC는 드롭다운 · 왼쪽 목록)에 "전국" + 17개 시·도를 3열 격자로, 칸마다 이름 + 대학 수. 세종처럼 작은 시·도는 지도에서 누르기 어려우므로 ②가 꼭 필요해요. 선택된 칸 = accent-soft 채움 + accent 테두리(선택 표시 규칙) [근거: L10, L11, L5]
- P3: 시·도 보기 = 그 시·도 경계만 확대(다른 시·도는 숨기거나 hairline으로 흐리게) + 대학 핀 전부. 머리 줄 "강원특별자치도 · 대학 n곳" + "전국으로" 되돌리기. 한곳에 몰린 핀(서울 등)은 묶음 핀(숫자)으로 합쳐 겹치지 않게 하고, 누르면 그 묶음 목록 시트 [근거: L1, L4, L3]

## 4. S2 주의 · 미결

1. **design.md에 지도 관련 컴포넌트가 없어요.** 지도 바탕(시·도 경계 path, 채움 · 선 토큰), 대학 핀(원형 표식 ELLIPSE 예외에 들어가는지), 개수 표시 · 묶음 핀, 떠 있는 "목록 보기" 버튼, 단계 구분도 칠하기가 모두 없어요. 새로 만들지 말고 "design.md 수정 제안"으로 멈춰 주세요. 제안 초안: map-region(시·도 path: 기본 {colors.canvas} 채움 + 1px {colors.hairline}, 선택 = {colors.accent-soft} 채움 + 1px {colors.accent}), map-pin(ELLIPSE, 기본 {colors.ink} · 선택 {colors.accent}), map-count(잉크 채움 + {colors.on-primary} 숫자). 단계 구분도는 1차에서 쓰지 않기를 권해요.
2. 그림자: 떠 있는 "목록 보기" 버튼 · 지도 위 카드에 그림자를 쓰려면 `shadow_allowed_on`(모달 · 바텀시트 · 토스트 · 드롭다운)에 없으므로 그림자 없이(1px 외곽선) 그리거나 수정 제안 필요.
3. 지도 바탕 방식: 1차 권장은 정적 SVG(0-2 A안). 타일 지도(B안)를 고르면 팔레트 밖 색(J1) · 키 · 약관 문제가 생겨요.
4. 데이터: 위치 데이터 출처(0-1의 1~3) 중 무엇을 쓸지, 공공누리 유형 · 출처 표시 문구, 좌표 검수 절차(관리자 2인 검수와 같은 흐름에 넣을지)를 정해야 해요. 정해지기 전 시안은 가상 좌표 · 가상 개수로 그려요.
5. "4년제" 범위: 일반대학만인지, 교육대학 · 산업대학 · 사이버대 · 특별법 대학(예: 사관학교, 과학기술원)을 넣을지 결정 필요. 분교 · 제2캠퍼스를 별도 핀으로 둘지도.
6. 내비게이션 자리 · 소분류 아이콘(icon/map 등) 확정은 design.md 수정 대상이에요.
7. 내 학교 위치(교사 가입 시 고른 시·도 · 학교) 표시를 넣으면 Route Blue는 그 표시에만 — 1차 범위 여부 S2 결정.
8. 문구: 지역 개수 · 대학 카드에 서열 · 추천 · 지원 결과로 읽히는 말을 쓰지 않아요. 금지어 대조(rules/design-rules.json `forbidden_words`)는 S2 몫.
9. uibowl 한계: 교육 · 입시 앱의 대학 지도, 시·도 단계 구분도, 시·도 경계만 있는 정적 지도 화면은 무료 범위 검색에서 0건이었어요. 전국 → 시·도 확대 흐름은 L1(개수 묶음) + L10(시·도 격자 시트)을 조합한 추정이에요.
