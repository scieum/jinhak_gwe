# 02-spec — 대학 상세 (univ-detail)

> 근거: work/univ-detail/01-research.md (P1~P7), docs/prd.md 6-1, docs/design.md
> 화면 위치: [전형계획] 대학 검색 → **대학 상세** → 전형 상세. 누구나(로그인 없음) 보는 공개 데이터 화면이에요.
> 개인 성적이 없는 화면이라서 판정 배지·판정 색·Route Blue(내 위치)는 쓰지 않아요. 화면 전체를 흑백으로 만들어요.
> 필수 컴포넌트 확인: univ-detail은 requires_trace_accordion, requires_disclaimer_note 어디에도 없어요. 계산 결과가 없으므로 `trace-accordion`은 넣지 않아요. 데이터 출처 고지용으로 `disclaimer-note` 1개만 맨 아래에 넣어요.

## 2. 모바일 390 × 844 (프레임 이름 univ-detail/390)

앱 셸: 상단 앱바 56px + 하단 `tab-bar-pill`(메뉴 탭 선택. 전형계획은 메뉴 안에 있어요). 좌우 패딩 16, 섹션 간격 32.

위에서 아래로:

1. 앱바 (56px)
   - 왼쪽 뒤로가기, 가운데 "대학 상세" heading-4. 오른쪽은 비워 둬요.
2. 대학 요약 카드 [P2, P1]
   - `univ-monogram` 56px("한") + 대학명 "한빛대학교" heading-1. 이름이 길면 줄이지 않고 두 줄로 흘려요.
   - 아래 줄 caption muted: "강원 · 사립 · 춘천캠퍼스"
   - `data-status-badge` "시행계획 기준" + caption muted "데이터 기준일 2026-11-18"
   - 흰 카드 + 1px hairline-soft, radius 24, 그림자 없음.
3. 기본 정보 [P7]
   - 라벨-값 2열 블록: 지역 / 설립 유형 / 캠퍼스 / 홈페이지. 라벨은 body-sm muted, 값은 body.
   - 홈페이지 값 자리에 `button-pill-soft` "홈페이지 ↗". 구분선 없이 여백으로 묶어요.
4. 전년 대비 바뀐 점 [P4]
   - 섹션 제목 heading-2 "전년 대비 바뀐 점" + 리드 body-lg "2027학년도와 비교해 4건이 바뀌었어요"
   - 전형별 접이식 행(아코디언 행 모양: canvas-soft 채움, radius 16, 펼침 화살표. 별도 컴포넌트 아님). 행 제목은 전형명 title + caption "변경 2건".
   - 첫 행(학생부교과 지역균형전형)을 펼친 상태로 그려요. 안쪽은 비교 줄: 항목 이름 body-sm muted → "120명 → 98명" table 고정폭 숫자, 바뀐 값만 700. 아래에 한 줄 문장 body "모집인원이 120명에서 98명으로 줄었어요".
   - 강조는 굵기와 화살표로만 해요. 색은 쓰지 않아요.
   - 블록 맨 아래: `button-pill-soft` "원문 보기 ↗" + caption muted "출처: 2028학년도 대입전형 시행계획 12~15쪽"
5. 2028 전형 목록 [P3, P6]
   - 섹션 제목 heading-2 "2028 전형 목록" + caption "7개"
   - 유형 필터: `segmented-control` 가로 스크롤 트랙. 선택지 전체 · 교과 · 종합 · 논술 · 실기 · 정시. 선택된 "전체"는 `segmented-control-active`. 유형마다 색을 넣지 않아요.
   - 소제목 heading-4 "수시 6개", "정시 1개"로 나눠요.
   - 전형 카드 목록: `data-table`의 모바일 형태라서 `univ-card` 구조를 써요. 이 화면에서는 대학이 하나뿐이라 모노그램은 빼고 전형명을 제목으로 둬요.
     - 전형명 heading-4 (길면 두 줄)
     - "교과 · 지역균형 · 모집 98명" body-sm muted, 숫자 고정폭
     - 아래 줄 흑백 알약 "수능최저 있음", "면접 없음"(`data-status-badge`와 같은 흑백 알약 모양) + `data-status-badge` "시행계획 기준"
     - 카드 오른쪽 끝 "›" 표시. 카드 전체를 누르면 전형 상세로 가요.
     - 카드 안에 판정 배지, 내 환산 숫자, "수시로에 담기" 버튼은 넣지 않아요(공개 화면).
   - 필터 결과가 0개일 때: `empty-state` "이 유형의 2028 전형은 없어요" + 설명 "다른 유형을 골라 보세요". 이 화면에 이미 주요 버튼이 있으므로 empty-state 안 버튼은 `button-pill-soft` "전체 보기"로 바꿔요.
6. 고지
   - `disclaimer-note` "대학 공식 자료가 최종 기준이에요 · 데이터 기준일 2026-11-18"
7. 하단 고정 영역 [P2]
   - `button-primary` "관심 대학 담기" (높이 52, 좌우 16 여백, `tab-bar-pill` 위 12px). 화면에 주요 버튼은 이것 하나예요.
   - 그 아래 `tab-bar-pill` (높이 64, 바닥에서 16 띄움, safe-area 지킴)
   - 본문 맨 아래 여백은 버튼 + 탭바 높이만큼 비워서 고지 문구가 가려지지 않게 해요.

## 4. 상호작용과 상태

- 관심 대학 담기: 누르면 학생 기기에 저장하고 `toast` "관심 대학에 담았어요"를 띄워요(모바일은 탭바 위, PC는 오른쪽 아래). 담은 뒤에는 같은 자리 버튼이 `button-outline` "관심 대학에서 빼기"로 바뀌어요. 프레임에는 담기 전 상태만 그려요.
- 유형 필터: 고르면 목록과 표가 바로 걸러져요. 개수 caption도 같이 바뀌어요.
- PC 표 행 선택: 키보드(위·아래 방향키, Enter)로도 고를 수 있고, 포커스는 2px 잉크 링이에요. Enter는 보조 패널 갱신, 패널의 "전형 상세 보기"가 이동이에요.
- 데이터 상태가 "모집요강 반영"으로 바뀌면 같은 `data-status-badge` 자리에 문구만 바뀌어요. 색은 바뀌지 않아요.
- 터치 영역: 모바일 누르는 요소 최소 44 × 44, PC 표 안 컨트롤 최소 32 높이.

## 5. 사용 컴포넌트

`sidebar`, `tab-bar-pill`, `univ-monogram`, `univ-card`, `data-status-badge`, `data-table`, `segmented-control`, `segmented-control-active`, `button-primary`, `button-outline`, `button-pill-soft`, `empty-state`, `toast`, `disclaimer-note`

쓰지 않는 것: 판정 배지, 판정 레인, 산출 근거 아코디언, 범위 막대, 컷 비교 막대(개인 성적·계산 결과가 없는 화면이라서요).

## 6. 문구 점검

- 모든 문구는 해요체예요.
- 결과를 약속하거나 가능성을 숫자로 말하는 표현은 쓰지 않아요. 변경사항은 "줄었어요", "바뀌었어요", "새로 들어갔어요"처럼 사실만 말해요.
- 대학명은 가상 이름(한빛대학교)만 써요. 실제 대학 로고·사진은 넣지 않아요.

## 7. 디자이너 메모

- 레이어 이름 = 컴포넌트 이름으로 지어요. 예: 대학 요약 카드 안 모노그램 레이어는 univ-monogram, 상태 알약은 data-status-badge, 전형 표는 data-table. 컴포넌트가 아닌 묶음(요약 띠, 변경 행, 보조 패널)은 한국어 이름으로 지어요.
- 알약 모양(버튼, 세그먼트, 배지, 흑백 알약, 탭바)은 모두 cornerRadius 9999로 둬요. 작아져도 네모로 바꾸지 않아요.
- 카드·요약 띠·보조 패널 radius 24, 표 컨테이너·접이식 행 radius 16, 표 셀 0. univ-monogram만 30% 스퀴클 예외예요.
- 그림자는 segmented-control-active와 toast에만 둬요. 카드, 버튼, 사이드바, 보조 패널에는 넣지 않아요.
- 색은 흑백 팔레트만 써요. 이 화면에는 판정 색과 Route Blue가 하나도 나오지 않아야 해요.
- 숫자(모집인원, 연도, 날짜, 수능최저 합)는 모두 고정폭 숫자, 자간 0, Pretendard 300/400/600/700만 써요.
- 프레임은 univ-detail/390(390 × 844), univ-detail/1440(1440 × 900) 두 개만 만들어요.
