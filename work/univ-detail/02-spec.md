> 화면 위치: 학생 대분류 "대학 찾기" › 전형계획 › **대학 상세**(상세 화면, 소분류 아님) → 전형 상세. 누구나(로그인 없음) 보는 공개 데이터 화면이에요.

## 4. 상호작용과 내용 상태

- 관심 대학 담기: 하트를 누르면 학생 기기에 저장하고 `toast` "관심 대학에 담았어요. 이 기기에만 저장돼요"(모바일은 고정 줄 위, PC는 오른쪽 아래). 담긴 뒤에는 같은 자리가 채운 하트 + "관심 대학에서 빼기"로 바뀌어요. 다시 누르면 빼고 `toast` "관심 대학에서 뺐어요". 빼기는 한 번 더 누르면 되돌릴 수 있어 확인 창을 두지 않아요(확인 창 규칙의 지우기 · 되돌리기 어려운 저장에 들지 않아요). 저장 중에는 하트가 비활성 + "저장 중".
- 유형 필터: 고르면 목록과 표가 바로 걸러지고 개수 caption도 같이 바뀌어요. 걸러져서 PC 선택 행이 사라지면 보조 패널은 빈 안내로 바뀌어요(5장 1440-panel-empty).
- 전년 대비 바뀐 점(모바일): 처음엔 첫 행만 펼쳐요. 여러 행을 동시에 펼칠 수 있어요.
- PC 표 행 선택: 키보드(위·아래 방향키, Enter)로도 골라요. 포커스는 2px ink 링, 선택은 R10 모양. Enter는 보조 패널 갱신, 패널의 "전형 상세 보기"가 이동이에요.
- 모집인원 정렬: 머리글을 누르면 내림차순 ▼ → 오름차순 ▲ → 원래 순서. 정렬된 열 머리글만 화살표를 ink로, 나머지는 text-muted.
- 데이터 상태가 "모집요강 반영"으로 바뀌면 같은 `data-status-badge` 자리와 R11 한 줄 문구만 바뀌어요. 색은 바뀌지 않아요. 출처 caption도 모집요강 쪽수로 바뀌어요.
- 2027 자료가 없으면(신설 대학 등) 바뀐 점 블록은 제목 + `data-status-badge` "준비 중" + body-sm "2027학년도 자료가 아직 없어서 비교하지 않았어요"만 보여요. 숫자를 만들어 넣지 않아요.
- 변경이 0건이면 리드 문장 "2027학년도와 비교해 바뀐 점이 없어요" + 원문 보기만 두고 표 · 접이식 행은 그리지 않아요.
- 터치 영역: 모바일 누르는 요소 최소 44 × 44, PC 표 안 컨트롤 최소 32 높이.

## 7. 문구 점검

- 모든 문구는 해요체예요.
- 지원 결과를 약속하거나 결과를 숫자로 단정하는 표현은 쓰지 않아요. 변경사항은 "줄었어요", "바뀌었어요", "새로 들어갔어요"처럼 사실만 말해요.
- 증감 기호 ▲▼는 모집인원처럼 많고 적음이 뜻하는 바가 분명한 숫자에만 써요. 수능최저 합처럼 작을수록 기준이 높아지는 값에는 ▲▼를 쓰지 않아요(방향 캡션을 늘리지 않으려고요).
- 오류 문구는 무엇이 안 됐고 어떻게 하면 되는지 같이 적어요(5-3 · 5-4).
- 대학명은 가상 이름(한빛대학교)만 써요. 실제 대학 로고·사진은 넣지 않아요.

## 8. 디자이너 메모

- 03-draft.json `frames` = 정확히 2개: univ-detail/390 (390×844), univ-detail/1440 (1440×900). 5장 상태 프레임 29개는 같은 Figma 섹션(346:143370)에 두고 `states`에만 적어요(frames에 넣으면 G3 실패).
