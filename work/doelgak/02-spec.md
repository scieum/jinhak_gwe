## 2. `univ-card` v2 — 두 프레임 공통 구성

모든 카드는 같은 높이예요(모바일 행 224 고정, PC 카드 248 고정). 내용이 적은 카드도 자리를 비워 높이를 맞춰요. 위에서 아래로 5단, 순서는 바꾸지 않아요.

1. 머리 줄
   - 왼쪽: `univ-logo`(경희대학교 · 성균관대학교) 또는 `univ-monogram`(그 밖, canvas-soft 바탕 + ink 첫 글자), 정사각 32(모바일) / 28(PC), 모서리 0
   - 이어서 대학명 heading-4, ink. 모바일은 한 줄, PC는 최대 2줄로 흘리고 2줄 자리를 늘 비워 둬요(높이 고정).
   - 오른쪽 위 끝: 관심 하트(디자인 시스템 interest-heart 인스턴스, 아이콘 20 · 터치 영역 44×44). 안 담김 = ink 선 하트, 담김 = Route Blue 채운 하트(design.md 선택 표시 규칙). 누르면 같은 자리에서 두 상태가 바뀌어요.
2. 학과 · 전형 한 줄: body-sm, text-muted, "국어국문학과 · 학생부교과(일반)". 넘치면 말줄임(…)으로 자르고 전체 이름은 상세에서 보여줘요(design.md 모바일 목록 한 줄 요약 허용).
3. 숫자 블록
   - 라벨 "내 환산" caption, text-muted
   - 범위 "약 2.4~2.7" numeric, 고정폭, Route Blue(내 위치)
   - 그 아래 회색 캡션 "70% 컷 3.1 · 차이 −0.4" caption, text-muted, 고정폭 숫자
   - 경계 · 충원율은 숫자 줄 오른쪽 끝 작은 caption: 3번 "경계"(ink 글자 + 1px ink 점선 외곽선, judge-edge), 5번 "충원율 약 180%"(text-muted)
4. 미니 비교 막대: `cut-compare-bar` 축소형, 카드 내용 폭 전체
   - 축: 모든 카드 같은 눈금 1.0 ~ 4.0. 왼쪽 = 1등급 쪽(좋음), 오른쪽 = 4 쪽. 양 끝에 caption "1" · "4" (text-muted)
   - 트랙: 높이 6, hairline 회색, 모서리 0
   - 70% 컷: ink 세로 눈금 2×12
   - 내 환산 범위: Route Blue 구간(예: 2.4~2.7 위치)
   - 50% 컷 · 판정 배지는 축소형에 넣지 않아요(상세에서만)
   - 대체 텍스트: "내 환산 9등급 약 2.4에서 2.7 사이, 70% 컷 3.1, 차이 −0.4"
5. 조건 칩 한 줄: `data-status-badge` 흑백 사각 칩(label, 높이 24, 모서리 0) — "수능최저 있음" / "수능최저 없음" / "수능최저 확인 필요", "재학생만", "학교장추천", "강원 고교만", "면접 없음". 한 줄을 넘으면 마지막 칩을 "+n"으로 접어요. 판정 색 · Route Blue는 쓰지 않아요.

카드에 넣지 않는 것:
- `judge-badge` (판정은 그룹 머리 · 레인 머리에서만 말해요, P9)
- "수시로에 담기" 버튼과 모든 주요 버튼(P14). 카드 전체를 누르면 상세가 열려요.

8번(입결 없음) 카드 변형:
- 숫자 블록: "내 환산" + "약 2.4~2.7"(Route Blue) / 캡션 "70% 컷 — · 비교할 입결이 아직 없어요"
- 미니 막대 자리: 트랙 + 내 범위 구간만, 컷 눈금 없음
- 조건 칩 줄 첫 칩: `data-status-badge` "입결 없음(신설)"

## 5. 종합 탭 라벨 규칙 (그리지 않음, R-JDG-005)

- 판정 이름은 "적합도 높음 / 보통 / 낮음" 세 단계만 써요. 안정 · 적정 · 소신 · 위험 이름은 쓰지 않아요.
- `judge-badge` 색 · 아이콘 재사용: 높음 = 안정 색 쌍 + ●, 보통 = 적정 색 쌍 + ◐, 낮음 = 소신 색 쌍 + ▲. 위험 색 쌍은 쓰지 않아요.
- 모바일 그룹 3개, PC `judge-lane` 3열. 입결 없음(신설) 그룹은 맨 아래 따로.
- `univ-card` 숫자 블록: 라벨 "전 교과 환산" + "약 2.4~2.9" / 캡션 "권장과목 4/5 이수". 미니 막대 자리는 같은 높이의 빈 칸으로 두어 카드 높이를 맞춰요. 순위 숫자나 퍼센트 값은 두지 않아요.
- 생기부 AI 결과가 있으면 조건 칩 줄 대신 `ai-label` "AI 분석 · 참고용" + 역량 요약 한 줄. AI 요약에는 판정 색을 쓰지 않아요.

## 9. design.md 수정 제안

1. rules `components`에 interest-heart · filter-chip · sidebar-item · app-bar가 없어요. design.md에는 관심 하트(univ-card 안), 필터 칩 선택 상태, 사이드바 메뉴 행, 모바일 앱바가 설명돼 있고 디자인 시스템 페이지에도 인스턴스가 있으니, Components 절에 이름으로 올리고 rules를 다시 만들면 좋겠어요.
2. `univ-card` 설명이 아직 "오른쪽 위 judge-badge", "하단 button-pill-soft 수시로에 담기"예요. 될각 목록 v2(판정 배지 없음 · 담기 버튼 없음 · 5단 고정 높이 · 구분선 행 변형)를 반영해 주세요.
3. `cut-compare-bar` 축소형(compact) 정의가 없어요. 축 1.0~4.0 공통 · 왼쪽 = 1등급 쪽 · 70% 컷만 ink 눈금(전체형은 hairline 세로선) · 판정 배지 없음을 변형으로 적어 두면 좋겠어요.
4. Don't "한 화면에 Route Blue 숫자는 1~2개까지만"과 카드마다 Route Blue 내 환산 범위(최대 8개)가 부딪혀요. 카드 범위를 "내 위치" 표시로 보아 예외로 둘지, 카드 숫자는 ink로 두고 미니 막대 구간만 Route Blue로 할지 정해 주세요. 이 설계서는 지시대로 Route Blue로 적었어요.
5. 조건 칩(흑백 사각, 지원 조건)에 맞는 컴포넌트가 없어 `data-status-badge`를 빌려 썼어요. 조건 칩 컴포넌트를 따로 둘지 정해 주세요.
6. 한양대학교 SVG는 work/logos에 있지만 디자인 시스템에 univ-logo 인스턴스가 없어요. 인스턴스를 추가하면 모노그램 대신 로고로 바꿀 수 있어요.
7. PC 레인 폭 204에서는 `univ-card` PC 패딩 24가 너무 커서 16으로 적었어요. 레인 안 카드 패딩 예외를 적어 두면 좋겠어요.
