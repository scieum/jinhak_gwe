## 대상 화면 요약

- 모바일: 교과 · 종합 세그먼트 → 판정별 그룹 목록(안정→적정→소신→위험) + 필터 바텀시트
- PC: 왼쪽 필터 + 판정 4열 레인(judge-lane) 또는 표 보기 전환
- 판정: 교과 = 안정/적정/소신/위험(R-JDG-001), 종합 = 적합도 높음/보통/낮음(R-JDG-005), 입결이 없으면 "입결 없음(신설)"으로 두고 판정하지 않음(R-JDG-006)
- 각 항목에서 바로 수시로에 담기(6-6 공통)

## 반영 포인트

- P1: 화면 맨 위에 교과 · 종합 segmented-control(알약 트랙 + 흰 선택 알약)을 두고, 바로 아래 한 줄에 "판정된 전형 n개 · 정렬" 요약을 둔다. 탭을 바꾸면 목록 전체가 그 전형 기준으로 바뀐다 (모바일) [근거: L3, L2]
- P2: 판정별 그룹 목록 — 그룹 머리에 judge-badge(색 + 아이콘 + 이름) + 개수를 두고 안정 → 적정 → 소신 → 위험 순서로 쌓는다. 입결이 없는 전형은 맨 아래 "입결 없음(신설)" 그룹(judge-none, 흑백)으로 따로 모으고 판정 배지를 붙이지 않는다(R-JDG-006). 종합 탭은 그룹 이름을 "적합도 높음/보통/낮음"으로 바꾼다(R-JDG-005) (모바일) [근거: L2, L4]
- P3: univ-card 안 판정 표시는 L1처럼 작은 옅은 배경 알약으로 오른쪽 위에 두되, 색은 design.md 판정 색 쌍만 쓴다. 판정이 경계면(R-JDG-002) 점선 "경계" 알약을 함께 붙이고, 충원율이 높으면 판정 옆에 충원율 캡션을 붙인다(R-JDG-003). 카드 아래 줄은 내 환산 / 70% 컷 숫자 + 수능최저 배지 (모바일/PC) [근거: L1, L2]
- P4: 담기 동작 — 카드마다 button-pill-soft "수시로에 담기"를 두고, 담긴 뒤에는 같은 자리에서 "담김" 상태로 바뀌는 두 상태 토글로 만든다(L3의 저장 토글 방식). PC 레인 상단에는 수시로 슬롯이 몇 칸 찼는지 보여줘 6장 한도를 의식하게 한다 (모바일/PC) [근거: L3, L2, L10]
- P5: 모바일 필터는 목록 위 button-pill-soft "필터" → bottom-sheet(왼쪽 제목 + 오른쪽 닫기, 뒤 scrim)로 연다. 시트 안 항목은 6-6의 지역 · 계열 · 학과 키워드 · 수능최저 유무 · 면접 유무. 적용된 필터는 목록 위 칩 줄로 보여준다 (모바일) [근거: L5, L1]
- P6: PC는 사이드바 옆에 왼쪽 필터 열을 고정하고, 체크박스 묶음(지역·계열) + 토글(수능최저·면접) + 하단 초기화/적용 버튼을 둔다. 필터를 바꿔도 본문 레인 위치는 그대로 (PC) [근거: L6, L7]
- P7: PC 본문은 judge-lane 4열(안정·적정·소신·위험)을 같은 폭으로 가로로 나란히 두고, 열 머리에 judge-badge + 개수, 열 안에 univ-card를 세로로 쌓는다. 레인 위 segmented-control로 "레인 보기 · 표 보기"를 전환하고, 표 보기는 data-table(대학·전형·내 환산·70% 컷·판정) (PC) [근거: L8, L9]
- P8: 카드를 누르면 상세에 cut-compare-bar(50%·70% 컷 세로선 + 내 환산 범위)를 차트와 수치로 함께 보여주고, 하단에 trace-accordion + disclaimer-note를 붙인다. 모바일은 전체 화면 상세, PC는 오른쪽 보조 패널 (모바일/PC) [근거: L9, L2]

## 가져오지 않을 것 (NEVER-2 · design.md)

- 레퍼런스 문구는 그대로 가져오지 않는다. 특히 "합격 가능", "합격 확률", "보장", "추천 대학"처럼 합격을 약속하거나 예측으로 읽히는 표현은 쓰지 않는다. 판정 영역 문구는 "될각 판정", "입결과 비교하면", "약 · 범위 · 추정"만 쓴다. (이번 10건에는 합격 관련 문구가 없었지만 S2에서 문구를 새로 쓸 때도 같은 기준을 적용한다.)
- L1의 주황/파랑 카테고리 배지 색, L8·L9의 빨강/파랑 등락 색, L3의 초록 강조 버튼 색은 쓰지 않는다. 판정 색은 판정에만, Route Blue는 내 위치(내 환산 범위)에만 쓴다.
- L10의 원형 "+" 자리 모양은 쓰지 않는다. 빈 슬롯 표현은 design.md susi-slot(점선 + rounded.md)을 따른다.
- 종합 탭에는 "합격 예측"을 연상시키는 숫자 순위나 퍼센트를 두지 않는다(R-JDG-005, PRD 13장).

## v2 카드 개선 (2026-11-18)

> 범위: univ-card 한 장의 구성만 다시 본다. 화면 골격(그룹 목록·judge-lane 4열·필터)은 P1~P8 그대로.
