## §0 앱 구현에서 찾은 기능 · 상태 · 팝업 (S2 상태 프레임 목록)

데이터 = 학생이 입력한 기록의 투영. 원서·서류 마감은 체크리스트(application.steps의 due_at), 면접·논술·실기는 수시로 칸(board slot의 exam_kind·exam_date). 관리자 데이터 아님, 서버 전송 없음.

기능
- F1 화면 머리: 제목 "입시 일정" + 리드 "원서·서류 마감과 고사 날짜를 한곳에서 확인해요." + button-outline "일정 입력·수정"(→ 원서·서류 체크리스트).
- F2 필터 줄: 지원 전형 선택(전체 전형 / "연도 · 대학 · 전형 · 학과"), 일정 종류 선택(전체 · 원서·서류 · 면접·논술·실기), 체크박스 "완료 일정 포함"(기본 꺼짐). URL ?plan= 으로 전형 하나만 열 수 있음(전형 계획 화면의 "이 전형 일정 보기"에서 진입).
- F3 툴바: ‹ 이전 달 · "2026년 11월" · 다음 달 › · "오늘"(이번 달로 가며 오늘 선택) + segmented-control "월간 · 목록".
- F4 월간 그리드: 일~토 7열, 날짜 칸 = 숫자 + 일정 있으면 "n건". 오늘 = aria-current, 누른 날 = 선택(다시 누르면 해제).
- F5 일정 목록: 머리 "이번 달 일정 · n개" 또는 "2026-11-21 일정 · n개" + 텍스트 버튼 "이번 달 전체 보기"(날짜 선택 시). 행 = 대학 · 학과 / 연도 · 전형 · 일정 이름 / (수시로 안 이름)에 기록 · 오른쪽 날짜(+시각)와 상태.
- F6 상태 꼬리표(eventStatus): "D-n" · "오늘" · "기한 지남" · "완료" · "날짜 미정". 시각이 있으면 시각이 지난 순간 "기한 지남".
- F7 다가오는 일정 카드: "다가오는 일정" + 가장 가까운 미완료 일정 1개(대학 · 일정 · 날짜 시각) + 오른쪽 상태(D-n/오늘).
- F8 날짜 미정 묶음: 접힌 details "날짜 미정 n개 · 입력한 날짜가 없어 달력에 표시하지 않아요" → 펼치면 같은 행 목록.
- F9 내보내기: 출처 캡션 "내가 입력한 일정 · 한국 시간" + button-outline "이번 달 n개 .ics 내보내기"(이번 달 0개면 비활성). 누르면 바로 파일 저장(확인 창 없음).
- F10 하단 안내 캡션: "날짜는 내가 저장한 기록이에요. 대학 공식 모집요강에서 최종 확인해 주세요. 날짜 미정 항목은 내보내지 않으며 자동 알림은 전송하지 않아요. 수정한 일정은 다시 내보내 주세요."

상태
- S-a 불러오는 중: "일정을 불러오고 있어요."
- S-b 불러오기 오류: 저장소 오류 문구(role=alert).
- S-c 전형 0개: 목록 빈 문구 + button-outline "지원할 전형부터 등록하기"(→ 체크리스트).
- S-d 이번 달/선택한 날 일정 0개: "등록한 일정이 없어요. 체크리스트에서 마감일을, 수시로에서 고사 날짜를 입력해 주세요."
- S-e 다가오는 일정 없음: 카드 문구 "날짜가 확인된 미완료 일정이 없어요." + 오른쪽 "날짜 미정".
- S-f 없는 전형(?plan= 이 삭제된 전형): 선택지 "삭제되었거나 없는 전형" + 경고 "이 전형을 찾지 못했어요. 전체 전형을 선택하거나 지원 준비 기록을 확인해 주세요."
- S-g 내보내기 실패: "일정을 내보내지 못했어요. 브라우저 다운로드 권한을 확인해 주세요."
- S-h 내보내기 비활성: 이번 달 일정 0개.
- S-i 목록 보기: 그리드 없이 F5 목록만.
- S-j 날짜 선택: 그리드에서 한 날 선택 + 목록이 그날로 좁혀짐.

팝업
- M1 일정 상세 Modal(aria "입시 일정 상세", Esc·포커스 가둠): 제목(일정 이름) + button-outline "닫기" / 대학 · 학과 / 연도 · 전형 / 날짜 시각 · 상태 / (안 이름)에 기록 · "안마다 고사 날짜가 다르면 각각 표시돼요." / "내가 입력한 일정 · 한국 시간 기준" / 메모(면접·논술·실기는 "고사 시각은 수시로에 기록되지 않아요. 원문에서 확인해 주세요.") / 링크 "등록한 원문 확인 ↗"(안전한 URL만) / button-outline "일정 수정하러 가기"(고사 → 수시로, 원서·서류 → 체크리스트).
- 그 밖의 팝업·확인 창·toast는 구현에 없음. 필터는 기본 select, 날짜 미정은 details 접힘.

- P1: 보기 전환은 앱과 같이 segmented-control 두 칸 "월간 · 목록"(F3). 월간 = "‹ 2026년 11월 ›" 월 이동 + 7열 그리드, 칸에는 일정 이름 대신 숫자 아래 "n건"(앱 그대로) 또는 잉크 점(최대 3개 + "+n") 중 S2에서 하나로 고정. 날짜를 누르면 그날 목록이 아래(모바일) / 오른쪽 패널(PC). 목록 = 날짜 머리("11.21 토 · D-3") 아래 행, 일정 없는 날은 건너뜀. 주간·3일·하루 보기는 만들지 않는다. [근거: L1, L2, L4, L8, L11]

## design.md 수정 제안 (S2 전에 확인 필요)

- 캘린더 부품 이름이 design.md·rules `components`에 없다: 월간 그리드(`calendar-month`), 목록 행(`agenda-row`), 다가오는 일정 카드(`dday-card`), 유형 꼬리표(`event-type-tag`), 월 고르기 패널(`month-picker`). G2가 "design.md에 없는 컴포넌트 이름 = 0"을 보므로 이름을 올리거나 기존 이름(data-table, stat-tile, filter-chip, bottom-sheet, modal)으로만 설계하도록 정해 주어야 한다.
