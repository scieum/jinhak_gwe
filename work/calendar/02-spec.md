겹치지 않게 본 것: 원서·서류 체크리스트는 마감일을 **입력**하는 화면, 수시로는 고사 날짜를 칸에 **입력**하는 화면이에요. 이 화면은 그 두 기록을 날짜로 **모아 보기만** 해요. 새 날짜를 입력하지 않고, 대학 공식 일정(관리자 데이터)을 끌어오지 않고, 서버에 보내지 않아요. 판정(안정 · 적정 · 소신 · 위험) · 판정 배지 · 환산 숫자가 없어요.

## 4. 데이터 규칙

- 일정 = 원서·서류 체크리스트 단계(마감일이 있으면 날짜 · 시각) + 수시로 칸(고사 종류 · 고사 날짜, 시각 없음). 같은 전형 · 같은 고사 · 같은 날짜가 여러 안(A안 · B안)에 있으면 한 행으로 합치고 "A안 · B안에 기록"으로 보여요(앱 그대로).
- 종류 = 기록 출처로만 정해요: 체크리스트 단계 → 원서·서류(event-doc), 수시로 고사 → 면접·논술·실기(event-exam). 일정 이름 글자로 종류를 추정하지 않아요.
- 수시로 고사는 완료 상태가 없어서 지난 날짜면 "기한 지남"이에요. 시각이 있는 체크리스트 일정은 그 시각이 지나는 순간 "기한 지남"(한국 시간).
- 내보내기(.ics) = 지금 필터가 걸린 "이번 달" 일정만. 날짜 미정은 빠져요. 서버로 보내지 않고 기기에서 파일을 만들어요. 자동 알림을 보내지 않아요. 파일에는 색이 들어가지 않아요.
- 관리자 데이터(시행계획 · 모집요강 일정)를 쓰지 않아요. 환산 · 판정 계산이 없어서 NEVER-1 대상 숫자가 없어요.
- 앱 반영 사항(2026-11-24): 일정 종류 색 토큰(event-doc · event-exam 두 쌍)을 앱 색 정의에 추가하고, 달력 칸 표식 줄 · 범례 · 칩 표식 · 행 종류 태그를 그려요.

## 7. 접근성

- 달력 = 표(caption "2026-11 일정 달력 · 날짜를 누르면 해당 날짜의 일정을 표시해요"), 칸 = 버튼(aria "2026-11-21 일정 2개, 면접·논술·실기 2개" / "일정 없음"), 오늘 aria-current=date, 선택 aria-pressed. 오늘 · 선택은 모양(잉크 채움 · 테두리)으로도 구분돼 색에 기대지 않아요.
- 종류 표식은 aria-hidden이고, 종류는 칸 aria · 태그 글자 · 칩 이름 · 범례 글자로 읽혀요. 칸 표식은 두 자리 고정(왼쪽 원서·서류, 오른쪽 면접·논술·실기)이라 색을 구분하기 어려워도 자리로 읽혀요. 표식 · 태그 대비는 흰 바탕 · 선택 칸 · tint 위 모두 5.1:1 이상.
- 방향키로 칸 이동(앞뒤 날 · 위아래 주), Enter/Space로 선택 · 해제. 달이 바뀌면 "2026년 11월"을 조용한 알림으로 알려요.
- 필터 칩: 일정 종류 3칩 = 라디오 묶음, "완료 포함" = 토글 버튼(aria-pressed), "전형" 칩 = 시트 · 목록을 여는 버튼(aria-haspopup).
- 행 = 버튼(aria "경희대 행정학과 면접 일정 상세, 면접·논술·실기"). 상태는 글자라서 색 없이 읽혀요.
- 시트 · 모달 열면 제목으로 포커스, 포커스 가둠, Esc로 닫고 누른 자리로 포커스가 돌아가요. 라디오 행은 방향키.
- 오류 · 안내 줄 role=alert, 불러오는 중 role=status. `toast`는 role=status.
- PC 떠 있는 목록(전형 · 달 고르기): 누른 칩 · 제목에 aria-expanded, 방향키로 행 이동, Esc · 바깥 누름으로 닫고 누른 자리로 포커스가 돌아가요.
- 숫자 · 날짜 고정폭. 모바일 터치 44 이상(칸 50×48, 칩 터치 44), 포커스 2px 잉크 링. 대비 4.5:1 이상({colors.text-faint}는 비활성 버튼 글자에만).
- 시트 · 모달 240ms, 선택 · 칩 150ms, prefers-reduced-motion이면 바로.
