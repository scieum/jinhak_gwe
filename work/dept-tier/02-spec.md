## 4. 규칙 (시안 숫자의 근거)

- 대상: 계열표(관리자 2명 검수)에서 대계열 · 중계열 · 소계열이 고른 값과 같은 모집단위 → 그중 공개 입결(관리자 2명 검수)이 있고, 수시 · 고른 전형 유형 · 교과등급 · 9등급제 · 70% 컷 1~9 · 2026학년도인 행만.
- 구간 폭 w = {0.1, 0.2, 0.3, 0.5} 중 하나 또는 직접 넣은 값(0.05 ≤ w ≤ 1.0, 소수 둘째 자리까지), 기본 0.5, 이 기기에만 기억. 계산은 0.01 단위 정수로 해요(컷 c → 100c, 폭 → 100w)라 소수 오차가 없어요.
- 직접 값 검사: 숫자와 소수점 하나만, 소수 셋째 자리 이상 · 쉼표 · 글자 = 형식 오류, 0.05 미만 · 1.0 초과 = 범위 오류. 오류면 층을 다시 나누지 않고 직전 폭을 그대로 써요. 빈칸 = 직전 폭 유지(오류 아님).
- 층: 아래 경계 = 1.0 + floor((c − 1.0) / w) × w, 위 경계 = 아래 경계 + w. 아래 경계 포함 · 위 경계 미포함. 9.0은 마지막 층(위 경계가 9.0을 넘으면 9.0으로 잘라 표기)에 넣어요. 표기 자릿수 = 폭의 소수 자릿수(0.2 → "2.4~2.6", 0.25 → "2.50~2.75").
- 층 범위: 맨 위 층 = 가장 작은 c의 층, 맨 아래 층 = 가장 큰 c의 층. 그 바깥 층은 만들지 않아요. 사이 빈 층은 빈 줄. 층 수가 많아도 접거나 줄이지 않아요(위 층부터 세로 스크롤).
- 층 안 순서: 대학 이름 가나다 → 모집단위 이름 가나다. 같은 대학 여러 모집단위는 각각 칸.
- 3개 미만 = 자료 부족, 0개이고 검수 전만 있으면 = 준비 중(폭과 상관없어요).
- 새 환산 · 보간 · 가중치는 없어요. 공개된 9등급 컷을 고른 폭으로 나누기만 해요(NEVER-1 대상 계산 없음). 내 위치만 환산값이 필요해서 검수된 규칙이 생길 때까지 "준비 중"이에요.

## 7. 접근성

- 피라미드 = 층마다 제목("70% 컷 1.5에서 2.0 사이, 모집단위 1개")이 있는 목록. 읽는 순서 = 위 층 → 아래 층, 층 안 가나다순.
- 구간 폭 `segmented-control`은 라디오 묶음("구간 폭, 0.5 선택됨", 5개 중)으로 읽히고 방향키로 바꿔요. 폭을 바꾸면 "층 12개로 다시 나눴어요"를 화면 읽기 프로그램에 알려요(조용한 알림).
- 직접 입력칸: 이름 "구간 폭 직접 입력, 0.05부터 1.0까지", 숫자 키패드(소수점 포함). "직접"을 고르면 포커스가 입력칸으로 가요. 오류 문구는 입력칸 설명으로 연결돼 함께 읽히고(오류 상태 표시 포함), 오류가 나면 "구간 폭은 0.05부터 1.0까지 넣을 수 있어요. 표는 직전 구간 폭 0.5 그대로예요"를 알려요. 오류는 색만이 아니라 링 + 글자로 보여요. 맞는 값이면 "층 10개로 다시 나눴어요".
- 칸 대체 텍스트: "고려대학교 행정학과, 2026학년도 학생부교과 70% 컷 1.6, 대학 상세로 이동". 로고는 장식(alt 빈값), 대학명이 글자로 따로 있어요. 말줄임된 이름도 대체 텍스트에는 전체 이름이에요.
- 빈 층도 제목 + "공개된 입결이 없어요"로 읽혀서 간격을 놓치지 않아요.
- 내 위치(참고 상태): "내 위치 환산 9등급 약 2.2에서 2.8 사이, 대표값 2.5, 2.0~2.5 층과 2.5~3.0 층 사이" 문장을 같이 둬요. 색만으로 표시하지 않아요(선 + 점 + 말풍선 글자).
- 숫자 고정폭. 모바일 칸 · 버튼 · 세그먼트 칸 · 입력칸 44 이상(칸 98 × 약 130), PC 칩 · 칸 32 이상, 입력칸 40. 포커스 2px 잉크 링. 칸은 Tab으로 층 순서대로 이동, Enter = 상세. `trace-accordion`은 Enter/Space.
- 층 · 칸 바뀜 150ms 페이드, 시트 · 모달 240ms, 입력칸 열림 150ms, prefers-reduced-motion이면 바로.
