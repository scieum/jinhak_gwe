# 01-research — 학과별 입결 티어표 (dept-tier, 공개)

작성일 2026-11-23 · 담당 researcher (S1)
근거: 사용자 요청(채팅 원문) "피라미드 형태의 티어표로 과별로 등급표를 만들어서 거기에 학교로고와 학과명(사소하게 다를 수 있으니)을 넣어주면 좋을 것 같은데. 인문/자연으로 나누고 시안부터"
PRD에는 이 화면 절이 따로 없어요. 가장 가까운 근거는 6-1(전형계획 탐색, 누구나), 6-11(입결 데이터 등록 · 2인 검수), 8장 AdmissionResult(cut_70, grade_system 9), 13장(데이터 기준일 · 대학 공식 자료 고지 · NEVER-2)이에요.

## 0. 이 화면이 하는 일

| 블록 | 내용 | 데이터 조건 |
|---|---|---|
| 계열 고르기 | 인문 / 자연 탭 → 중계열 → 소계열(학과 묶음) | 관리자 검수 계열표(univ-detail-wiki '입결이 비슷한 대학'과 같은 표) |
| 티어 피라미드 | 고른 학과 묶음의 대학들을 수시 교과 70% 컷(9등급) 구간별 층으로 쌓음. 위층일수록 컷 숫자가 작음 | 2인 검수 뒤 공개된 입결만 (NEVER-1) |
| 칸 | 대학 로고 + 그 대학의 실제 모집단위 이름(예: 행정학과 / 공공인재학부 / 정책학과) + 컷 숫자 | 같음 |
| 어떻게 나눴나요 | 층 경계값, 기준 학년도, 전형 유형, 빠진 대학 기준 | 같음 |

- 티어는 "공개 입결 숫자 구간"일 뿐이에요. 서열 · 추천 · 지원 결과 예측으로 읽히면 안 돼요(NEVER-2).
- 공개 화면이라 판정 색(안정/적정/소신/위험)을 층에 쓰지 않아요. Route Blue는 학생이 자기 위치를 켰을 때 그 표시에만 써요.
- 환산 9등급(내 위치)을 함께 보일 경우 검수된 환산 규칙만 써요(NEVER-1). 1차 시안 범위인지는 S2 결정.

## 1. 레퍼런스 (uibowl)

검색 6회, 모두 1페이지: 패턴 `랭킹 × 교육&도서`, 패턴 `랭킹 × 금융`, OCR `티어`(3건 모두 무관: 토스 '프롭티어', Kia '티어링', 펫프렌즈 상품명 → 넣지 않음), OCR `랭킹 기준 × 랭킹`, 컴포넌트 `탭, 칩 × 랭킹`, 패턴 `브랜드 × 그리드`(0건 — 그리드는 uibowl 컴포넌트 이름이 아님).

## 2. 반영 포인트

- P1: 계열 선택은 3단으로 화면 위쪽에 쌓아요: 인문/자연 = `segmented-control`(또는 상단 탭) → 중계열 = 가로 스크롤 텍스트 줄 → 소계열(학과 묶음) = 칩. 소계열이 많으면 칩 대신 드롭다운으로 접어요. 새 컴포넌트를 만들지 않고 design.md 기존 탭 · 칩 · 드롭다운으로 되는지 S2에서 확인 [근거: L10, L12, L3, L9]
- P2: 피라미드는 "위층일수록 칸이 적고 좁은" 층 쌓기로 그려요. 층 = 70% 컷 구간 하나(예: "1.0 ~ 1.5"), 층 머리에 구간 숫자를 그대로 적고, 층 이름은 숫자 구간만 써요(S/A/B · 1티어 같은 서열 이름 · 트로피 · 메달 · 순번은 쓰지 않음). 모든 층은 같은 중립 색(판정 색 금지) [근거: L2, L1, L11]
- P3: 칸 하나 = 원형(또는 정사각) 로고 + 그 대학의 실제 모집단위 이름 + 컷 숫자 세로 스택. 모집단위 이름은 대학이 쓰는 그대로 두고 2줄까지 말줄임, 대학명은 로고 아래 캡션. 로고 자산이 없으면 같은 크기의 이니셜 기본 칸으로 채워 줄 높이를 맞춰요 [근거: L2, L4, L9]
- P4: 같은 층 안 칸 순서는 서열로 읽히지 않게 가나다순(또는 컷 오름차순 중 S2 결정)으로 두고 순번 숫자를 붙이지 않아요. 칸을 누르면 그 대학 상세(univ-detail, 해당 모집단위)로 이동 [근거: L9, L4, L5]
- P5: 피라미드 바로 위에 "어떻게 나눴나요" 진입을 둬요: 제목 옆 ⓘ 또는 "안내" 텍스트 버튼 → 펼침/시트에 층 경계값, 기준 "2026학년도 수시 교과 70% 컷(9등급) · 관리자 검수 입결만", 빠진 대학 조건(입결 미공개 · 검수 전 · 모집단위 없음)을 불릿으로 [근거: L4, L11, L7, L8]
- P6: 기준 시각 · 출처를 피라미드 위에 작게 먼저 적어요: "기준 2026학년도 입결 · 데이터 기준일 2026-11-20". 아래에는 `disclaimer-note` "공개된 작년 입결 숫자를 구간으로 묶은 표예요 · 대학 순위나 추천이 아니에요 · 대학 공식 자료가 최종 기준이에요" [근거: L9, L5, L13, L7]
- P7: 학생이 자기 위치를 켜면(선택) 피라미드 옆 세로 축에 내 환산 9등급 범위를 마커 하나로만 표시하고, 이 마커에만 Route Blue를 써요. 칸 · 층에는 색을 더하지 않아요. 내 위치는 목록과 분리된 박스(켜기 전 "내 위치 켜기" 상태)로 두고, 검수된 환산 규칙이 없으면 마커 대신 "준비 중" [근거: L8, L6]
- P8: 데이터 부족 상태는 층 · 묶음 단위로 표시해요: 검수된 입결이 있는 대학이 기준 수(예: 3곳) 미만이면 피라미드 대신 "이 학과 묶음은 공개된 입결이 아직 적어요" `empty-state`, 검수 전 대학은 칸으로 그리지 않고 "준비 중 n곳" 한 줄만 [근거: L6, L7]

## 3. 화면 위치 · 구성 순서 (제안)

1. 앱바 "학과별 입결 티어표" + ⓘ
2. 인문 / 자연 → 중계열 → 소계열 선택 (P1)
3. 기준 줄 + "어떻게 나눴나요" (P5, P6)
4. (선택) 내 위치 박스 (P7)
5. 피라미드 (P2~P4) — 390 폭에서는 층마다 칸이 넘치면 층 안 가로 스크롤 또는 줄바꿈 중 S2 결정, 1440 폭에서는 좌우 대칭 피라미드 + 오른쪽 세로 컷 축
6. `disclaimer-note` (P6)

## 4. S2 주의 · 미결

1. design.md를 이번 S1에서 열어 보지 않았어요. 피라미드 층 · 로고 칸이 기존 컴포넌트(`univ-card`, `data-table`, `segmented-control`, `empty-state`, `disclaimer-note`, `data-status-badge` 등)로 표현되는지 확인하고, 안 되면 새로 만들지 말고 "design.md 수정 제안"으로 멈춰 주세요.
2. 층 경계값: 고정 폭(0.5 등급 단위) vs 분위수 중 무엇으로 할지, 경계값을 관리자 설정으로 둘지 S2에서 정해야 해요. 정해지기 전에는 가상 숫자로만 그려요.
3. "티어"라는 단어 자체가 서열로 읽힐 수 있어요. 화면 제목은 사용자 명칭 "티어표"를 따르되, 층 이름은 숫자 구간만 쓰기를 권해요. 금지어 목록(rules/design-rules.json `forbidden_words`)과 대조는 S2 몫이에요.
4. 학교 로고 사용: 로고 이미지 사용 허락 · 자산 출처가 정해지지 않았어요(PRD 13장 "사용 허락 확인된 자료만"). 시안에서는 이니셜 기본 칸으로 그리는 안을 함께 준비해 주세요.
