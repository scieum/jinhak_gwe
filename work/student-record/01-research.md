# 01 리서치 — 학생 기록 상세 (student-record, 교사용)

조사일 2026-11-18 · 출처 uibowl (무료 등급, 검색어를 바꿔 10회 검색)
대상: 교사가 학생 한 명을 열어 보는 상세 화면. 탭 = 성적 추이 / 수능 최저 / 상담 / 누가기록 / 수시로. 핵심은 **성적 추이 탭**.
- 내신: 학기별 평균 등급 선 차트 (전 교과 · 국수영사과)
- 모의고사: 회차별 영역 등급 선 차트 (국 · 수 · 영 · 탐1 · 탐2)
- 등급 축은 1이 위 (값이 작을수록 위)

디자인 전제 (design.md 2026-11-18): 모서리 0, 흑백 바탕, 색은 판정색(결정 신호)과 Route Blue(선택 상태 · 핵심 숫자 1~2개)만. 등급 숫자에 색을 넣지 않는다.

검색어: 성적 리포트 · 학습 리포트(+그래프&차트) · 차트 · 그래프&차트+탭(통계·리포트) · 자산 추이(0건) · 대시보드(PC) · 프로필 상세(PC) · 그래프&차트+탭(PC) · 타임라인(PC) · 통계·리포트+그래프&차트(PC)

## 반영 포인트

- P1: 등급 선 차트는 점 마커 + 직선, Y축은 1이 위(내신 1~5, 모의고사 1~9 눈금), 가장 최근 학기/회차 점만 Route Blue 원 + 값 라벨로 "지금"을 표시하고 나머지 점·선은 잉크 [근거: L1, L6]
- P2: 계열이 여러 개(국·수·영·사·과 / 국·수·영·탐1·탐2)라 색으로 나누지 않는다 — 카드 위 과목 칩(필터 칩, 선택 = Route Blue 1px 테두리 + accent-soft)으로 고른 계열만 Route Blue 2px 선, 나머지는 hairline 회색 1px 선 + 선 끝 직접 라벨(과목명) [근거: L2, L5, L7]
- P3: 차트 아래에 같은 값을 표로 반복한다(행 = 과목/영역, 열 = 학기/회차, 고정폭 숫자 오른쪽 정렬, 빈 값은 "–") — 정확한 값 확인과 차트 대체 텍스트 역할을 함께 한다 [근거: L1, L6]
- P4: 차트 카드 머리에 규칙으로 계산한 추이 한 줄 문장(예: "지난 학기보다 평균 등급 0.3 낮아졌어요(좋아졌어요)")을 두고, 비교 기준은 가로 점선 1개 + 캡션으로만 표시 [근거: L1, L2]
- P5: 화면 머리 = 학생 정보 한 줄(학년 · 반 · 번호 · 희망 진로) → 숫자 타일 2~3개(최근 내신 평균, 최근 모의고사 평균) 중 핵심 숫자 1개만 Route Blue → 탭 5개(선택 = 아래 2px Route Blue 막대) [근거: L4, L8, L10]
- P6: PC는 사이드바 + 성적 추이 탭 본문을 내신 카드 | 모의고사 카드 2열로 나란히, 모바일은 같은 카드를 세로 1열로 쌓고 탭 줄은 가로 스크롤 [근거: L6, L9, L3]
- P7: 기간 범위는 카드 오른쪽 위 세그먼트(전체 · 최근 4회)로 바꾸고, 카드·칩·세그먼트 모서리는 모두 0으로 옮긴다(레퍼런스의 둥근 칩·막대 모서리는 가져오지 않음) [근거: L5, L2]

## 가져오지 않는 것

- L3·L5의 노랑·분홍·청록 계열 색 구분 → 흑백 + Route Blue 선택 계열로 대체 (design.md: 등급에 색 금지, 판정색 장식 금지).
- L8의 일러스트·사진 머리 → 학생 사진 없이 이름·번호 텍스트만 (교사 기기 개인정보 최소화).
