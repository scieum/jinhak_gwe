## 5. 접근성

- 범위 막대 대체 텍스트: "환산 9등급 약 2.3에서 2.6 사이, 대표값 약 2.45, 신뢰도 보통이에요."
- 방법 점마다 접근 이름: "A-1 평균 기반 약 2.3".
- 신뢰도는 색 없이 글자로만 표시해요. 등급 숫자에 색을 넣지 않아요.
- 대비 4.5:1 이상, {colors.text-faint}는 읽는 글자에 쓰지 않아요.
- 모바일 터치 영역 44px 이상(세그먼트·아코디언 머리), 포커스는 2px 잉크 링.
- 대표값 표시가 미끄러져 들어오는 400ms 동작은 prefers-reduced-motion이면 끄고 바로 보여줘요.

## 6. 문구 원칙 점검

- 모든 문장 해요체.
- 추정값에는 "약", 묶음 값에는 "범위", 결과 제목에는 "추정"을 붙였어요.
- 합격을 약속하거나 수치로 단정하는 표현은 쓰지 않았어요. 순위로 읽히는 "상위 n%" 배지도 쓰지 않아요(누적비는 근거 단계에만).

## 디자이너 메모

- 프레임은 정확히 2개: five-to-nine/390 (390×844), five-to-nine/1440 (1440×900).
- 레이어 이름 = 컴포넌트 이름으로 지어요. 예: `range-bar-5to9`, `stat-tile`, `grade-chip`, `data-table`, `trace-accordion`, `disclaimer-note`, `segmented-control`, `segmented-control-active`, `tab-bar-pill`, `sidebar`, `mode-switch`. 컴포넌트가 아닌 요약 줄·설명 문장은 "summary"·"method-gap-note"처럼 일반 텍스트 레이어로 둬요.
- 알약(버튼, 세그먼트, 칩, 신뢰도 배지, 범위 막대 트랙, 탭바)의 cornerRadius는 9999. 카드 24, 표 컨테이너·아코디언 16, 범위 막대 내부 구간 0.
- 색은 팔레트 변수에 바인딩해요. Route Blue(#0066ff)는 범위 막대의 대표값 원과 말풍선에만 써요.
- 그림자는 `segmented-control-active`에만 있어요. 카드·패널·표에는 그림자를 넣지 않아요.
- 글꼴 Pretendard(300/400/600/700), 자간 0, 숫자는 고정폭.

계산식:

- A-1 (R-CONV-001 → 002 → 003, v3.1-2와 같음): p = 5 + (g5 − 1) × 17, g9 = 2 + (p − 7.5) ÷ 9.5.
- A-2 (R-CONV-004 + R-CONV-010): 과목 하나를 같은 보간으로 바꾼 뒤 학점 비중으로 가중 평균해요.
  - 1등급(수강자 많음): 누적비 가운데 5% → g9 = 1 + (5 − 2) ÷ 5.5 = 1.5455
  - 2등급(수강자 많음): 22% → g9 = 3 + (22 − 17) ÷ 14.5 = 3.3448
