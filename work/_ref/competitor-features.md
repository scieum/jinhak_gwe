## 0. 먼저 알아야 할 시장 변화 (2026-07-29)

「초·중등교육법」 제25조의2(학교생활기록의 상업적 이용 제한)가 **2026-07-29부터 시행**됐어요. 이 때문에 사설 서비스가 크게 바뀌었어요.

- **바이브온**: 생기부 학업·교내활동 정보를 DB에 저장하지 않고(로그인 세션이 끝나면 파기), 다른 이용자 데이터와 비교하는 상대평가를 절대평가로 바꿨어요. 업로드 즉시 회원 보안키로 암호화해요. (vibeon.ai/official/notice/3965)
- **진학사**: 교사용 진학통 판매를 멈췄다가 교과 기준으로만 재개했어요. 수시 합격통은 **학생부 AI 진단을 빼고**, 종합전형도 비교과 없이 교과 성적만으로 제공해요. 교육부 1차 회신은 "서술형 항목(창체·세특) 분석·평가의 영업 활용"이 주된 규율 대상이고 교과 성적 산출·모의지원은 일률적으로 막는 건 아니라는 취지예요. (jinhak.com/jh/customer-center/notice/2688)
- **메가스터디**: 생기부 전체를 받지 않고, 회원이 직접 입력한 교과 성적만으로 진단한다고 밝혀요.
- **서울시교육청**: 법 시행을 계기로 "공교육 진학지원 강화"를 내세웠어요(쎈진학 나침판·1:1 상담 확대).

**시사점**: 사설 서비스에서 "생기부 서술 영역 AI 분석"이 빠지거나 약해졌어요. 공교육 무료 서비스인 진학 내비의 생기부 AI 분석은 오히려 빈자리를 채울 수 있어요. 다만 이 법이 비영리 공공 서비스 + 외부 LLM 전송에 어떻게 적용되는지는 확인되지 않았어요(PRD 미결 #7과 함께 확인 필요).

## 2. 기능 갭 — 경쟁 서비스에는 있고 진학 내비에는 없는 기능

- **N1** = NEVER-1(검수 안 된 계산 공개 금지) · **N2** = NEVER-2(합격 확률·가능성 표현 금지)
- **저장** = 학생 데이터 서버 저장 안 함(교사 학급 데이터만 RLS 서버) · **AI** = 실행 중 AI는 생기부 분석만
