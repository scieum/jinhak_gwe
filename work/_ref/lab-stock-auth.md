## 결정 (사용자, 2026-11-18)
- 로그인은 **교사·관리자만**. 학생은 로그인 없이 기기 저장(카드는 QR·파일).
- 교사 학급 데이터는 서버(Supabase) 저장 — PRD "MVP 회원가입·서버 저장 제외"를 바꿈(work/_pending/apply5.py 예정).

## 화면 구성 (그대로 가져옴)
- **로그인 PC(1440)**: 상단 web-header(왼쪽 워드마크, 오른쪽 "회원가입" 검정 버튼). 왼쪽 반(720) 가운데 폼 440: 제목 "로그인" + 부제 "개인 이메일로 로그인하세요", 개인 이메일, 비밀번호(눈 아이콘 보기 토글), "로그인" 주요 버튼(입력 전 비활성), "비밀번호 찾기" 링크, "아직 회원이 아니신가요? [회원가입 ›]"(button-pill-soft). 오른쪽 반(720) 회색 소개 패널.
- **로그인 모바일(390)**: nav-pill(워드마크) + 폼 카드 + 아래 회원가입 줄. 탭바 없음.
- **회원가입 PC**: 같은 반 나눔. 폼 = "1 학교 선택"(안내 띠 "고른 학교의 기록만 보여요. 가입한 뒤에는 바꿀 수 없어요", 4단계 진행 막대, 시/도 → 지역(시/군/구) → 학교급 세그먼트 → 학교 드롭다운) → "2 계정"(이름, 개인 이메일, 비밀번호 8자 이상 + 보기, 비밀번호 확인) → 약관(모두 동의 / 서비스 이용약관(필수) / 개인정보 수집·이용(필수) / 만 14세 이상(필수), 각 › 열기) → "가입하기" 주요 버튼 → "이미 계정이 있으신가요? [로그인 ›]".
- **흐름**: 가입 → 확인 메일 링크 → 로그인. 메일 확인 전 로그인 = "아직 이메일 확인이 끝나지 않았어요…". 비밀번호 찾기(메일 발송) → 재설정 → "비밀번호를 바꿨어요. 새 비밀번호로 로그인하세요." 안내. 메일 링크 만료 안내. 프로필(학교) 없는 계정 안내.
- 오류 문구 예: "이메일 또는 비밀번호가 올바르지 않아요." "서버에 연결하지 못했어요. 잠시 후 다시 시도하세요."
