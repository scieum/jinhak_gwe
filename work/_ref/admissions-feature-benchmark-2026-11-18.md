# 입시 서비스 추가 기능 조사 — 공식 자료 재검증과 확장 제안

조사일: 2026-11-18(KST) · 대상: 진학 내비 · 상태: 연구 및 제안, 구현 완료 목록 아님

## 1. 조사 범위와 읽는 방법

진학사·유웨이·대학어디가·바이브온, 메가스터디·이투스·EBSi·강원진학지원센터·진학어플라이의 공식 공개 페이지를 조사했다. 로그인·결제 후 기능을 직접 사용한 평가는 아니다. 동적 페이지의 본문을 읽지 못한 경우 공식 도메인의 검색 색인으로 확인한 사실만 기록했다. 가격·정확도·이용자 수는 비교하지 않았다.

기존 [경쟁 서비스 조사](competitor-features.md), [남은 디자인 계획](../_pending/design-plan.md), [PRD](../../docs/prd.md), [앱 구현 기록](../../app/IMPLEMENTATION.md)을 함께 대조했다. **PRD에 있음 / 이미 채택한 확장 / 이번 추가 제안 / 보류**를 구분한다. “기존”은 기획에 있다는 뜻이며 실제 앱 구현 완료를 뜻하지 않는다.

2027학년도 서비스 사례는 기능 구조를 참고하기 위한 자료다. 진학 내비의 대상인 2028학년도에 일정·지원 자격·성적 산식·입결 기준을 그대로 적용하지 않는다.

후속 구현: 사용자 요청에 따라 **N01·N03·N04·N06의 앱 기능을 구현**했다. 아래 표는 조사 당시 우선순위이며 최신 구현 범위·데이터 제한·검증은 [우선순위 높음 구현 기록](priority-features-implementation.md)을 따른다. N12 전형 성향 탐색은 별도 체험판으로 구현했다.

## 3. 이미 채택한 기능 — 추가 개발로 중복 계산하지 않기

기존 문서의 사용자 결정과 디자인 계획 B1~B5에 이미 포함되어 있다. 아래는 채택 상태를 재확인한 것이며 이번 조사에서 새로 승인받은 기능이 아니다.

| 기능 | 예정된 내용 | 이번 조사로 보강할 점 |
|---|---|---|
| 입시 캘린더 | 내 카드 일정, 월/목록 보기, 고사 겹침, D-day, ICS 내보내기 | 제출·접수 완료 여부까지 확장할지 검토 |
| 수능최저 역검색 + what-if | 기준 시험 선택, 충족/근접/미충족/자료 부족, 한 영역 등급 변경 | 원래 성적을 보존하고 가상 조건임을 명확히 표시 |
| 전형 비교 | 관심 전형 2~4개, 다른 점만 보기, 전형·입결 비교 | 연도·점수 척도가 다른 수치의 비교 가능 여부 표시 |
| 면접 준비 | 예상 질문, 답변 메모, 연습 체크, 타이머, 기기 저장 | 공식 기출과 AI 예상 질문을 구분하고 자료 출처 표시 |
| 공공 바로가기 | 상담·원서·경쟁률 공식 링크 | 지역·대학·관심 전형에 맞는 링크 우선 노출 |

## 4. 이번 추가 기능 후보

다음은 관찰한 서비스 흐름에서 도출한 **진학 내비용 설계 제안**이다. 참고 사이트가 아래 기능을 동일하게 제공한다는 뜻은 아니다. P1은 다음 확장 후보, P2는 후속 후보, P3은 범위 재검토다. 예상 난도는 기존 데이터 확보를 가정한 상대 평가이며 일정 견적이 아니다.

| ID | 추가 기능 | 학생·교사가 실제로 하는 일 | 기존 대비 차이 | 참고·추론 근거 | 우선순위 / 난도 |
|---|---|---|---|---|---|
| N01 | **원서·서류 제출 체크리스트** | 카드별로 원서 작성, 결제, 접수 확인, 제출서류, 도착 확인을 따로 체크. 대학 공식 확인 링크 열기 | 달력은 날짜, 보드는 지원 후보 중심. “완료했는지”를 관리하는 단계 추가 | 진학어플라이 접수·서류 확인 안내를 개인 작업표로 확장 [S12] | **P1 / 중** |

## 7. 기존 조사에 대한 보강·불확실성

- **대학어디가:** 기존 문서는 공식 본문을 읽지 못했다고 기록했지만, 이번에는 공식 초보자 가이드로 성적 조합·연도별 산식·상담 출력·학과 정보를 직접 확인했다. HTML/OCR 입력이나 관심대학 최대 개수, AI 출시일은 이번에 재검증하지 않았으므로 이 보고서의 확정 사실에 포함하지 않는다. [S3]
- **유웨이:** 2026-07-29 공지는 비교과 입력과 학생부종합 모의지원 리포트 일부의 일시 중단을 안내한다. 이번 조사에서 재개 공지를 확인하지 못했으므로 현재 전체 기능이 정상 제공된다고 단정하지 않는다. 이 서비스 공지를 진학 내비의 법적 적용 여부에 대한 결론으로 사용하지 않는다. [S13]
- **바이브온:** 2026-05-19 리포트 공지는 당시 변경의 근거이며 모든 항목이 현재 그대로 유지된다는 증거는 아니다. 수시ON·면접ON 소개 URL은 확인했지만 동적 본문을 읽지 못해 영상평가·질문 수·시즌 기간을 최신 사실로 재사용하지 않았다. 무료 체험 안내의 기간·횟수도 고정 조건으로 옮기지 않았다. [S4][S5]
- **진학사:** 점공은 서비스에 자발적으로 등록한 이용자의 표본이며 전체 지원자를 직접 보여 주는 기능으로 해석하지 않는다. 우리 제안 N05는 표본 순위나 추가합격 예측을 사용하지 않는다. [S1]
- **기존 결정 유지:** 생기부 AI·PDF 입력 유지, 채택된 5개 확장, 학생 기기 저장과 검수 규칙 사용 원칙을 이번 조사로 변경하지 않았다. 후보 N01~N11은 미승인 제안이다.
- **검색의 한계:** 공개 안내만으로 사용성·예측 성능·현시점 유료 기능 접근성은 검증하지 못했다. 다른 사이트 기능 소개를 우리 서비스 데이터의 이용 허락으로 간주하지 않는다.
