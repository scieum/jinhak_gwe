# schs_lms "역량 보기" 분석 (2026-11-18)

출처: github.com/scieum/schs_lms — `apps/web/src/lib/domain/competency.ts`, `apps/web/src/components/writing/competency-view.tsx` (Figma N11, N56)

## 무엇을 하나
생기부 문장을 대입 학생부종합전형 평가 **3대 역량**(대교협 2024 개편 공통 평가요소)으로 문장마다 나누고, 색으로 칠해 보여준다. 옆 패널에서는 **평가항목 10개**로 나눠 문장 수를 센다. 교사가 참고로만 본다.

## 3대 역량 × 평가항목 10개
| 역량 | 평가항목 (짧은 이름) |
|---|---|
| 학업역량 | 학업성취도 · 학업태도 · 탐구력 |
| 진로역량 | 전공(계열) 관련 교과 이수 노력(교과 이수 노력) · 전공(계열) 관련 교과 성취도(교과 성취도) · 진로 탐색 활동과 경험(진로 탐색) |
| 공동체역량 | 협업과 소통능력(협업과 소통) · 나눔과 배려 · 성실성과 규칙준수(성실·규칙준수) · 리더십 |

## 화면 구성
- **본문 색칠**: 문장마다 역량 옅은 색 배경. 한 역량/항목을 고르면(초점) 해당 문장은 진한 색, 나머지는 35% 투명. 문장에 마우스를 올리면 툴팁(평가항목 이름 + 역량 이름).
- **평가 항목 패널**(오른쪽 264px): "평가 항목 · N문장(· 자동)", 3색 비율 막대(문장 수 비례), 역량 행(색 점 + 이름 + n문장) 아래 항목 행(이름 + 개수). 개수 0은 흐리게·비활성. 누르면 초점 토글.
- **빠진 항목**: 문장이 없는 항목 최대 2개를 "○○·○○ 문장이 없어요"로 알림.
- **역량 확인(간단형)**: 역량 3줄 — 색 점 + 이름 + 문장 수 비례 막대 + "n문장", 아래 빠진 항목 칩. "문장 색으로 보기 ›"로 본문 색칠 열기.
- AI가 나누면 "AI" 라벨 + "저장된 결과 · 시각" + "AI로 다시 나누기". AI가 꺼져 있으면 **낱말 규칙**으로 나누고 "자동" 표시.

## 규칙 기반(AI 없을 때)
평가항목마다 낱말 정규식(예: 탐구력 = 탐구|실험|가설|분석|측정…, 협업과 소통 = 모둠|협력|토의|발표…). 낱말이 가장 많이 걸린 역량을 고른다(같으면 학업 > 진로 > 공동체).

## 색 (schs_lms 원본)
학업 파랑(tint #D3DAFF, dot #536DFE) · 진로 초록(#C9F0DC, #00B86B) · 공동체 노랑(#FFE6B0, #F5A524).
→ 진학 내비에서는 Route Blue(선택)·판정색(안정 초록·소신 주황)과 겹치지 않게 조정한 토큰을 쓴다(work/_pending/apply2.py).

## 진학 내비 적용 시 주의
- 점수·5단계 점·등급처럼 평가 결과로 읽히는 표현 대신 **문장 수**만 보여준다(NEVER-2).
- 실행 중 AI는 생기부 분석만 허용(PRD 13장) — 이 기능이 그 범위. AI 블록엔 ai-label.
- 원문 인용은 원문에 실제 있는 문장만.
