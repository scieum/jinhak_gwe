# 대입 전형 성향 탐색 — 길콩과 나의 준비 방식 찾기

작성: 2026-11-18 · 기능 ID: N12 · 앱 경로: `/admission-style`

## 사용자 요청과 현재 산출물

사용자 요청: “MBTI 검사 비슷한 대입 전형 심리검사”, 나에게 어울리는 전형 추천, 유아이볼 참고, 색을 활용한 화면, 직접 만든 캐릭터 에셋.

기능을 추가 조사표에 등록하고 실제 클릭 가능한 React 체험판을 만들었다. 학생 메뉴 `대학 찾기 → 전형 성향 탐색`에서 진입한다. 소개 → 15문항 → 결과 → 실제 성적 확인으로 이어진다. 기능 구현과 Figma 정식 시안은 별개이며 이번 작업에서 Figma 파일은 수정하지 않았다.

표준화된 심리검사로 소개하지 않는다. 검사 이름은 **전형 성향 탐색**, 결과는 **함께 살펴볼 전형**이다. 질문과 연결 규칙은 직접 작성한 체험판이다. 성적·지원 자격·대학별 평가 기준은 별도로 확인한다. MBTI 코드로 전형을 결정하거나 내향/외향으로 면접 적합성을 단정하지 않는다.

## 결과 유형

| 준비 방식 | 친근한 유형 이름 | 탐색할 전형 | 결과에서 따로 확인하는 것 |
|---|---|---|---|
| 수업·과제·과목별 계획 | 꾸준히 쌓는 기록가 | 학생부교과 | 실제 내신, 반영 교과·학년, 성취도 처리, 수능최저, 자격 |
| 질문·탐구·성찰 | 깊이 파는 탐구가 | 학생부종합 | 학생부에 남은 과정, 과목 이수, 서류·면접 요소 |
| 자료 해석·논리·표현 | 근거를 잇는 논증가 | 논술 | 인문·수리 등 유형, 기출 수행, 제한시간, 수능최저 |
| 수행·제작·반복 연습 | 반복하며 만드는 실천가 | 실기·실적 | 실제 전공 준비, 실기 과제, 실적 인정 범위, 자격 |
| 시험 계획·오답·시간 배분 | 전략을 세우는 도전가 | 수능 중심 전형 | 모의고사 추이, 모집시기, 대학별 반영 영역·산식 |
| 여러 방식의 응답이 비슷함 | 여러 길을 살피는 탐색가 | 조건을 만족한 복수 전형을 함께 표시 | 임의로 하나를 우승 유형으로 만들지 않음 |
| 경험 부족·뚜렷한 선호 없음 | 경험을 더 알아가는 / 가능성을 열어 둔 탐색가 | 순위 없이 준비 방식 소개 | 낮은 능력이나 부적합 판정을 내리지 않음 |

## 문항과 규칙

질문 원본: [admissionStyle.ts](../../app/src/domain/admissionStyle.ts). 영역별 3문항, 총 15문항을 영역이 교대로 나오도록 배치했다. 문항은 성취 수준보다 준비 방식과 관심을 묻는다.

- 응답: 거의 그렇지 않아요(0), 가끔 그래요(1), 자주 그래요(2), 매우 그래요(3), 경험이 없거나 잘 모르겠어요(null).
- null은 0점으로 바꾸지 않는다. 영역마다 알려진 응답이 최소 2개 있어야 비교한다.
- 모든 영역의 비교가 가능할 때, 평균 2 이상이면서 최고 평균과 차이가 0.5 이내인 영역을 모두 표시한다.
- 알려진 응답이 부족하면 정보 부족 결과, 모든 평균이 2 미만이면 열린 탐색 결과를 표시한다.
- 이 기준은 **설계용 임시 규칙**이다. 심리측정 검증, 상담교사 문항 검토, 학생 파일럿 조사는 아직 하지 않았다. 정확도·신뢰도·합격확률·백분위를 표시하지 않는다.
- 결과에는 실제로 긍정 응답한 문장과 다음 확인 사항을 보여준다. 외부 AI 호출 없이 기기 내 고정 규칙으로 계산한다.
- 답변은 React 메모리에만 유지한다. 화면을 떠나거나 새로고침하면 초기화되며 성적 DB·서버·로그에 저장하지 않는다.

## UI와 캐릭터

| 화면 | 구성 |
|---|---|
| 소개 | “나에게 맞는 입시의 시작점.”, 길콩 일러스트, 15문항·약 3분(예상) 안내, 시작 버튼, 준비 방식 5개 카드 |
| 질문 | 한 화면 한 문항, 진행률, 라디오 5개, 이전/다음, 답변 변경, 길콩 응원 영역 |
| 결과 | 유형 이름, 탐색 전형, 내 응답 근거, 다음 확인, 규칙 펼치기, 성적 화면 연결, 다시 탐색 |
| 모바일 | 한 열 질문·결과, 작은 캐릭터 안내, 큰 터치 영역. 소개에서는 그림과 문장을 위아래 배치 |

사용자가 이번 기능에 색과 그림을 요청했으므로 탐색 화면에 한해 연보라·민트·살구·크림·연한 하늘색의 장식 배경을 적용했다. 색은 전형의 좋고 나쁨이나 판정을 나타내지 않는다. 본문은 어두운 잉크, 주요 버튼은 검정, 선택과 진행은 기존 Route Blue를 사용한다. 버튼·카드는 기존 직각을 유지하며 둥근 형태는 캐릭터·장식 일러스트 영역에 사용한다.

`docs/design.md`는 수정하지 않았다. 이 파일과 `admission-style.css`가 요청 범위의 디자인 확장 기록이며 정식 디자인 시스템에 등록된 것으로 간주하지 않는다.

캐릭터 **길콩**: 나침반 수첩을 든 크림색 탐험 친구. 청록색 가방, 연보라 목도리, 살구색 수첩. 특정 성적이나 우수 유형을 대표하지 않고 모든 응답자를 안내한다. built-in imagegen으로 새로 생성한 투명 PNG 1254×1254, 약 1.44 MB. RGBA와 알파 범위 0~255를 확인했다.

## 남은 확장

검증: 앱 전체 130개 테스트 통과, 프로덕션 빌드 통과. 실제 Chrome에서 1440px 소개와 390px 소개·문항·결과를 확인했고 가로 넘침 없음, 15문항 완료 후 기록가 결과 확인, 페이지 오류 없음. [PC 화면](admission-style-desktop.png), [모바일 소개](admission-style-mobile.png), [모바일 문항](admission-style-question.png), [모바일 결과](admission-style-result.png).

현재 체험판에는 결과 저장·공유 카드 다운로드·유형별 추가 캐릭터 포즈·실제 성적과 결합한 전형 검색은 없다. 실제 전형 추천을 강화할 때는 이 체험판의 선호 결과와 검수된 대학별 조건을 별도 축으로 보여준다. 성향 점수로 성적이나 자격을 덮어쓰지 않는다.

학생·상담교사에게 문항 이해도와 결과 해석을 검토받은 후 문항을 다듬고, 유형별 포즈와 정식 Figma 화면을 이어서 제작할 수 있다.
