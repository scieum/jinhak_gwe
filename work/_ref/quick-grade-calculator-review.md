# 간편 등급 계산 추가 · 2026-11-19

## 참고 사이트 확인

- https://jaehyung.kr/gradeCalculator
- 5등급 평균, 9등급 평균, 상위 누적 비율 입력 및 슬라이더가 즉시 연동된다.
- 부산교육청 예상 보정(2025), 경기진협 실측 분포(2025), 이론적 구간 중앙값의 세 모델이 있다. 기본 선택은 부산이다.
- 사이트의 부산 1.00 → 1.38은 누적 1%의 예상치를 택한 구현이다. 모든 학생에게 적용되는 공식 환산표로 해석할 수 없다.
- 사이트 구현은 실측표에 없는 9등급제 최상위 구간에 누적 0.1%를 가정해 보간한다. 이 가정은 이번 기능에 도입하지 않았다.

## 이번 구현

구간 중앙값 모델 하나를 명시적으로 제공한다. 5등급 구간은 0/10/34/66/90/100%, 9등급 구간은 0/4/11/23/40/60/77/89/96/100%이다. 구간의 중앙값을 등급과 연결하여 선형 보간하고 표시 단계에서만 소수 둘째 자리로 반올림한다. 원 사이트의 소스 코드를 복사하지 않고 독립적인 계산 함수와 React UI를 작성했다.

- 기본 예시: 5등급 2.00 → 이론적 누적 22% → 9등급 약 3.34.
- 양방향 입력, 슬라이더, 빠른 선택, 두 등급제 구간 막대, 계산 설명 및 원문 링크.
- 원래 입력 문자열·정밀도 유지. 빈 입력과 범위 초과는 계산하지 않으며 이전 결과를 지운다.
- 0~100%는 입력 가능하지만 중앙값 밖은 끝 등급으로 제한한다. 해당 구간에서는 역변환이 유일하지 않음을 표시한다.
- 평균의 실측 분포와 과목 단위 명목 구간을 구분한다. 전국 석차나 대학 공식 점수라는 표현을 쓰지 않는다.
- IndexedDB와 무관하게 계산 UI가 표시되며 성적을 저장·전송하지 않는다.
- 기존 상세 분석은 같은 경로 아래 접기/펼치기에 유지한다. 기존 draft 규칙과 입결 판정은 변경하지 않는다.

## 검증

- Vitest: 16개 파일, 210개 테스트 모두 통과. 새 계산·화면 테스트 19개 포함.
- `npm.cmd run build`: TypeScript 및 Vite 빌드 통과. 큰 번들에 대한 Vite 경고는 남아 있다.
- 연결형 브라우저 호스트를 사용할 수 없어 로컬 Chrome으로 확인했다. 1440px 데스크톱 및 390px 모바일 화면, 양방향 입력, 빈칸·범위 초과 복구, 상세 분석 펼치기, 가로 넘침 없음, 브라우저 실행 오류 없음을 확인했다.
- 최종 화면: `quick-grade-desktop.png`, `quick-grade-mobile.png`.
