# 대학 지도 위치 데이터

2026-11-25 실제 앱 연결. 기존 대학 목록 196개를 모두 매핑했으며, DGIST를 추가해 **197개 대학·244개 캠퍼스·17개 시도**를 제공한다. 대학 수와 캠퍼스 수는 다르다. 지도 개수는 캠퍼스 기준이다.

## 출처와 범위

- 원본: [교육부 대학교 주소기반 좌표정보](https://www.data.go.kr/data/15138981/fileData.do), 자료 기준일 2025-11-26, 수집일 2026-11-25. 원본 2,142행. 원본 SHA-256은 생성 JSON에 기록한다.
- 일반대학·교육대학·산업대학·특별법 대학의 학부 기관을 대상으로 한다. 전문대학·사이버대학·대학원 단독 기관·폐교는 제외한다.
- 본교·분교 구분은 원본 학교 구분을 따른다. 이름이 `본교 · 시군`인 표식도 실제 캠퍼스 한 곳이다. `본교만`은 법적 본분교 구분이며 물리적 대표 캠퍼스 한 곳만 의미하지 않는다.
- 교육부 학부 행에 누락된 14개 캠퍼스는 `campus-supplements.json`에 별도로 기록했다. 13개는 공식 대학 안내로 주소를 대조한 교육부 대학원 행의 동일 캠퍼스 좌표다. 경찰대학은 공식 아산 캠퍼스 주소와 공개 주소 좌표 제공처(findby)를 사용했다. 각 행의 `campus_source_url`, `source_url`에서 출처를 확인할 수 있다.
- `KCUE대학교` 행(A0000639)은 대교협 사무실 주소로 확인되어 제외했다. 실제 대학임을 확인하지 못한 행을 대학으로 표시하지 않는다.
- 대학 이름·통합은 기존 `universityIdentities.json`의 효력 발생한 항목을 적용한다. 이전 이름은 검색 별칭으로 보존한다.

현재 앱 대학 목록의 연결 누락은 0개다. 다만 교육부 2025년 자료에 없는 모든 물리적 캠퍼스를 전수 조사한 것은 아니다. 신규·이전·추가 캠퍼스는 다음 자료 갱신 시 확인해야 한다. 최신 현장 검수 또는 관리자 2인 검수를 완료했다는 뜻이 아니다.

## 생성 및 갱신

1. 위 공공데이터포털에서 XLSX를 내려받아 이 폴더의 `moe-campus-coordinates.xlsx`로 저장한다. 현재 파일은 `FILE_000000003547770`, `fileDetailSn=1`이다.
2. 원본 기준일이 바뀌면 `app/tools/build_university_map.py`의 `SOURCE_DATE`와 조합일 `AS_OF`를 변경한다. `campus-supplements.json`의 주소·출처와 기존 대학 identity 목록도 대조한다.
3. 저장소 루트에서 `python app/tools/build_university_map.py`를 실행한다(openpyxl 필요). 생성물은 `app/public/data/univ-map.json`, `campus-mapping.csv`, `mapping-report.json`이다.
4. `mapping-report.json`의 `directory_unmapped`와 지역별 수, 중복·좌표 범위를 확인한다. 앱 폴더에서 `npm.cmd run test -- tests/univ-map-data.test.tsx`, `npm.cmd run build:deploy`로 검증한다.

공개 자료는 version 2의 `official-published`/`source-published` 경로로 읽으며, 원본 URL·해시·기준일과 행별 주소·좌표·출처를 검사한다. 이 값은 출처 구분이며 전자서명이나 개별 좌표의 독립 검증을 의미하지 않는다. 기존 version 1 관리자 2인 검수 데이터 처리 규칙은 그대로 유지한다. 일반 앱의 개인 성적 샘플 모드에서도 대학 지도는 실제 위치 자료를 읽는다.

## 검증 기록

- 타입 검사 통과, 지도 관련 5개 테스트 파일 30개 테스트 통과, 배포 데이터 Python 테스트 6개 통과.
- 실제 데이터 196개 대학 전체 연결, 17개 시도, 중복·출처·좌표 검증, 검색→가천대 메디컬캠퍼스 선택→주소·핀·출처 연결 확인.
- 실제 배포 빌드의 Chromium 390px·1440px 화면에서 244개 캠퍼스 표시와 검색→핀 선택을 확인했다. 가로 넘침·페이지 오류 0건. 로컬 캡처와 결과는 `work/_cache/university-map-smoke/`에 있다.
- G5 디자인 게이트 통과. 기존 Figma의 고정 예시 데이터 재현에만 `VITE_MAP_DESIGN_FIXTURE=true`를 설정해 실행한다. 일반 빌드에는 설정하지 않는다. 실제 데이터 검증은 위 통합 테스트와 별개로 수행한다.
- 배포 빌드와 배포 필수 데이터 검증 통과. 서버 배포나 원격 저장소 게시를 수행한 것은 아니다.

수집 원본과 생성 데이터는 로컬 자료다. 기존 코드만 공개하는 저장소 방침에 따라 원본을 임의로 게시하지 않는다. 배포 시 지도 JSON은 기존 배포 데이터 번들에 포함된다.
