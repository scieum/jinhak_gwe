# 강원권 추가 자료의 통합본 반영

통합 기준 파일: `_all.csv`. 현재 총 25,191행. 기존 병합 대상 중 출처 기준에 맞는 행은 그대로 보존했습니다.

현재 README의 대학 입학처 원문만 사용 기준과 사용자 요청의 전문대 제외 기준을 적용했습니다.

| 자료 | 통합 행 | 출처 기준 제외 행 |
|---|---:|---:|
| chuncheon-education.csv | 33 | 0 |
| halla.csv | 310 | 0 |
| hallym.csv | 558 | 0 |
| kyungdong.csv | 152 | 0 |
| sangji.csv | 559 | 0 |
| yonsei-mirae.csv | 0 | 221 |

추가 강원권 대학의 통합 반영량은 5개교 1,612행입니다. 한라대 어디가 보완본(halla-adiga.csv) 191행은 대상 파일에서 제외했습니다. 연세대 미래 221행은 어디가 출처로 제외했습니다. 기존 국민대 570행·인하대 221행도 같은 출처 기준으로 제외됩니다.

전문대 원문과 기존 출처별 파일은 삭제하지 않았습니다. 병합 스크립트는 강원권 4년제 목록을 명시적으로 포함하며, 전문대·폴리텍과 어디가 출처를 재유입하지 않습니다.

검증: 기존 허용 행 누락 0, 강원권 허용 행 누락 0, 금지 출처·전문대 잔존 0. 대학별 CSV 원문은 변경하지 않았습니다.
