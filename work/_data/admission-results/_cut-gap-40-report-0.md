# 컷 없는 40개 대학 — 어디가 '대학 제공' 수시 50%·70% 컷 보충 (0묶음: _cut-gap-40.json 0~9번)

상태: draft (검수 전). 2026-11-27. _all.csv·기존 `<slug>.csv`·앱 파일은 바꾸지 않았다. 병합 전.

- 재현: `python fetch_cut_gap_0.py national-expansion slug:unvCd[:m] ...`(GET 3개 화면 + 결과 아코디언 POST, 1초 간격, 동시 1개) → `python build_cut_gap_0.py [slug ...]`
- 원본: `national-expansion/<slug>-adiga-<2024|2025|2026>[-<unvCd>].html`(searchSyr = 학년도+1)과 2027 화면 펼침 `…-2026[-<unvCd>]-20|30|40.html`(POST criteriaAndResultItemNewAjax.do). 각 `.meta.json`에 URL·sha256. unvCd가 여러 개인 경동대·단국대는 파일 이름 끝에 unvCd를 붙였다.
- 2024·2025: 결과공개 화면 본문의 수시 결과표에서 「최종등록자 교과성적 학생부등급 50% cut·70% cut」(나사렛대 2024는 「학생부 교과성적 (환산등급)」) 열. 등급 칸이 비고 같은 표의 「대학별환산 최종등록자 환산점수」만 있는 행은 metric 환산점수로 넣었다(교통대 23행). 수능·백분위 열이 있는 표(정시)는 제외.
- 2026: 2027 화면 「전년도 전형결과」 표의 「학생부 환산등급 50%·70%」(환산등급이 0이고 환산점수만 있으면 환산점수 — 이번 묶음엔 해당 0행). 표에 '최종등록자' 문구는 없다(공개표준안 형식). 표 안의 정시 행·「미제출 사유」 행·0.0 행은 제외.
- 50/70 칸이 '-'·빈칸·0·문자이면 넣지 않음. 값은 원문 그대로(반올림 없음). 70% 값이 50%보다 좋은(작은) 행도 원문대로 둠: 교통대 69, 대전대 19, 경동대 2, 경인교대 2행(종합 등 등급 외 기준 선발 표).
- 전형명: 같은 학년도 기존 `<slug>.csv`에 모집단위가 같은 행이 있고 전형명이 같거나(학생부종합/교과·전형·괄호·공백 빼고) 한쪽이 다른 쪽의 줄임(예: 지역인재 Ⅰ 전형 → 지역Ⅰ, 농어촌학생전형 → 농어촌전형)이며 그 대응이 하나뿐일 때만 기존 표기. 모집단위는 공백·가운뎃점·[교직]류 꼬리표 차이, 괄호 부연(예: 경영학부 → 경영학부 (경영학전공/회계학전공), 건축학과 → 건축학과(5년제)), '구) 옛 이름'(토목환경공학과 → 건설환경공학전공 구) 토목환경공학과), 교통대 원문 머리표 '□전'만 흡수했다. '(야)'는 흡수하지 않는다. 바꾼 행은 note에 어디가 원문 전형/모집단위.
- note "입학처 행 보완" = 기존 csv에 같은 학년도·전형·모집단위 행이 있음(이 대학들은 그 행에 50/70 컷이 없음). "입학처 미수록 …" = 같은 키를 확정 못 한 행(이름이 달라 대응 불명 포함). 이 행의 admission_type은 같은 원문 전형명이 대응된 행(또는 2026 아코디언 코드 20=종합, 30=교과)에서 가져왔다.
- 2024·2025 '충원 합격 순위'는 순위라 cut_other에(knue 방식), 2026 '충원인원'은 fill_count.
- 캠퍼스: 단국대는 unvCd로(0000082 죽전, 0002726 천안). 경동대·교통대는 한 화면에 두 캠퍼스가 섞여 있어 기존 입학처 행의 모집단위→캠퍼스 대응이 하나일 때만 배정했다.
