## 원칙
- 대학 입학처 공식 발표 자료(입시결과 PDF/엑셀/웹페이지, 전형 가이드북 부록)를 먼저 쓴다.
- 입학처에 없는 행·컷만 대입정보포털(adiga.kr)의 대학 제공 결과표로 보충한다(2026-11-19 사용자 결정). 보충 행은 `<slug>-adiga.csv`에 따로 두고 source_url은 adiga 주소. 입학처 파일(`<slug>.csv`)과 같은 키(학년도·수시/정시·전형·모집단위)에 입학처 행이 있고 그 행에 없는 컷(cut_50/cut_70)을 adiga가 줄 때도 adiga 행을 추가하며, note에 "입학처 행 보완"이라고 적는다.
- 사설 사이트(입결검색기, 진학사, 유웨이 등)·블로그·카페 수치는 쓰지 않는다.
- 문서에 없는 값은 비운다. 추정·보간·계산 금지. 숫자는 원문 그대로(반올림 금지).
- 행마다 출처 URL과 쪽수(또는 표 이름)를 단다.
