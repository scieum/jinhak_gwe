# 시안 공통 예시 데이터 (2026-11-22)

모든 화면 시안(S3·S4)은 이 값만 씁니다. 학생 화면의 "나"와 교사 화면의 "7번 하늘"은 같은 사람입니다.
여기 없는 값이 필요하면 이 값들과 모순되지 않게 만들고, 이 파일에 추가합니다.
NEVER-1·NEVER-2는 그대로 적용됩니다(검수 전 환산 규칙으로 계산한 값 금지, 합격 확률·보장 표현 금지).

## 학급
- 2학년 3반, 담임 1명, 학생 28명
- 별칭은 자연물 두 글자 하나로만: 하늘, 바다, 노을, 구름, 바람, 햇살, 이슬, 단비, 소나무, 별빛 … (학생C·솔방울 같은 다른 체계 금지)
- 번호 + 별칭으로 표기: "7번 하늘"
- 상담카드 제출: 제출 21명 · 미제출 7명
- 누가기록: 이번 달 기록 있는 학생 25명 · 없는 학생 3명

## 7번 하늘 (= 학생 화면의 "나")
- 학년 2학년, 계열 인문사회, 희망 전공 정책·행정
- 입력 과목 24개
- 내신 5등급 평균 **2.1** (학점 가중)
  - 과목군: 국어 2.3 · 수학 1.9 · 영어 2.0 · 사회 2.2 · 과학 2.1
  - 학기 추이: 1-1 2.4 → 1-2 2.2 → 2-1 2.0 → 2-2 1.9
- 9등급 환산(5 to 9): 추정 범위 **약 2.2~2.8**, 대표값 **2.5**, 신뢰도 보통
- 최근 모의고사(9등급): 국어 3 · 수학 2 · 영어 2 · 탐구1 3 · 탐구2 3
- 관심 대학 6곳(수시 6장): 상담 화면·수시로·관심 비교에서 같은 6곳

## 그래프 축 기본값
- 내신 추이 축: 데이터 범위 ±0.5로 좁힘(예: 1.5~3.0), 전체 1~5는 토글로
- 모의고사 추이 축: 1~5(값이 5 아래로 가면 넓힘)
