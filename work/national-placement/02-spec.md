## 1. 시안 데이터 (가상 · 시험용 숫자)

모든 숫자는 시험용 예시예요. 대학 이름은 화면 모양을 보여 주려고만 쓰고, 컷 · 행 수 · 모집인원은 실제 발표값이 아니에요. 검수된 환산 규칙으로 만든 숫자는 없어요(내 위치는 참고 상태에만, admission-results 시안과 같은 값).

## 4. 규칙 · 데이터

- 점 위치 = 대학이 발표한 9등급제 단일 수치 그대로(앱 "명확한 단일 수치만"). 범위 값 · 5등급제 값 · 서로 다른 통계를 같은 값으로 섞지 않아요. 평균을 컷으로 바꾸지 않아요. 새 환산 · 보간 · 가중치 없음 → NEVER-1 대상 계산 없음.
- 점을 찍는 조건 = 원문 대조 · 이용 조건 확인이 끝난 행(D2). 사용 허락이 확인되지 않은 외부 배치표 · 입결은 넣지 않아요(PRD 13장 · R-CONV-006 license_status = allowed).
- 같은 값 묶음 = 같은 대학 · 같은 학년도 · 같은 통계 · 같은 값(소수 첫째 자리). 행 수는 원문 행 수.
