## 공통 원칙

- 바탕은 흰 캔버스, 구조는 옅은 회색 단계와 1px 선. 모든 모서리 0. 카드·사이드바·버튼에 그림자 없음(그림자는 `bottom-sheet`에만).
- 판정·경고는 늘 색 + 아이콘 + 이름을 같이 써요. 색만으로 전달하지 않아요.
  - 수능 최저 판정(1순위 목표, 충족 현황): 충족 = 안정 쌍 ● / 근접 = 적정 쌍 ◐ / 미충족 = 위험 쌍 ■ / 자료 부족·판정 불가 = 판정 없음 쌍(아이콘 없이 이름만). `judge-badge` 모양을 그대로 써요.
  - 카드 조합 경고(수시로 경고): 소신 쌍 ▲ + "경고 n". `judge-badge` 경고 변형이에요.
  - 성적 하락은 판정이 아니라 신호라서 흑백 `data-status-badge`로 둬요.
- Route Blue는 두 가지에만 써요. ① 선택 상태: 선택된 `sidebar-item`, 켜진 `filter-chip`, `mode-switch`의 교사 칸, `tab-bar-pill`의 메뉴 탭 ② 핵심 숫자 1개: "상담 필요 9명"의 숫자. 판정 배지 안, 버튼 채움, 장식에는 쓰지 않아요.
- 문구는 "충족 현황", "충족해요/아직 못 미쳐요"처럼 지금 성적 기준 사실만 써요. 앞날을 점치는 예측 표현을 쓰지 않아요. 환산값에는 "약"과 범위를 붙여요.
- 학생은 번호 · 별칭으로만 보여요(실명 없음). 아래 수치는 모두 가상값이에요. 환산 9등급 범위는 PRD R-CONV(5→9 누적비율 보간) 결과이고, 성적이 없는 학생은 계산하지 않고 "성적 없음"으로 둬요.
- 숫자(번호, 등급, 범위, 명수, 날짜)는 모두 고정폭 숫자예요.
- 주요 버튼(`button-primary`)은 학생이 0명인 빈 상태에서만 하나 나와요. 평소 화면에는 주요 버튼이 없어요.

- 브리핑 펼침: `bottom-sheet`(그림자 허용, 뒤 scrim). 제목 "먼저 볼 학생 3명" + `data-status-badge` "규칙으로 고름". 행 3개 = 번호 · 별칭 / 신호 배지 최대 2개 / 이유 한 줄(PC P5 표와 같음). 편집 동작은 없어요.
