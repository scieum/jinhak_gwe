기존 미커밋 `fiveToNine` 구현은 보존한다. 학생 화면은 검수 차단이 있는 `conversion.ts` API를 사용한다. 기존 샘플 데이터의 verified 표시는 운영 검수로 취급하지 않는다.

학생 데이터는 기기에만 저장한다. 실제 대학 규칙·입결·신뢰도 정책·배치표를 임의로 verified로 올리지 않는다. 가상 입력을 쓰는 계산 테스트는 제품 데이터와 분리한다.

### 추가: 학생 모의고사 입력·추이 연결 (2026-11-20)

- `/score-trend`에서 기기에 저장한 모의고사를 영역별로 조회한다. 원점수·만점·예상 등급과 입력/등급컷 대기 상태를 회차별 표로 제공한다. 기존 모의고사 연결 준비 중 문구를 실제 기록으로 교체했다.
- 검수된 해당 시험·영역 등급컷이 있을 때만 등급 차트를 표시한다. 예상 등급 범위는 세로 구간으로 표시하고 중간값을 만들지 않는다. 표시 중인 회차의 등급이 없거나 범위이면 인접 선을 잇지 않는다. 현재 운영 등급컷은 여전히 비어 있다.
- 시험 목록 순서로 정렬하며 수정 시각으로 최근 시험을 고르지 않는다. 백업으로 들어온 목록 밖 시험은 표에 `순서 미확인`으로 남기고 최근 시험·차트에서는 제외한다. 원점수 0점은 유지하고 모든 영역을 지운 기록은 추이에서 제외한다.
- 추이 표의 수정 링크가 `/mock-score?exam=...`으로 이동한다. 복원한 시험도 입력 화면에서 수정할 수 있고, 저장 후 성적 추이로 돌아가 확인할 수 있다.
- 원점수 영역별 저장을 IndexedDB 트랜잭션 안에서 읽기·병합·저장하도록 변경했다. 여러 영역을 빠르게 입력해도 이전 영역이 덮어써지지 않는다. 시험을 바꾼 뒤 도착한 이전 저장 응답이 현재 초안을 지우지 않도록 보호했다.
- 검증: 신규 회귀 9개 포함 전체 25개 파일 274개 테스트 통과. TypeScript 검사·프로덕션 빌드 성공. 기존 500KB 초과 번들 경고 유지.
- 브라우저 시각 검증은 연결 호스트 부재로 미완료. 화면 이동·영역 선택·재저장·추이 갱신은 jsdom/IndexedDB 통합 테스트로 검증했다.
- 대학별 최저 기준 연결과 실제 등급컷 등록·내용 검수는 남아 있다. 대학별 최저 판정이나 영역 평균을 임의로 만들지 않았다.
