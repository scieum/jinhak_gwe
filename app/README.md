# 진학 내비 개발

Node 24, npm 11, Python 3.12 환경에서 검증합니다.

```sh
cd /workspace/jinhak_gwe/app
npm ci --cache /workspace/.npm-cache
npm run build
npm test -- --maxWorkers=2
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

## 계산 API

`src/engine/conversion.ts`의 `convertSubjects(subjects, options)`에 과목·검수된 보간/보정/신뢰도 규칙·배치표 조회 조건을 전달합니다. `src/engine/types.ts`에 입력 형식이 있습니다. `status`는 `ready`, `not_ready`, `invalid` 중 하나입니다. 결과의 각 방법과 신뢰도에도 상태가 있으므로 숫자나 라벨을 쓰기 전에 확인해야 합니다.

- A-1: 학점 가중 평균 → 5등급 중앙 누적비 → 9등급 중앙 누적비 보간.
- A-2: 과목별 환산 후 학점 가중. 수강자수가 있으면 검수된 인원 보정 규칙 필수. 없으면 명목 중앙 누적비 사용. 보정 규칙 미검수 시 명목값으로 몰래 대체하지 않습니다.
- 인원 보정 후보식: `round(n × 누적비 / 100)`로 경계 인원을 구해 실제 누적비 구간 중앙 사용. 수강자수 5명 이하·석차등급 없는 과목은 제외합니다. 성적표의 수강자수와 등급만으로 동석차 집단을 복원할 수 없으며, 원문 대조 전 후보 상태입니다.
- A-3: 고정분할 100/90/80/70/60/0점과 A~E 누적비를 연결하고 석차등급 구간 안으로 제한합니다. 합계 100±0.1%는 100으로 정규화하고 trace에 기록합니다. 추정분할/미상/입력 누락이면 계산하지 않습니다. 비교 대상 과목이 달라지는 것을 막기 위해 선택된 산출 과목 모두 입력이 있어야 A-3 평균을 냅니다. 검수 전 기본 비활성입니다.
- B: 검수 완료이면서 이용 허락된 표만, 정확히 같은 교과 구성으로 조회합니다. 동일 학기 우선, 없으면 가장 가까운 학기(동률은 최신 연도·큰 표본·ID 순). 표 범위 밖 외삽 금지. 대체 학기 사용 시 검수된 신뢰도 정책의 결과를 한 단계 낮춥니다.
- 신뢰도: 산출 과목 수, 소수 수강 비율, 제외 비율, 방법 간 차이를 사용합니다. 기준값은 검수된 외부 정책으로 전달하며 현재 제품 기본값을 임의 확정하지 않았습니다.
- `judgeRange`는 검수된 입결과 관리자 기준으로 max 값을 판정하고, min에서 라벨이 달라지는지 반환합니다. 충원율·수능최저는 별도 정보이며 이 함수에서 판정값을 바꾸지 않습니다.

중간 계산은 반올림하지 않습니다. `trace`로 과목별 환산값·학점 가중치·제외 사유·출처·학기 대체 여부를 확인할 수 있습니다. 현재 API는 화면이나 서버에 연결하지 않았으며 학생 데이터를 전송하거나 저장하지 않습니다.

## 데이터 검수 상태

`src/data/conversion-rules.ts`는 모두 **draft**입니다. 테스트의 synthetic `verified` 사본은 계산 구현 검증용이며 운영 데이터의 검수 이력이 아닙니다. 실제 활성화는 내용 검수 후 별도 변경으로 처리합니다.

부산 1차 배치표 후보는 기존 조사·화면 설계에 기록된 3개 대응점뿐입니다. 원표 전체가 아니며 구성 교과, 원문 숫자, 사용 허락을 확인하지 못했습니다. 2026-11-18 원문 접근 시 환경 프록시가 403을 반환했습니다. 관련 도메인 접근을 적용한 뒤 원문을 다시 확인하고, 전체 표·출처 페이지·정확한 과목 범위·이용 조건을 등록해야 합니다. 원자료의 대학 라인은 저장하지 않습니다.

## 남은 작업

대학별 교과/출결 계산, 익명 표본으로 A-3 검증, 인원 산출식 원문 확인, 전체 실측표 확보·이용 조건 검수, 성적 입력·IndexedDB 저장·화면 연결이 남아 있습니다.

저장소 루트의 Python 하네스 테스트에는 기존 실패 2개가 있습니다. 규칙 파일의 문서 해시가 CRLF 기준인데 Linux 문서는 LF이므로 J9가 실패합니다. 이번 변경에서는 보호된 docs/rules/scripts를 수정하지 않았습니다.
