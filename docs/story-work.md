# 작업 흐름 — 진학 내비 화면 디자인

> AI 없이 손으로 했던 마지막 경험을 실제 순서대로 적은 것이다.
> 판정 기준(어기면 안 되는 것)은 story-service.md에 있다. 이 문서와 섞지 않는다.
> 가이드 = docs/design.md (특히 Do's and Don'ts).

## 실제 흐름

1. 나는 uibowl에서 경쟁사 레퍼런스를 수집한다.
2. 나는 레퍼런스를 분석해 우리 서비스에 반영할 부분을 고른다. **(멈칫: 무엇을 가져올지 판단)**
3. 나는 분석 내용을 토대로 화면 설계 문서를 구체화한다.
4. 나는 Figma에 레퍼런스와 화면 설계서를 반영한 UI 키스크린 2~3개를 그린다.
   - 실제 경험: 390×844만 그렸다.
   - 앞으로: design.md 기준으로 모바일 390×844 + PC 1440×900 두 프레임을 그린다.
5. 나는 내부 관계자와 협의해 컨셉 시안을 확정한다. **(멈칫: 확정 판단) (넘김 → 내부 관계자)**
6. 나는 확정 시안으로 디자인 토큰과 컴포넌트를 만들고 화면 디자인에 들어간다.
7. 나는 완성 시안의 토큰·컴포넌트가 design.md를 어기지 않았는지 검토한다. **(멈칫: 위반 여부 판단)**
