# 하네스 파이프라인 — 진학 내비 화면 디자인

```
S1 리서치 ──▶ S2 설계 ──▶ S3 시안 ──▶ [사람 승인] ──▶ S4 제작 ──▶ S5 판정
 (1·2번)      (3번)      (4번)         (5번)          (6번)      (7번)
                ▲           │ 반려                       ▲          │ 위반
                └───────────┘                            └──────────┘
```
(괄호 = story-work.md 단계 번호)

## 단계별 입출력

| 단계 | 담당 | 입력 | 출력 |
|---|---|---|---|
| S1 리서치 | 에이전트 | 대상 화면 이름, prd.md 해당 절 | uibowl 레퍼런스 목록(링크 N개) + 반영 포인트 |
| S2 설계 | 에이전트 | S1 출력, prd.md, design.md | 화면 설계서(구성 요소, 사용하는 design.md 컴포넌트 이름, 문구) |
| S3 시안 | 에이전트 | S2 출력, design.md | Figma 시안 1개 — 390×844 + 1440×900 프레임 |
| 승인 | 내부 관계자 | S3 출력 | 승인/반려 기록(사유 포함) |
| S4 제작 | 에이전트 | 승인된 시안, design.md | Figma 변수·컴포넌트를 적용한 최종 화면 |
| S5 판정 | 판정 스크립트(읽기 전용) | S4 출력, design.md, story-service.md | 위반 리포트(항목별 건수) |

## 되돌아가는 지점

| 상황 | 복귀 |
|---|---|
| 승인 반려 | S2. 사유가 "레퍼런스 방향"이면 S1 |
| S5 위반 | S4. 같은 위반으로 3회 연속 실패하면 멈추고 실행자에게 넘김 |
| S4에서 design.md에 없는 토큰 필요 | 멈추고 "design.md 수정 제안"을 실행자에게 넘김 |
