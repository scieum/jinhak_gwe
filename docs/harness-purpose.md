# 하네스 목적 — 진학 내비 화면 디자인

## 매번 달라지는 것 (입력)
- 대상 화면 이름 1개 (docs/prd.md 15장 "핵심 화면" 목록에서 선택. 예: `수시로`)

## 고정 입력
- docs/prd.md — 서비스 요구사항
- docs/design.md — 토큰·컴포넌트·Do's and Don'ts (가이드 SSOT)
- docs/story-service.md — 판정 기준 (NEVER-1, NEVER-2)

## 사용자
- 실행자: 디자이너 1명
- 확정 승인자: 내부 관계자 (story-work.md 5번 넘김 지점)

## 토큰·컴포넌트 원칙
- design.md에 정의된 것을 Figma 변수·컴포넌트로 옮기기만 한다. 새 토큰을 만들지 않는다.
- 필요한 것이 design.md에 없으면 멈추고 "design.md 수정 제안"을 실행자에게 넘긴다.

## 완료 기준
대상 화면 1개가 Figma에 390×844 + 1440×900 두 프레임으로 있고,
design.md 위반 0건, 금지어(NEVER-2) 0건, 내부 관계자 승인 기록 1건이면 완료.
(위반 항목별 세는 방법은 R5에서 확정)
